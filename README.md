# JX 的考研知识库

这是一个用于记录考研复习过程的个人知识库，主要整理数学、408 和英语中的知识点、解题方法、真题复盘与学习心得。

## 包含内容

### 408

`408/` 包含数据结构、计算机组成原理、操作系统和计算机网络四门课程的笔记，以及考纲、真题分析、考前记忆清单、算法模板和易错知识点整理。

### 数学

`数学/` 记录高等数学中的解题方法、典型题型和复盘笔记，重点关注如何识别题目条件并选择合适的方法。

### 英语

`英语/` 记录英语阅读中的解题思路、长难句理解和单词记忆相关的复盘与方法总结。

## 使用说明

仓库中的笔记均为 Markdown 文件，推荐使用 [Obsidian](https://obsidian.md/) 打开和浏览。内容会随复习进度持续补充和调整。
