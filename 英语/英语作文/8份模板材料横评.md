## 二、逐份点评

### 1. AI 归来（88 页）—— 大作文主力

**强项（别处没有的）**
- **第二段七种论证方案**：举例论证 / 宾语从句+定语从句 / 四种从句+常用短语 / not only 倒装 / 虚拟语气恐吓法 / 对比论证 / 比喻句。**每个方案都配 5–8 条真题例句**，是唯一把"第二段怎么写"讲透的材料。
- **六大方面语料库**：社会 / 自然 / 文化 / 个人 / 交流 / 科技，每个方面又按「核心 → 方式 → 目标」三层展开。
- **图画分类拆分组合法**：非对话型 / 对话型 / 两幅图 / 一图一表，四套统一公式，取代了"一题一法"。
- 图表第一段全覆盖：动态单方向 / 多方向 / 双图表 / 静态 / 万能场景。
- **49 张真题原图**（图表截图 + 真题漫画，含 2009 网络"近"与"远"、2015 手机时代的聚会、2019 登山途中、2010 文化"火锅"、2011 旅程之"余"、2023 龙舟赛、2020 两种习惯等）。
- 图画主题阐述三方案 + 文字作文第一段写法。

**弱项**
- **几乎不讲小作文**——小作文在这份材料里是空白。
- 篇幅最大（88 页），不筛选会淹。

**适合**：大作文第一段 + 第二段 + 图画/图表全套。

---

### 2. 御风（74 页）—— 方法论与范文

**强项**
- **「预审题」理论**：反模板的核心思想——让文章结构与题目逻辑对齐，模板感就变成高级感。
- **图画第一段 A/B/C 三式** + 描述三步法（主体+动作 → 加修饰 → 次要信息用非谓语）。
- 图表范式：动态五要素（时间+事物+趋势+数值+意义）、静态逐个写法 + **聚类写法**。
- **十种句式**（提高 GRA）：否定 / 定从 / 让步 / It 句 / 假设 / 倒装 / 强调 / 比较 / 插入语 / 原因句。
- **附录一逻辑词 15 类**——这份表很完整。
- 小作文：**事件六要素表达库**（时间/地点/人物/起因/经过/结果）+ **14+ 种信件结尾两句式表** + 通知模板。
- **20 篇范文**（英一 2011/2013/2019/2020/2024，英二多篇，小作文多项）。
- 评分标准五档表。

**弱项**
- 图表第一段的细节不如 AI 归来细。
- **53 张图未被我利用**（含范文手写样张、格式示意），需单独提取。

**适合**：全科打底 + 小作文框架 + 句式升级 + 看范文。

---

### 3. 帕拉迪宇（56 页）—— 小作文素材库

**强项**
- **小作文功能句约 200 条**：六类信件（建议 / 邀请 / 道歉 / 祝贺 / 介绍 / 通知）各配「首句 7 + 中句 7 + 尾句 7」。
- 第一段**目的句 27 条**（按信件类型分）+ 问候语 10 条。
- **"241 / 231 / 152 / 252"公式化打法**——按段选句的组合思路。
- 附**题目相关词词汇表**。
- 原卷样张：齐头式、缩进式对比。

**弱项**
- **句子模板感强**——每句都是固定句式，全用会露馅，必须挑着用、改造着用。
- 大作文部分相对常规，不如 AI 归来细。

**适合**：小作文句子不够用、需要扩充时。

---

### 4. 英语作文.docx（7.5 KB）—— 词汇与格式速查

**强项**
- **字数与行数分配**：小作文 14 行 ≈150 词（40/70/40）；大作文 20 行 ≈220 词（60/110/50）。**这是别处没有的具体量化**。
- **四类词汇表**：名词 ~70 / 动词 ~60 / 形容词 ~50 / 副词 ~14。
- 小作文问候语 + 4 种接续（安慰/感激/回信/祝贺）。
- 告示 NOTICE 完整模板。
- 中间段框架 + 完整范例 + 结尾段（sheds light on / Looking ahead）。

**弱项**
- 零散、不成体系，像随手记的笔记。
- 小作文点明目的只有 5 种（不如帕拉迪宇的 27 条）。

**适合**：补词汇量、确认字数格式。

---

### 5–6. 27考研 图画 / 图表模板（各 5 页）—— 原因与好处公式卡

**强项**
- 图画卡：单图/双图第一段公式 + **万能原因 ①–⑥ 英文原句** + **好处库 7 类英文**（个人品质/读书教育/传统美德/环境保护/科技/文化/万能）+ 第三段 Altogether 三版本。
- 图表卡：柱状/折线 + 饼图/表格公式 + **万能原因 ①–⑤ 并标注"适用哪几年真题"**（这个标注很有用）+ **好处库 7 类（加粗标通用性）**。

**弱项**
- 只有公式，**没有方法讲解**；句子偏旧（`What springs from this cartoon...` 已是"模板身份证"）。

**适合**：写第二段时"没话说"，来这两张卡取原因与好处。

---

### 7–8. 27考研 小作文 v1 / v2

**v1（9 页）**
- 强项：**7 类信件万能论点库**（每类 2–3 个论点，且**标注适用真题年份**）+ 目的句 9 种 + 通知招募版/介绍版 + 注意事项 4 类。
- 弱项：句子简单；覆盖信件类型少于 v2。

**v2（3 页）**
- 强项：**8 套完整信件模板（①–⑩ 编号句）**——感谢 / 祝贺 / 投诉 / 介绍 / 申请 / 道歉 / 推荐 / 邀请。**v1 没有"感谢信/祝贺信"的完整模板**，v2 补上了。
- 弱项：句子非常基础（如 `I am excessively sorry to tell you that...`），模板感最重。

**适合**：v1 取论点、v2 取骨架。

## 五、五份材料的共同短板

1. **都不讲"如何避免模板化"**——这正是《英语一作文-去模板化写作方案》存在的理由，它补的正是这块。
2. **图与文分离**——AI 归来、御风、帕拉迪宇的 PDF 里都有大量真题原图，但整理文字时容易漏掉。若要图文对照，需要单独提图。
3. **句子新旧混杂**——老模板句（`As is vividly depicted...`、`With the rapid development of society and economy...`）与较新的表达混在一起，需自行筛。
4. **没有阅卷数据支撑**——所有材料的"高分"主张都是经验判断，没有评分样本或阅卷细则佐证。
