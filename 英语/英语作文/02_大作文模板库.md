# 02 · 大作文模板库（英语一 B 节 · 20 分 · 160–200 词）

> 侧重点：**语法**（句子能不能撑住 15 分以上）+ **切题**（跑题直接掉两档）
> 七家资料按 `D-来源缩写` 编号

## 〇、先定基线

| 项 | 标准 | 说明 |
|---|---|---|
| 词数 | **175–200 词** | 少于 160 明显不足；200 词占答题卡 18–20 行 |
| 句数 | **10–12 句** | 三段：3 / 5 / 3 |
| 段落 | 3 段，首行缩进 4 字符 | 不写标题 |
| 时间 | 25 分钟（5 分钟审题列提纲 + 20 分钟默写） | AI归来的实测值 |
| 主题句 | 每段**第一句**必须亮明本段干什么 | 阅卷老师只看每段第一句也能给分 |

### 英一到底考什么（近 16 年统计，空卡材料）

| 题型 | 次数 | 年份 |
|---|---|---|
| 图画 | **14 次** | 主流 |
| 图表 | 1 次 | 2025 |
| 图画 + 图表 | 1 次 | 2024 |
| 文字（材料作文） | 0 次 | 大纲有，未考过 |

> 结论：**图画仍是主战场，但 2024/2025 连续两年破例，图表必须会。** 精力按 AI归来的建议分配：图表 20 / 双图表 40 / 图画 20 / 图画+图表 10 / 文字 10（满分 100 的精力）。

## D-KK · 空卡 大作文万能模板

**定位**：343 法 · 10 句话搞定 · 四合一（英一英二通用）

### 框架（背这张表就够）
| 段 | 句数 | 内容 | 是否分题型 |
|---|---|---|---|
| 一 | 2–3 | 描述题干 + 补充细节 +（翻译标题） | **分 4 型**：图画 / 图表 / 文字 / 图画+图表 |
| 二 | 4–5 | 过渡句 + 原因 | 通用 |
| 三 | 3 | 总结过渡 + 提出建议 + 万能结尾 | 通用 |

### 原因与建议的角度槽（最实用的部分）
| 位置 | 可选角度 |
|---|---|
| 二段原因 | 经济 / 科技 / 社会 / 家庭 / 个人 / 举例 |
| 三段建议 | 社会 / 政府 / 学校 / 家庭 / 个人 |

### 优缺点
| 优点 | 缺点 |
|---|---|
| 背得最少（10 句），上手最快 | 通用句占比高 → **切题度天然弱**，容易「说了很多但没说这幅图」 |
| 第一段四种开头都给了，不会开局崩 | 原因句偏抽象，缺具体细节支撑 |
| 有考情数据，方向不跑偏 | 语言上限约 14 分，想上 16 必须换句 |

**适用分数段**：11–14 / 20
**推荐用法**：**第一层骨架。** 先用它把「三段各写几句」固定下来，再往里塞具体内容。**不要指望它直接给你高分。**

### 切题风险（重点看这条）
> 空卡的万能句容易写成「放之四海而皆准」：
> `It is of great significance for us to pay attention to this phenomenon.`
> 这句话放在任何题目下都对，也放在任何题目下都**不得分**。

**改造要求**：二段 3 个原因里，**至少 1 个必须出现题干的具体主体**（不是「人们」，是「大学生/老年人/家长/游客」）。

### 改造清单
- [ ] 每段第一句改成「本段主题句 + 题干关键词」
- [ ] 二段原因：删掉最空的那一条，换成题干场景里的具体现象
- [ ] 三段建议：从「政府/社会/个人」里**只选 2 个**，且都要落到题干主体
- [ ] 第一段描述句加 1 个具体细节（数字、动作、表情、文字说明）
- [ ] 万能结尾换掉：`Only in this way can we...` 是最烂大街的句式

## D-CR · 柴荣 大作文

**定位**：段落结构 + 论证角度清单（最清爽的提纲工具）

### 结构
```
P1 描述（2–3 句）
   第 1 句：图表/图画下方文字概括
   第 2 句：趋势描述（动态）/ 占比描述（静态）
   第 3 句：描述总结（可选）

P2 分析（3–4 句）
   第 1 句：引出原因
   第 2–4 句：原因 1 / 2 / 3（第 3 条可选）

P3 总结（1–3 句）
   第 1 句：论述总结
   第 2 句：提出建议（可选）
   第 3 句：憧憬未来（可选）
```

### 两个清单（治「想不出原因」）
| 清单 | 内容 |
|---|---|
| 分析角度（9 个） | 政府 / 政策 / 经济 / 科技 / 媒体 / 社会 / 文化 / 学校 / 家庭 / 个人 |
| 论证方法（5 种） | 因果论证 / 正反论证 / 举例论证 / 数据引用 / 名言引用 |

### 优缺点
| 优点 | 缺点 |
|---|---|
| 结构最干净，一眼看懂每句干什么 | 句型基本停在 12 分档，缺高级语法 |
| 角度清单能救「考场空白」 | 无完整范文，不知道拼起来什么样 |
| 句数与词数对应清楚 | 分析角度偏「宏观」，个人化细节少 |

**适用分数段**：12–15 / 20
**推荐用法**：**当列提纲的尺子。** 考前 30 秒用它定「三段各几句、二段三个角度选哪三个」，句子从 D-AI / D-WJT 取。

### 改造清单
- [ ] 角度清单每次只用 3 个，**且必须有一个是「个人/家庭」层面**（否则全是宏大叙事，显得空）
- [ ] P3 的「憧憬未来」慎用，容易写成口号；改成「具体可执行的动作」更稳
- [ ] 每个原因后加一句解释或例子（否则就是三句口号）

## D-AI · AI归来 大作文（**建议作为主干教材**）

**定位**：按行文顺序逐句给「待选句 + 公式 + 真题套用」

### 结构（88 页，按这个顺序学）
```
3.1 图表作文第一段：总体描述 + 细节描述 + 社会现象   （p6）
3.2 通用第二段：过渡句 + 原因 1/2/3                  （p31）
3.3 通用第三段：总结全文 + 具体措施 + 畅想未来       （p58）
3.4 图画作文第一段：图画描述 + 主题阐述              （p69）
3.5 文字作文第一段：文字改写 + 表明态度              （p82）
```

> 学习路径：**先学一个题型的第一段 → 二段 → 三段 → 再补其他题型的第一段**。二、三段通用，这是它最大的效率设计。

### 它的核心方法：每句给 3–5 个「待选句」
以第二段过渡句为例：
```
升级前：There are many reasons to explain my idea.
替换词：many→innumerable / countless / a host of / a variety of
        reason→factor / cause
        explain→contribute / give rise to / account for
        idea→standpoint / perspective / viewpoint

待选 1：Three key reasons, from my perspective, account for this phenomenon.
待选 2：From my perspective, the causes of X can be summarized as three main aspects.
待选 3：Several factors contribute to this phenomenon.
待选 4：A variety of reasons can be cited to account for this phenomenon.
```

### 图表词库（这是它最硬的资产）
| 功能 | 词/句 |
|---|---|
| 增加 | increase / rise / grow / expand / climb / jump / surge / soar |
| 减少 | decrease / decline / diminish / shrink / drop / fall |
| 持平 | remain flat / stay at / stand at / stabilize |
| 波动 | vary / rise and fall / fluctuate |
| 幅度 | sharply / markedly / notably / remarkably / dramatically；slightly / gradually / steadily / modestly |
| 占比 | account for / make up / constitute；proportion / percentage / share（对比用 ratio） |
| 峰值谷值 | peak at / reach a peak of / hit a record high；bottom out at / hit a trough |
| 倍数 | A doubled / tripled；A is X times as high as B；A increased by X / to X |
| 排序 | rank first / top the list / follow closely behind / the lion's share |
| 约数 | approximately / roughly / nearly / just over / just under |
| 趋势名词短语 | `The period from A to B witnessed a steady rise in...` |

### 二段「举例论证」四步组装（可直接抄的模板）
```
第 1 步 引出例子：This point can be confirmed by the example of my roommate,
第 2 步 简单句描述现状：My hometown, a livable city, places a high priority on infrastructure construction.
第 3 步 which 非限定从句表结果：, which enables residents to relax and unwind at nearby parks.
第 4 步 换角度收尾：During this period, citizen satisfaction has improved.
```
> 关键提醒（原文）：「放弃背诵名人事例，专注于准备 2–3 个来自生活、经历、社会的例子」。

### 优缺点
| 优点 | 缺点 |
|---|---|
| 思路最系统，五种题型全覆盖且可迁移 | 88 页信息量，最容易「看完等于没看」 |
| 每句多版本，能拼出「独一无二」的模板 | 不做取舍就套不出来 |
| 图表词库质量高，直接可用 | 部分待选句偏长，200 词容易超 |

**适用分数段**：13–16 / 20
**推荐用法**：**主干教材。** 但必须做减法：**每个句位只固定 1 个句子**，其余全部划掉当备选。固定后再练 8 篇真题。

### 改造清单
- [ ] 每个句位选 1 句，抄到一张纸上，形成**你自己的 10 句**（这一步不做，学完也白学）
- [ ] 图表描述句不要堆数字，200 词里数据最多出现 2 组
- [ ] 二段三个原因必须是**三个不同角度**，不能都是「经济」
- [ ] 三段「畅想未来」最多 1 句，多了变口号
- [ ] 图画题的第一段要写出「对比/反差」，只描述不对比 = 没抓住寓意

## D-JT · 晶婷 大作文

**定位**：中文句模 + 逐句字数 + 填空练习（自制模板训练册）

### 形态
和它的小作文讲义一样，**大量留白让你自己写英文**。例如：
```
【选择 1】这幅图描绘了关于 xx 的现象，给人留下了多么深刻的印象啊！
短句：______________________________________
长句：______________________________________

【选择 2】[sth/主题词]这个被忽略的现象像达摩克利斯之剑一样悬在人类头上。
```

### 它的量化标准
- 第一段：**6 行，每行 9–12 个单词**（约 60 词）
- 短句 / 长句双版本，可按水平选

### 优缺点
| 优点 | 缺点 |
|---|---|
| 字数、行数控制到句，最容易治好篇幅失控 | 英文全靠自己写，基础弱写不出来 |
| 短句/长句双版本，有明确的升级路径 | 信息密度低，58 页里有效内容约 15 页 |
| 中文句模思路清楚，适合前期「想明白再写」 | 没有成品范文 |

**适用分数段**：12–16 / 20（上限看你写出来的水平）
**推荐用法**：**前期训练册。** 用它的中文句模练「把思路翻成英文」，用它的行数×词数卡篇幅。英文表达从 D-AI / D-WJT 取。

### 改造清单
- [ ] 只用量化标准 + 中文思路，**不要直译中文句模**（容易中式英语）
- [ ] 每段写完数行数：一段 6 行、二段 8 行、三段 4 行，超了就砍
- [ ] 短句版先写到不出错，再升级长句

## D-WJT · 王晶婷 高分写作技巧（**语料库主力**）

**定位**：食材库 + 分类型模板 + 18 个常用句型 + 近 10 年范文

### 结构
```
第一章 大作文第一段（图画 / 图表）
第二章 小作文
第三章 第二段万能模板：建议类 / 推荐介绍类 / 活动类 / 感情类
第四章 第三段万能模板
Part4 附录
  第一章 历年大小作文题目
  第二章 必备语料库
     词汇：图画图表必背词 / 话题分类词 / 高分替换词 / 必备闪光词
     句子：句子原则 / 18 个写作常用句型
  第三章 近 10 年大小作文范文
```

### 作者自述的定位（原话，很重要）
> 「很多同学是看中了王晶婷的语料高级、模板句小众来的。」
> 「把大作文语料拆解成一个个独立的『食材』，分门别类摆放在『晶婷写作食材库』里，由你自由选择食材口味和分量。」
> 「少而精，是我写这本书的底线。」
> 「简单且正确的句子，得分一定比复杂却写错的句子要高。先把简单的句子写对、写稳，你就已经超越了大多数人。」

### 优缺点
| 优点 | 缺点 |
|---|---|
| 语料小众，撞模板概率最低 | 需要自己组装，没有「整套成品」 |
| 同一功能位多版本，可按难度选 | 部分句子书面化，硬套会显得不自然 |
| 替换词成体系，能持续升级语言 | 两本讲义（这本 + 配套讲义）要配合用 |
| 有近 10 年范文可对照 | — |

**适用分数段**：14–17 / 20
**推荐用法**：**当弹药库 + 升级路径。** 骨架用 D-AI，每个功能位从它这里取 1 个「进阶版」句子替换，形成自己的版本。

### 改造清单
- [ ] 每个功能位只留 2 个版本（安全版 + 进阶版），其余划掉
- [ ] 进阶版必须自己套过一个真题才算掌握
- [ ] 一句里最多 1 个「高级结构」，堆两个就变炫技
- [ ] 闪光词（`paramount` / `ubiquitous`）大作文可用，但一篇不超过 3 个

## D-DD · 大道至简 大作文（**范文库主力**）

**定位**：2011–2025 共 15 年真题逐篇拆解（思路 + 逐句语料 + 完整范文）

### 结构（每篇四块）
```
（零）写作思路
（一）首段 —— 描述图片
（二）中间段 —— 阐释涵义（①说明现象 ②分析原因 ③…）
（三）结尾段 —— 发表评论
（四）完整范文（标了词数：194 / 213 / 226 词）
```

### 它独特的地方
1. **按类型分组练，不按年份**——同类作文放一起，一篇积累的语料可迁移到下一篇
2. **每段给「思路 → 可用句型 → 语料」三层**，不是直接甩范文
3. **范文词数贴着考场实际**（194–226 词），不是「名家散文」

### 题目清单（可当题材库）
| 类型 | 年份 |
|---|---|
| 社会现象·消极 | 2011 |
| 个人品质 | 2012、2013、2014、2016、2017、2018、2019、2020、2021、2022 |
| 社会现象·科技 | 2015 |
| 社会现象·积极 | 2023、2024、2025（家用电器，图表） |

> 明显规律：**个人品质占 10/15**，这是英一图画作文的绝对主流。

### 优缺点
| 优点 | 缺点 |
|---|---|
| 语料最真实，直接对应真题 | 没有通用模板，要自己提炼 |
| 范文词数接近考场实际 | 15 篇信息量大，容易只读不写 |
| 同类型可迁移，学习效率高 | 每篇的句型偏「范文级」，默写难度高 |

**适用分数段**：15–18 / 20（范文水平）
**推荐用法**：**两天一篇，背—默—总结。** 不要只读。每篇做完问三个问题：
1. 它的首段是怎么「描述 + 点题」的？
2. 二段用了哪三个角度？
3. 尾段有没有一句我能直接搬走？

### 改造清单
- [ ] 不要整篇背，**每篇只摘 3 句**（首段 1、二段 1、尾段 1）
- [ ] 摘完立刻套到另一个年份的题目上写一遍
- [ ] 范文里的长难句降一档再用（原文 226 词，你写 190 词就够）
- [ ] 注意 2025 是图表题，说明它也在跟着题型变化，别只练图画

## D-MK · monkey 大三元

**定位**：论点框架 + 外刊金句库（拔高用）

### 大三元四类
| 类 | 追问 | 适用题 |
|---|---|---|
| 1 变化与成因 | 现实是什么？为什么这样？相较以前有哪些变化？ | 科技/社会现象类（2015、2023、2024、2025） |
| 2 优秀品质 | 好，为什么好？对谁好？从哪些角度看是好？ | 个人品质类（2012–2022 主流） |
| 3 不良问题 | 不好，为什么不好？对谁不好？没有它会怎样？ | 消极现象类（2011） |
| 4 建议警醒 | 该怎么做？不解决会有什么后果？ | 尾段通用 |

### 金句的形态（每句带抽象功能标签）
```
① Owing to the universalization of Internet access, China has witnessed a remarkable
   development in mass communication, and with it the further exposure to new wants
   and new ideas.
   标签：变化 A→变化 B→变化 C，向前可追溯根源，向后可探究影响

② Never before has internet served so much to empower education as in this year.
   标签：某个东西在某个方面有突出贡献，越来越重要

③ To paraphrase 18th-century statesman Edmund Burke, "all that is needed for the
   triumph of a misguided cause is that good people do nothing."
   标签：如果我们无动于衷，当前问题真可能造成严重后果
```

### 优缺点
| 优点 | 缺点 |
|---|---|
| 论证有纵深（矛盾/历史继承/短期利益 vs 公共利益），不是空喊 | 句子长、难度高，套用需要功力 |
| 金句来自外刊，与考研阅读同源，质量高 | 容易「背了用不上」 |
| 每句都有功能标签，知道什么时候用 | 部分句子带美国语境（Edmund Burke、pink slip），硬套不自然 |

**适用分数段**：14–17 / 20（用得好）
**推荐用法**：**只当拔高句库。** 一篇里最多用 **1–2 句**：二段第三个原因，或尾段第一句。**绝不要整段用它**——会变成「背了一堆大词但没说这幅图」。

### 改造清单
- [ ] 一篇最多 2 句，多了必翻车
- [ ] 带美国人名/制度的句子（pink slip、Edmund Burke）改成通用表达
- [ ] 长句砍到 25 词以内再用
- [ ] 用之前先确认它和题干主题**真的对得上**，别为了用而用

| 第三段 | 总结+建议+万能结尾 | 总结+建议+憧憬 | 总结+措施+畅想 | 中文句模 | 万能模板 | 发表评论 | 建议警醒 |
| 语言水平 | ★★☆ | ★★☆ | ★★★ | 取决于你 | ★★★ | ★★★★ | ★★★★ |

**结论**：
- 结构最省事 → 空卡
- 提纲最快 → 柴荣
- 句子最全 → AI归来
- 语料最好 → 王晶婷 / 大道至简
- 拔高最猛 → monkey

## 语法升级阶梯（把 12 分句改成 16 分句）

按这个顺序练，一次只升一级：

| 级 | 手段 | 例 |
|---|---|---|
| 1 | 简单句写对 | `Many students are addicted to short videos.` |
| 2 | 加状语/定语 | `Many college students, especially freshmen, are increasingly addicted to short videos.` |
| 3 | 非谓语开头 | `Addicted to short videos, many students find it hard to concentrate in class.` |
| 4 | 定语从句 | `Many students are addicted to short videos, which severely undermines their academic performance.` |
| 5 | 名词化 / 倒装 / 强调 | `So pervasive has this addiction become that it now threatens students' academic performance.` |

**铁律**：**升级到第 4 级就够 16 分了。** 第 5 级一篇最多 1 句，用错直接掉档。

## 切题检查表（写完必过，比语法重要）

### 第一段
- [ ] 图画题：写出「谁 + 在做什么 + 细节 + 文字说明」四要素
- [ ] 图画题：有没有点出**对比/反差**？（英一图画的寓意几乎都靠对比）
- [ ] 图表题：有没有写出**趋势或占比**（不是只抄标题）
- [ ] 图表题：数据最多 2 组，不要变成报数
- [ ] 主题句：有没有一句话说明「这幅图反映了什么现象」

### 第二段
- [ ] 三个原因是不是**三个不同角度**（经济/社会/个人）？
- [ ] 有没有**至少一处**出现题干的具体主体（不是「人们」）
- [ ] 有没有一句是「解释机制」而不只是「下判断」？

### 第三段
- [ ] 建议是不是**可执行的动作**（不是「我们应该重视」）？
- [ ] 建议主体对不对？（给大学生的建议别写「政府应完善立法」）
- [ ] 有没有重复第二段说过的话？

### 全文
- [ ] 主题词是否**始终用题干原词**（不要中途换同义词，会被判偏题）
- [ ] 有没有一句是「放之四海而皆准」的空话？有就删
- [ ] 200 词里，与这幅图/这张表**直接相关**的内容占多少？低于 40% 就是套模板
