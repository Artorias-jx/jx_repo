## 一、模块分工：谁负责哪一块（核心表）

**不要问「用哪个老师的模板」，要问「这个位置用谁的东西」。**

| 模块 | 首选 | 备选 | 为什么 |
|---|---|---|---|
| **大作文骨架**（写几句、每句干什么） | D-KK 空卡 343 法 | D-CR 柴荣段落结构 | 空卡 10 句最省事；柴荣结构最清晰 |
| **大作文思路**（每句给什么内容） | D-AI AI归来 | D-DD 大道至简 | AI归来逐句待选 + 真题套用，可迁移性最强 |
| **大作文语料**（句子怎么说好听） | D-WJT 王晶婷食材库 | D-DD 大道至简范文 | 王晶婷小众不撞车；大道至简贴真题 |
| **大作文拔高**（尾段一句定档次） | D-MK monkey 金句 | — | 外刊来源，质量高于市面模板 |
| **大作文提纲**（考场 30 秒定三段） | D-CR 柴荣角度清单 | — | 9 个角度 + 5 种论证方法，专治卡壳 |
| **小作文骨架** | X-MK monkey 9 句 | X-KK 空卡 6 句 | monkey 有决策流程；空卡最快 |
| **小作文题型判断** | X-CR 柴荣分类表 | — | 4 类 + 考频，能定优先级 |
| **小作文字数** | X-JT 晶婷（6 行×9–12 词） | 基线 95–115 词 | 唯一给量化标准的 |
| **小作文语料** | X-WJT 王晶婷 | X-CR 柴荣动名词搭配 | 换词换句用 |
| **小作文格式** | X-KK 空卡 | X-AI AI归来 | 标题/日期/落款规范 |

### 一句话版本
```
大作文 = 空卡的骨架 + AI归来的思路 + 王晶婷/大道至简的语料 + monkey 的一句拔高
小作文 = monkey 的决策 + 王晶婷的句子 + 空卡的格式 + 晶婷的字数
```

**注意**：这是「取用关系」，不是「混着背」。**同一功能位只能有一个来源**，否则考场会犹豫。

## 二、三套组合方案（选一套，别改）

### 方案 A · 稳妥型（推荐，8 周）

| 周 | 任务 | 产出 |
|---|---|---|
| 1 | 背 D-KK 空卡 10 句框架，默写 3 遍 | 一张「我的 10 句」纸 |
| 2 | D-AI 第一段：图表 1 套 + 图画 1 套，各固定 1 句 | 2 个开头模板 |
| 3 | D-AI 第二段：过渡句 1 + 原因位 3 + 连接词 5 | 二段模板 |
| 4 | D-AI 第三段 + D-CR 角度清单 | 三段模板 + 提纲卡 |
| 5 | D-WJT 替换：每个功能位换 1 个进阶句 | 自己的最终版模板 |
| 6 | D-DD 挑 4 篇同类真题，仿写 + 对照 | 4 篇成品 |
| 7 | 限时成套（大 25 min / 小 15 min），每周 3 套 | 6 套限时卷 |
| 8 | 只做默写 + 改错，不碰新模板 | 定型 |

**小作文同步**：每周 2 篇，用 X-MK 五问定结构，X-WJT 取句，X-JT 卡字数。

### 方案 B · 抢救型（4–6 周，时间紧/基础弱）

**只做三件事**：
1. 空卡 10 句背熟（第 1 周）
2. 柴荣小作文题型表看一遍，每类写 1 篇（第 2 周）
3. 每周 3 篇大 + 3 篇小，全部限时（第 3 周起）

**禁止**：开第二套模板、看新资料、背范文。**这个阶段换模板 = 自杀。**

### 方案 C · 冲高分（10–12 周，目标 16+）

| 阶段 | 主线 | 辅线 |
|---|---|---|
| 1–4 周 | D-DD 大道至简 8 篇仿写（每篇背—默—套写） | D-AI 逐句打磨 |
| 5–8 周 | D-DD 剩余 7 篇 + D-WJT 语料升级 | D-MK 每篇加 1 句 |
| 9–10 周 | 限时成套 + 自我批改 | 柴荣角度清单查漏 |
| 11–12 周 | 只默写，定型 | — |

## 三、「多套多练」的具体做法（这是提分的唯一路径）

### 3.1 一题多写（最有效）
同一个题目写 **3 遍**，每遍只改一个变量：

| 遍次 | 只改什么 | 目的 |
|---|---|---|
| 第 1 遍 | 不限时，把骨架填满 | 验证模板能不能用 |
| 第 2 遍 | 换三个原因的角度 | 练「同一个题不同写法」 |
| 第 3 遍 | 限时 25 分钟，换开头句 | 练考场状态 |

> 写 3 个题目各 1 遍 < 写 1 个题目 3 遍。**前者练的是「见过」，后者练的是「会用」。**

### 3.2 模板压力测试（每套模板必做）
拿这套模板去套这 5 道题，任何一道套不顺，模板就有洞：

| 题 | 考什么 |
|---|---|
| 2011 旅程之「余」 | 消极现象 |
| 2019 爬山（途中 vs 山顶） | 对比型图画 |
| 2021 传统文化（戏曲） | 积极现象 |
| 2024 图画+图表 | 混合题型 |
| 2025 家用电器（图表） | 纯图表 |

### 3.3 背—默—改 三步
```
背：只背自己固定的 10 句，不背范文
默：不看原文，计时默写（大 20 min / 小 12 min）
改：对照自己的模板卡，看哪句漏了、哪句写歪了
```
> 默写比背诵重要。**能默出来才算会，能背出来只是眼熟。**

### 3.4 建立「错句本」
每次写完，只记三类错误：
1. 语法错（时态、主谓、单复数）
2. 搭配错（介词、动词搭配）
3. 切题错（写了与题目无关的内容）

**每类每周统计一次，看哪类在减少。** 不减少说明练法有问题。

## 四、每类模板的打磨方向（汇总速查）

### 小作文

| 来源 | 必须改的地方 | 改成什么 |
|---|---|---|
| 柴荣 | `In the first place / What is more / Finally` | `To begin with / More importantly / Last but not least` |
| 柴荣 | 九类模板的填空 | 每个空必须落题干原词，不许写 `sth` |
| monkey | `on Zhihu Community`、`mostly like to mention` | `on social platforms`、`would like to highlight` |
| monkey | 三条并列 | 改成「时间→内容→要求」的递进，不是同质罗列 |
| AI归来 | 60% 的句子 | 保留结构，句子重写（撞车率最高） |
| 空卡 | 6 句 | 扩到 8 句（信息点多的题必须扩） |
| 空卡 | 万能建议句 | 按题干主体改（给留学生别写「政府立法」） |
| 晶婷 | 中文句模 | 只用量化标准，不直译 |
| 王晶婷 | 每功能位 3+ 个版本 | 只留 2 个（安全版 + 进阶版） |

### 大作文

| 来源 | 必须改的地方 | 改成什么 |
|---|---|---|
| 空卡 | 每段第一句 | 加题干关键词，变成主题句 |
| 空卡 | 二段最空的那条原因 | 换成题干场景的具体现象 |
| 空卡 | `Only in this way can we...` | 删掉，换具体动作 |
| 柴荣 | 9 个角度 | 每次只用 3 个，且含 1 个「个人/家庭」层面 |
| 柴荣 | 「憧憬未来」 | 改成可执行动作 |
| AI归来 | 88 页所有待选句 | 每个句位只固定 1 句，其余划掉 |
| AI归来 | 图表数据 | 200 词里最多 2 组 |
| 晶婷 | 中文句模 | 只取思路和字数，不直译 |
| 王晶婷 | 闪光词 | 一篇不超过 3 个 |
| 王晶婷 | 进阶句 | 必须自己套过一个真题才算掌握 |
| 大道至简 | 226 词范文 | 降到 190 词再用 |
| 大道至简 | 整篇 | 每篇只摘 3 句 |
| monkey | 全部 | 一篇最多 2 句，且必须与主题对得上 |
| monkey | 带美国人名/制度的句子 | 改成通用表达 |

### 通用三条
1. **每套模板必须有一句「只有你能写出来」的句子**（自己的生活例子）
2. **每个功能位只留一个版本**，多版本 = 考场犹豫
3. **改完必须重新套 2 个真题验证**，否则等于没改

## 五、真实人工评分中的「切题」注意事项

> 阅卷现实：一篇作文平均看 **13–15 秒**。第一眼看字数/段落，第二眼看每段第一句，第三眼看有没有跑题。

### 5.1 阅卷老师实际在看什么

| 顺序 | 看什么 | 影响 |
|---|---|---|
| 1 | 卷面（字迹、涂改、行数） | 印象分，实际影响 1–2 分 |
| 2 | 分段（是不是三段） | 少于三段直接降档 |
| 3 | 每段第一句 | 决定「有没有结构」 |
| 4 | 主题词 | 主题词错 = 判偏题，直接掉两档 |
| 5 | 有没有明显语法错 | 3 处以上严重错误降档 |
| 6 | 有没有亮点句 | 决定能不能上 16+ |

### 5.2 切题五条红线

| 红线 | 说明 | 后果 |
|---|---|---|
| **主题词跑偏** | 图画是「合作」，你写「坚持」 | 判偏题，10 分以下 |
| **只描述不点题** | 首段写了 3 句图，没说这幅图反映什么 | 内容分砍半 |
| **二段答非所问** | 题目问「为什么」，你写「怎么办」 | 二段基本不得分 |
| **小作文漏要点** | 题干要求 3 点，只写 2 点 | 每漏一点扣 2 分左右 |
| **套模板痕迹过重** | 通篇万能句，与题干无关 | 判「套作」，内容分很低 |

### 5.3 不同题型的切题要点

**图画作文（英一主流）**
- 必须先说清「对比在哪」：2019 爬山（途中泄气 vs 山顶继续）、2021 戏曲（喜欢 vs 不了解）
- 寓意句要一句话点破，不要绕
- 不要过度解读：图画说什么就写什么，别引申到无关话题

**图表作文（2025 起必须会）**
- 动态图写「趋势」，静态图写「占比」，别搞反
- 数据 2 组足够，多了像报账
- 必须有一句「这组数据说明了什么」

**小作文**
- 题干给的 3 个信息点，**一个都不能漏**
- 格式错（书信加标题、告示没日期）直接扣分
- 语气要对：给教授写信不能太随意，给朋友不能太正式

### 5.4 一个反直觉的事实
> **语言漂亮但偏题的作文，分数低于语言平淡但切题的作文。**
> 阅卷是按「内容 + 语言 + 结构」三项打分，内容跑偏的话，语言分再高也补不回来。

## 六、批改软件与 AI 打分：只能当参考

### 6.1 它们能做什么

| 能做 | 不能做 |
|---|---|
| 查语法错（时态、主谓一致、单复数） | 判断是否切题 |
| 查拼写 | 判断寓意抓得准不准 |
| 查搭配是否地道 | 判断二段是否答非所问 |
| 统计词数、句长、词汇多样性 | 判断「这句话和图有关系吗」 |
| 给出词汇升级建议 | 给出可靠的绝对分数 |

### 6.2 三个已知偏差

1. **分数不稳定**：同一篇作文，不同时间/不同工具给出的分可能差 **2–3 分**。看趋势，不看绝对值。
2. **偏爱长句和难词**：AI 倾向给「复杂但可能写错」的句子更高评价，而真实阅卷恰恰相反（王晶婷：「简单且正确的句子，得分一定比复杂却写错的句子要高」）。
3. **完全不看切题**：把所有主题词替换成另一个话题，AI 分数可能几乎不变——这正说明它判不了切题。

### 6.3 正确用法（三步）

```
第 1 步  用 AI 查硬伤：语法、拼写、搭配。逐条改，别嫌烦。
第 2 步  用人工标准查切题：拿「切题检查表」（02 文件末尾）自己过一遍。
第 3 步  用范文对照：和大道至简 / 王晶婷的同题材范文比，看差在哪。
```

**判断进步的正确指标**（不是 AI 分数）：
- 限时内能不能写完（大 25 min / 小 15 min）
- 语法错从几处降到几处
- 二段能不能稳定给出 3 个不同角度
- 首段能不能一句话点破寓意

### 6.4 一句话
> **AI 是你的语法老师，不是你的阅卷老师。**

## 八、最后三条

1. **模板的数量和分数成反比。** 背 8 套不如把 1 套套 8 遍。
2. **改模板的时间要花在「删」上，不是「加」上。** 每加一句，就要删一句。
3. **考前两周停止一切输入。** 只默写、只改错、只看自己的模板卡。
