## 三、每套卷子的三步流程

### 第 1 步 · 评分

**客观题（1–16 题，共 80 分）—— 你自己对答案**

- 你对完答案后，把**错的题号 + 你当时写的是什么**发我即可，全对就说一句「客观题全对」。
- 我负责：归因（K/M/C/R/T）、写进错题本、统计客观题失分。对的题不用发。

**解答题（17–22 题，共 70 分）—— 分大题发我**

- 一次发 1–2 题（一题一图最佳），标清题号。
- 我按评分细则逐题批改，写明每一步的得分与扣分点。

**拍照要求**

- 用手机横拍或竖拍都行，但要**正着拍**（别把照片拍成躺倒的）。
- **一页一图**，不要两三页挤在一张里。挤在一起时我为了看清笔迹要反复裁剪放大，慢且容易误读。
- 保证题干和笔迹都在画面内、不反光、不遮挡。

**答案 / 评分细则**

- 发我一次就能复用；分题发时注明是哪一年的即可。

### 第 2 步 · 错题归因

- 我从评分报告中列出全部非满分题，**逐条追问**：当时怎么想的？卡在哪一步？是没想到还是算错了？
- **你答** → 我把你的原话提炼成「错因」，写进 `20XX年/错题本.md`
- 每题都要落到**可执行的动作**，不接受「粗心」「马虎」这类标签

### 第 3 步 · 复盘计划

- 依据错因分布，给出：优先级排序、当天 / 次日 / 一周内的具体动作、需回补的知识点清单
- 写进 `20XX年/评分报告.md` 末节

## 四、评分口径（事先说死，不中途放宽）

1. 按数一评分标准给分，**过程分与结果分分开计**，该扣就扣。
2. 全卷所有失分归入五类，不允许模糊标签：

| 代号 | 类别  | 判断依据                  |
| -- | --- | --------------------- |
| K  | 知识性 | 概念、公式、定理本身不熟或记错       |
| M  | 方法性 | 知识点会，但想不到用哪个方法 / 不会构造 |
| C  | 计算性 | 思路对，中途算错、抄错、漏项        |
| R  | 审题性 | 看错条件、漏看限定、答非所问        |
| T  | 时间性 | 会做但没时间做完 / 被迫跳过       |

1. 每道错题在错题本里必须写明：**下次遇到同类题，第一步做什么**。

## 五、复盘方法（通用 SOP，每套卷子都照此执行）

评分报告出来后，按下面顺序过，不要跳步：

1. **先看「本该拿分却丢的题」** —— 即归为 C / R / T 的题。这类是提分最快的部分，占比往往最大。
2. **再看 M 类** —— 抄写标准解法的**关键决策点**（不是抄全过程），只记「看到什么条件 → 想到什么方法」。
3. **最后看 K 类** —— 回到笔记 / 教材补概念，并当场做 2 道同考点基础题验证。
4. **隔一天重做**：把全卷错题重做一遍（不看答案），做对的划掉，仍错的升级为「顽固错题」。
5. **一周后抽检**：从错题本随机抽 3 题重做。仍错 → 说明当时没真懂，重新归因。
