## 三、每套卷子的三步流程

### 第 1 步 · 评分

**客观题 —— 你自己对答案**

> 题号区间**逐年不同**：**2010–2020** 是选择 1–8（4 分×8）＋ 填空 9–14（4 分×6），**共 56 分**；**2021–2026** 是选择 1–10（5 分×10）＋ 填空 11–16（5 分×6），**共 80 分**。批改前先确认本年度结构。

- 你对完答案后，把**错的题号 + 你当时写的是什么**发我即可，全对就说一句「客观题全对」。
- 我负责：归因（K/M/C/R/T）、写进错题本、统计客观题失分。对的题不用发。

**解答题 —— 分大题发我**

> **2010–2020** 是 15–23 题（共 94 分）；**2021–2026** 是 17–22 题（共 70 分）。

- 一次发 1–2 题（一题一图最佳），标清题号。
- 我按评分细则逐题批改，写明每一步的得分与扣分点。

**拍照要求**

- 用手机横拍或竖拍都行，但要**正着拍**（别把照片拍成躺倒的）。
- **一页一图**，不要两三页挤在一张里。挤在一起时我为了看清笔迹要反复裁剪放大，慢且容易误读。
- 保证题干和笔迹都在画面内、不反光、不遮挡。

**原卷 / 答案（用后即弃，不入库）**

- 原卷题干、答案 / 评分细则发我用于批改即可，**不会存进仓库**。
- 同一个年份的答案发一次就够我复用；分题发时注明是哪一年即可。

### 第 2 步 · 错题归因

- 我从评分报告中列出全部非满分题，**逐条追问**：当时怎么想的？卡在哪一步？是没想到还是算错了？
- **你答** → 我把你的原话提炼成「错因」，写进 `20XX年/错题本.md`
- 每题都要落到**可执行的动作**，不接受「粗心」「马虎」这类标签

### 第 3 步 · 复盘计划

- 依据错因分布，给出：优先级排序、**第一天 / 第二天**的具体动作、需回补的知识点清单
- 写进 `20XX年/评分报告.md` 末节

### 第 4 步 · 阶段复盘（两段各一次）

- 触发时机（2026-09-20 改）：
  - **段① 21 之前** —— **三本书 ＋ 大观严选题过完一轮**时出 → `复盘/复盘-1（21之前）.md`
  - **段② 21 及之后** —— **21–26 全部套卷评分归因完毕**时出（**全库收官**）→ `复盘/复盘-2（21之后）.md`
- 固定内容：**失分类型分布（本段合计）→ 漏洞收敛表（跨套）→ 错题抽检（随机 3 题）→ 补漏进度 → 阶段结论**
- 「漏洞收敛表」用三档标记：🔴 反复失分（≥2 套）／🟡 已补但未验证／🟢 已收敛（连续 2 套不再失分），并**每条注明「去哪儿补」**（大观严选题 / 三本书 / 自有专项库）
- 材料映射总表见 [[复盘/复盘总纲|🧭 复盘总纲]]

## 四、评分口径（事先说死，不中途放宽）

1. 按数一评分标准给分，**过程分与结果分分开计**，该扣就扣。
2. 全卷所有失分归入五类，不允许模糊标签：

| 代号 | 类别  | 判断依据                  |
| -- | --- | --------------------- |
| K  | 知识性 | 概念、公式、定理本身不熟或记错       |
| M  | 方法性 | 知识点会，但想不到用哪个方法 / 不会构造 |
| C  | 计算性 | 思路对，中途算错、抄错、漏项        |
| R  | 审题性 | 看错条件、漏看限定、答非所问        |
| T  | 时间性 | 会做但没时间做完 / 被迫跳过       |

3. **每道错题固定四段，顺序不能换**（2026-09-17 定）：
   **① 知识点是什么 → ② 为什么错 → ③ 出题人为什么这么出 → ④ 操作手法 · 条件反射**
   - **「条件反射」写成能背的短句**，格式统一为 **「见到 ___ ⇒ 立刻 ___」**。示例：「见到**不等式证明** ⇒ 无脑夹逼」「见到**二阶及以上导数** ⇒ 想泰勒」「见到**闭曲线积分** ⇒ 想格林 / 斯托克斯」。
   - ⚠️ **但只收「不容易自己发现」的**（2026-09-17 定）—— 收录范围：**① 反直觉的判据 / 结论；② 题干的伪装；③ 会导致全题归零的第一步判断；④ 自己踩过的动作习惯。**
     **不收**：教科书标准流程（"夹逼""泰勒""写增广矩阵""分布函数法"）；**以及"见弧长⇒弧长公式"这类字面自指的废话**。
     **每本控制在 5–7 条** —— 多了就没人看了。
   - 每本错题本末尾附一张**跨题的条件反射总表**（考前扫一遍）。
   - 模板：`_模板/错题本模板.md`。
4. **每本错题本顶部必须有「🔁 跨套同类索引」**（2026-09-17 定）—— 逐题回答「**这个坑以前踩过吗**」：标出往期同类题号、累计次数，判读只允许三种 —— **首现 / 🔴 反复失分（附本卷是第几次）/ 🔴 复发（同一错法第 2 次）**。这是判"要不要开专项"的依据。
5. **C / R / T 类失分必须逐条登记到 [[非知识性错误总表]]** —— 同一错法第 2 次出现标 🔴 复发，同一"失误环节"累计 3 条就开专项。K / M 类不进那张表。

## 五、复盘方法（通用 SOP，每套卷子都照此执行）

所以 `评分报告.md` 的复盘计划按「**第一天 / 第二天**」两段写，**不写「一周内 / 一周后」这类远期清单**（会堆积成空头支票）。

> [!important] 第二天去哪儿刷（2026-09-20 定）
> **不再笼统写「刷本卷错得最多的模块」，要落到具体材料：**
>
> | 本卷失分集中在 | 第二天去哪儿 | 错题入库页 |
> | --- | --- | --- |
> | 线代 | 三本书（**A / C**）· 线代 | `专项/线代·分类书错题精选.md` |
> | 概率 | 三本书（**A / C**）· 概率 | `专项/概率·分类书错题精选.md` |
> | 高数（非三重线面） | **大观严选题** 对应章节 | `专项/高数·大观严选题错题精选.md` |
> | 三重积分 / 线面积分 | **自有收口页**（全部来源的错题入此页） | `专项/三重线面专项错题精析.md` |
>
> 完整刷法细则见 [[复盘/复盘总纲|🧭 复盘总纲]] §二、§四。

评分报告出来后，按下面顺序过，不要跳步：

1. **先看「本该拿分却丢的题」** —— 即归为 C / R / T 的题。这类是提分最快的部分，占比往往最大。
2. **再看 M 类** —— 抄写标准解法的**关键决策点**（不是抄全过程），只记「看到什么条件 → 想到什么方法」；**并顺手把它提炼成一条条件反射**（「见到 ___ ⇒ 立刻 ___」），填进错题本末尾的总表。
3. **最后看 K 类** —— 回到笔记 / 教材补概念，并当场做 2 道同考点基础题验证。
4. **第二天重做 + 定点补漏**：把全卷错题重做一遍（不看答案、限时），做对的划掉，仍错的升级为「顽固错题」；然后**按上表去刷对应材料**，刷出的新错题入对应专项页。
5. **抽检**：从**上一套**的错题本随机抽 3 题重做（放在下一套的第二天）。仍错 → 说明当时没真懂，重新归因。阶段复盘时再集中抽检一次。
