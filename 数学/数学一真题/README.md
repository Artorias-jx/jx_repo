## 二、文件命名约定

| 材料 | 存放位置 | 命名示例 |
| --- | --- | --- |
| 我的答题卡 | `20XX年/我的作答/` | `2021-作答-01.jpg` |
| 订正版（重做后） | `20XX年/我的作答/` | `2021-订正-01.jpg` |

> **原卷和答案不入库** —— 它们只发给我用于评分，用完即弃；仓库里只保留你的答题卡。
> **单题特写不入库** —— 只拍某一道题局部（用于批改）的图同样用完即弃，仓库里只存**整页答题卡**。
> **订正图只存档，不做文字核对** —— 订正版照片存进 `20XX年/我的作答/` 即完成记录，不再另写「订正核对」正文（2026-09-13 定）。
> **专项练习错题另起一页** —— 「第二天」刷专项时做错的题，归到 `专项/` 下**按考点命名**的文件（如 `线面积分专项错题精析.md`），**不混进套卷的 `错题本.md`**（2026-09-14 定）。
> **配套的理论速查 / 方法论也放 `专项/`** —— 与错题精析同目录，便于对照（如 `梯度·散度·旋度与线面公式.md`，2026-09-16 定）。
> 你只需把图片直接发到对话里，存盘、重命名、归位由 buddy 完成，你不用手动整理。

## 三、每套卷子的三步流程

### 第 1 步 · 评分

**客观题 —— 你自己对答案**

> 题号区间**逐年不同**：**2010–2020** 是选择 1–8（4 分×8）＋ 填空 9–14（4 分×6），**共 56 分**；**2021–2026** 是选择 1–10（5 分×10）＋ 填空 11–16（5 分×6），**共 80 分**。批改前先确认本年度结构。

- 你对完答案后，把**错的题号 + 你当时写的是什么**发我即可，全对就说一句「客观题全对」。
- 我负责：归因（K/M/C/R/T）、写进错题本、统计客观题失分。对的题不用发。

**解答题 —— 分大题发我**

> **2010–2020** 是 15–23 题（共 94 分）；**2021–2026** 是 17–22 题（共 70 分）。

- 一次发 1–2 题（一题一图最佳），标清题号。
- 我按评分细则逐题批改，写明每一步的得分与扣分点。

**拍照要求**

- 用手机横拍或竖拍都行，但要**正着拍**（别把照片拍成躺倒的）。
- **一页一图**，不要两三页挤在一张里。挤在一起时我为了看清笔迹要反复裁剪放大，慢且容易误读。
- 保证题干和笔迹都在画面内、不反光、不遮挡。

**原卷 / 答案（用后即弃，不入库）**

- 原卷题干、答案 / 评分细则发我用于批改即可，**不会存进仓库**。
- 同一个年份的答案发一次就够我复用；分题发时注明是哪一年即可。

### 第 2 步 · 错题归因

- 我从评分报告中列出全部非满分题，**逐条追问**：当时怎么想的？卡在哪一步？是没想到还是算错了？
- **你答** → 我把你的原话提炼成「错因」，写进 `20XX年/错题本.md`
- 每题都要落到**可执行的动作**，不接受「粗心」「马虎」这类标签

### 第 3 步 · 复盘计划

- 依据错因分布，给出：优先级排序、**第一天 / 第二天**的具体动作、需回补的知识点清单
- 写进 `20XX年/评分报告.md` 末节

### 第 4 步 · 块末复盘（每 5–6 套一次）

- 一块（5–6 套）**全部评分归因完毕**后，buddy 汇总出一份阶段复盘，写进 `复盘/复盘-N（年份区间）.md`
- 固定四块内容：**失分类型分布（本块合计）→ 漏洞收敛表（跨套）→ 错题抽检（随机 3 题）→ 下一块重点**
- 「漏洞收敛表」用三档标记：🔴 反复失分（≥2 套）／🟡 已补但未验证／🟢 已收敛（连续 2 套不再失分）
- 触发时机：本块**最后一套的「第二天」刷题完成**时

## 四、评分口径（事先说死，不中途放宽）

1. 按数一评分标准给分，**过程分与结果分分开计**，该扣就扣。
2. 全卷所有失分归入五类，不允许模糊标签：

| 代号 | 类别  | 判断依据                  |
| -- | --- | --------------------- |
| K  | 知识性 | 概念、公式、定理本身不熟或记错       |
| M  | 方法性 | 知识点会，但想不到用哪个方法 / 不会构造 |
| C  | 计算性 | 思路对，中途算错、抄错、漏项        |
| R  | 审题性 | 看错条件、漏看限定、答非所问        |
| T  | 时间性 | 会做但没时间做完 / 被迫跳过       |

3. 每道错题在错题本里必须写明：**下次遇到同类题，第一步做什么**。
4. **C / R / T 类失分必须逐条登记到 [[非知识性错误总表]]** —— 同一错法第 2 次出现标 🔴 复发，同一"失误环节"累计 3 条就开专项。K / M 类不进那张表。

## 五、复盘方法（通用 SOP，每套卷子都照此执行）

**节奏：两天一套** —— **第一天**写卷 + 复盘（复盘 60–90 分钟）；**第二天**只刷「本卷错得最多的模块」，
所以 `评分报告.md` 的复盘计划按「**第一天 / 第二天**」两段写，**不写「一周内 / 一周后」这类远期清单**（会堆积成空头支票）。

评分报告出来后，按下面顺序过，不要跳步：

1. **先看「本该拿分却丢的题」** —— 即归为 C / R / T 的题。这类是提分最快的部分，占比往往最大。
2. **再看 M 类** —— 抄写标准解法的**关键决策点**（不是抄全过程），只记「看到什么条件 → 想到什么方法」。
3. **最后看 K 类** —— 回到笔记 / 教材补概念，并当场做 2 道同考点基础题验证。
4. **第二天重做**：把全卷错题重做一遍（不看答案、限时），做对的划掉，仍错的升级为「顽固错题」；再按失分排序刷同考点新题。
5. **抽检**：从**上一套**的错题本随机抽 3 题重做（放在下一套的第二天）。仍错 → 说明当时没真懂，重新归因。块末复盘时再集中抽检一次。
