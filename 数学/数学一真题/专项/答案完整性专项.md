## 二、两个子类型

### 子类型 A · 漏「全集」 —— 答案是「族 / 集」，只写了一个代表

| 项 | 内容 |
| --- | --- |
| **实例** | 2015·20(2)（求所有 $\xi$）、2011·21(1)（求所有特征向量）、**大观严选题 · 不定积分（漏 $C$）** |
| **长什么样** | ① 题干有**数量词**（所有 / 任意 / 至少 / 唯一 / 至多 / 恰有）；② 问**通解 / 全部解 / 基础解系 / 特征向量**；③ **它是不定积分**（哪怕一个字都没提"所有"） |
| **你做了什么** | 方程解对了 / 原函数算对了，但**只写出一个特解、一个具体向量、一个原函数**就收笔 |
| **正确形式** | 齐次解 ⇒ **基础解系 × 任意常数**；特征向量 ⇒ **$k_i(\cdot)$，$k_i\ne0$**；含参 ⇒ **把参数范围写全**（别漏 $c\ne0$）；**不定积分 ⇒ 末尾必写 $+C$** |
| **为什么容易漏** | 算完时心理上"答完了" —— **数量词与常数都是「形式要求」，不参与计算**，不刻意去对，就一定会漏 |

> **判据一句话**：**答案的形式必须与题干的数量词一致。** 问"所有"就给族，问"一个"才给特解。
> **补充**：**不定积分是"函数族"，不是"一个函数"** —— 凡 $\int f(x)dx$，答案天生带 $+C$（定积分才不带）。

### 子类型 B · 漏「前提」 —— 定理的适用条件没验证就动手

| 项 | 内容 |
| --- | --- |
| **实例** | 2013·16（逐项求导前没证收敛半径） |
| **长什么样** | 你用了某个定理/公式/交换（逐项求导·逐项积分、洛必达、等价无穷小替换、积分中值、格林/高斯/斯托克斯、含参积分号下求导…） |
| **你做了什么** | 直接动手算，**没写"满足什么条件所以可以用"** |
| **正确形式** | 动手**之前**先补一句前提验证（如"由 $\lim\frac{a_{n+1}}{a_n}=0$ 得 $R=+\infty$，故可在 $(-\infty,+\infty)$ 上逐项求导"） |
| **为什么容易漏** | 形式上"移项即得"，**看起来不需要理由** —— 命题人正是利用这个错觉设陷阱 |

> **判据一句话**：**凡是"把算符搬进去"（求和号 ↔ 求导/积分号、极限 ↔ 积分号…），都必须先写依据。**

## 三、共同结构（为什么这些条是同一个病）

四条表面无关（线代 2 条 ＋ 高数 2 条），但**失效的环节完全相同**：

```
算对了  →  「最后落笔」  →  少写一步
          ↑
      没有任何自检动作
```

- 题型不同 ⇒ **刷题不会自动治好它**（换个考点照样漏）。
- 唯一有效的对策是**机械化自检**：交卷前用固定清单扫一遍，而不是"下次注意"。

## 五、交卷前 30 秒自检（**唯一真正能防住它的动作**）

> 不是"下次注意"，是**固定的五问**。每道大题收笔后扫一遍，全卷最后再扫一遍。

1. **数量词**：题干出现「所有 / 任意 / 至少 / 唯一 / 至多 / 恰有」→ **每一个都在答案里回应了吗**？
2. **参数 / 常数**：凡「求通解 / 特征向量 / 基础解系 / 全部解 / 所有」→ **带任意常数了吗**？只写一个特解＝**没答完**。**凡是不定积分 → 末尾有 $+C$ 吗**（定积分才无常数）？
3. **前提**：凡是把**算符搬进去**（求和↔求导/积分、极限↔积分、洛必达、等价替换、格林/高斯/斯托克斯）→ **前提写了吗**？
4. **范围**：解出的参数 / 收敛域 / 定义域有约束吗（$c\ne0$、$R$、收敛域端点开闭）？
5. **问了几问**：多问的题，**每一问都给结论了吗**？（2013·18(II) 就是栽在这）

> 📌 **这 30 秒是本次升级换来的唯一交付物。** 三条合计 7 分，换算成得分率就是 **4.7 个百分点**。
