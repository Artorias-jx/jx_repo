| 代号 | 类别 | 累计题数 | 占比 | 趋势 |

| C | 计算性 | 0 | 0% | **两套均为 0** |
| R | 审题性 | 0 | 0% | 两套均为 0 |
| T | 时间性 | 0 | 0% | **两套均无时间性失分** |

> 每次评分后由 buddy 更新。某一类**连续 3 套占比最高**，就说明它不是偶然失误，要单独开专项训练。
> 目前 K 类连续两套居首，占比在降（**71% → 60%**，按题数）—— 回补在起作用。**C / R / T 两套全零**：失分全部来自"不会"和"忘了"。
