## 四、失分结构分析

| 类型            | 题号                | 失分     | 占比        |
| ------------- | ----------------- | ------ | --------- |
| **K 知识性（遗忘）** | 14、17、18、20(2)、22 | **36** | **80.0%** |
| **M 方法性**     | 5、21(2)           | **9**  | **20.0%** |
| C 计算性         | —                 | 0      | 0%        |
| R 审题性         | —                 | 0      | 0%        |
| T 时间性         | —                 | 0      | 0%        |
| **合计**        |                   | **45** | 100%      |

**结论：**

1. **不是"时间不够"，是"忘了"。** 你的原话是「忘了线面积分了」「忘了概率论了」「不知道怎么动手」——20(2)、21(2)、22 丢掉的 19 分里，**没有一分是时间问题**。
2. **45 分失分里 80% 是知识遗忘。** 这和「刚结束强化」的阶段完全吻合：知识点过了一遍，但没经过真题检验，遗忘面很大。**这个阶段的真题不只是考试，更是体检——它替你标出了所有漏洞的位置。**
3. **三个"整块遗忘"是最大金矿**：曲面积分（14，5 分）+ 格林公式挖洞（20(2)，6 分）+ 概率论分布（22，12 分）= **23 分**。
4. **两处"没见过"的方法短板**：第 5 题不知道 $p+q=r(A)$；21(2) 不知道矩阵平方根走谱分解。这两处补一次就永久解决。
5. 唯一的好消息：**19 题满分、21(1) 满分**。说明你的线代功底和计算能力是在的，缺的只是覆盖面。
