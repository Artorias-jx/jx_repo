## 错题 01 · 第 3 题

#数学/模块/高数 #数学/考点/方向导数 #数学/失分/K

- **考点**：方向导数（多元函数沿指定方向的变化率）
- **失分类型**：**K 知识性**（公式遗忘）
- **当时怎么想的**：
  > 「忘记了方向导数的求法」
- **错在哪**：整题没动笔，$\nabla f$ 与方向向量的单位化都没写。
- **关键决策点**：
  看到"沿某个方向 $\boldsymbol{n}$ 的方向导数" → 固定三步：
  1. 求 $\nabla f(P)=(f_x,f_y,f_z)\big|_{P}$
  2. 单位化 $\boldsymbol{n}^{0}=\dfrac{\boldsymbol{n}}{|\boldsymbol{n}|}$
  3. 点乘 $\left.\dfrac{\partial f}{\partial \boldsymbol{n}}\right|_{P}=\nabla f(P)\cdot\boldsymbol{n}^{0}$

  本题 $f=x^{2}y+z^{2}$，$P(1,2,0)$，$\boldsymbol{n}=(1,2,2)$：
  $\nabla f=(2xy,\ x^{2},\ 2z)\big|_{(1,2,0)}=(4,1,0)$，$|\boldsymbol{n}|=3$，$\boldsymbol{n}^{0}=\frac13(1,2,2)$
  → $\dfrac{\partial f}{\partial \boldsymbol{n}}=\dfrac{4+2+0}{3}=2$ → **选 D**
- **下次遇到同类题，第一步做什么**：
  **先把 $\nabla f(P)$ 和 $\boldsymbol{n}^{0}$ 各写一行**，再点乘。不要从"方向余弦公式"开始背——那只是这三步的展开式，最容易记错。
- **是数还是向量（易混点）**：
  **方向导数是数（标量），梯度是向量。** 前者由点乘 $\nabla f(P)\cdot\boldsymbol{n}^{0}$ 给出，点乘的结果本就是标量、没有方向；$\boldsymbol{n}$ 只负责指明"沿哪个方向测"。
  1. **方向向量必须先单位化**：否则算出的是"每 $|\boldsymbol{n}|$ 长度"的变化率，比真值**大 $|\boldsymbol{n}|$ 倍**。
  2. **最大方向导数 $=|\nabla f|$**，在 $\boldsymbol{n}^{0}$ 与 $\nabla f$ **同向**时取到；**反向**取最小值 $-|\nabla f|$。
- [ ] **默写三步**：$\nabla f(P)$ → $\boldsymbol{n}^{0}=\dfrac{\boldsymbol{n}}{|\boldsymbol{n}|}$ → 点乘。

## 错题 02 · 第 18(1) 题

#数学/模块/高数 #数学/考点/极限保号性 #数学/失分/M

- **考点**：极限的局部保号性 ＋ 零点存在定理
- **失分类型**：**M 方法性**（性质知道，但推理跳步）
- **当时怎么想的**：
  > 「我知道保号性是局部，但是我想着，x 趋于 0+ 了应该也没差多远，就没写。」
- **错在哪**：
  你写的是「由 $\lim\limits_{x\to0^{+}}\dfrac{f(x)}{x}<0$ **得** $\lim\limits_{x\to0^{+}}f(x)<0$」。
  这一步**不成立**：由 $\dfrac{f(x)}{x}<0$ 只能得 $f(x)<0$ 在 $(0,\delta)$ 上**局部**成立，而 $\lim f(x)=0$ 完全可能——只要 $f(x)\sim Lx$（$L<0$）。
- **为什么"没差多远"这个想法会致命**：
  $f(x)=-x$ 就满足 $\dfrac{f(x)}{x}=-1<0$，但 $\lim\limits_{x\to0^{+}}f(x)=0$，不是负数。
  也就是说，$\dfrac{f(x)}{x}<0$ 给的信息只有"$f(x)$ 与 $x$ **异号**"，它**推不出** $f$ 的极限是负数。
  **证明题里没有"差不多"，只有"能不能由已知条件推出来"。**
- **关键决策点**：
  看到"极限的**正负号**已知，要证**零点/根的个数**" → 固定动作：
  1. 用**局部保号性取一个具体的点** $c$：$\exists\delta>0$，$x\in(0,\delta)$ 时 $\dfrac{f(x)}{x}<0$，故 $\exists c\in(0,\delta)$，$f(c)<0$
  2. 在 $[c,1]$ 上用零点定理（$f(c)<0<f(1)$）得 $\exists\xi\in(c,1)$，$f(\xi)=0$
- **下次遇到同类题，第一步做什么**：
  **凡是"由 $\lim$ 的符号 ⇒ 某点函数值的符号"，必须落地成一个具体的点 $c$ 写在卷面上。** 这一步本身就是评分点，跳了就丢分。

## 错题 03 · 第 18(2) 题

#数学/模块/高数 #数学/考点/中值定理 #数学/失分/K

- **考点**：罗尔定理反复使用、"根的个数"型证明
- **失分类型**：**K 知识性**（整块遗忘）
- **当时怎么想的**：
  > 「我没复习，已经忘了那些中值定理，还有什么证明题的定理。」
- **做到哪一步了**：
  你**写对了辅助函数** $g(x)=f(x)f'(x)$ 和**求导** $g'(x)=[f'(x)]^{2}+f(x)f''(x)$。
  这是本题**最难想到的一步**——说明"构造辅助函数"的直觉你还有，缺的是**定理本身**。所以这 4 分不是能力问题，是回补问题。
- **关键决策点（完整三步）**：
  1. **先补出 $f(0)=0$**：因为 $\dfrac{f(x)}{x}$ 的极限**存在且有限**，所以 $f(x)=x\cdot\dfrac{f(x)}{x}\to0$，又 $f$ 连续 → $f(0)=0$。
     ⚠️ 注意这一步靠的是"极限存在且有限"，**不是**保号性。
  2. **造出第三个零点**：在 $[0,\xi]$ 上对 $f$ 用**罗尔定理**（$f(0)=f(\xi)=0$）→ $\exists\eta\in(0,\xi)$，$f'(\eta)=0$，于是 $g(\eta)=f(\eta)f'(\eta)=0$。
     现在 $g$ 有三个零点：$0,\ \eta,\ \xi$。
  3. **两段罗尔**：在 $(0,\eta)$、$(\eta,\xi)$ 上**分别**用罗尔定理 → $\exists\eta_1\ne\eta_2$ 使 $g'(\eta_1)=g'(\eta_2)=0$，即 $ff''+(f')^{2}=0$ 在 $(0,1)$ 内有两个不同实根。
- **"根的个数"证明题的通用套路**（背下来）：
  > 要证"某方程有 $k$ 个根" → 找一个**辅助函数 $F$**，凑出 $F$ 的 **$k+1$ 个零点** → 用 **$k$ 次罗尔定理**。
  > $k=1$ 一般用零点定理；$k\ge2$ 基本都要"**先造零点、再罗尔**"。
- **下次遇到同类题，第一步做什么**：
  看完题目立刻问自己两句话：
  **① 要证谁的零点？→ 写出辅助函数 $F$；② 能凑出 $F$ 的几个零点？→ 决定要几次罗尔。**
  （本题：$F=ff'$，要 3 个零点 → 用 2 次罗尔）

## 错题 04 · 第 19(2) 题

#数学/模块/高数 #数学/考点/曲面积分 #数学/失分/M

- **考点**：第一类曲面积分（曲面薄片的质量）
- **失分类型**：**M 方法性**（知道有第一类曲面积分，但设错了积分类型）＋ **执行层缺口**（不会算第一类曲面积分）
- **当时怎么想的**：
  > 「M，我发现我不会算第一类曲面积分。」
- **错在哪**：
  你写成 $M=\iiint_{\Omega}\mu(x,y,z)\,dV$（$\Omega$ 取"二者的交集"），并把 $z$ 的上下限写成 $\sqrt{x^{2}+y^{2}}$ 到 $\sqrt{2x}$。
  **$S$ 是曲面薄片，不是体**，应当是 $M=\iint_{S}\mu\,dS$。
- **关键决策点**：
  看到"**薄片形体** / **壳体** / **曲面被另一曲面割下的部分**" → 立刻判定为**第一类曲面积分**（面），不是三重积分（体）。然后三步走：
  1. 代入曲面方程化简被积函数：$z=\sqrt{x^{2}+y^{2}}\Rightarrow\sqrt{x^{2}+y^{2}+z^{2}}=\sqrt2\sqrt{x^{2}+y^{2}}$
  2. 面积元素：$dS=\sqrt{1+z_x^{2}+z_y^{2}}\,dxdy=\sqrt2\,dxdy$
  3. 投影区域：$D:\ x^{2}+y^{2}\le 2x$（由第 (1) 问的投影曲线围成）→ 化极坐标

  $$M=18\iint_{D}\sqrt{x^{2}+y^{2}}\,dxdy=48\int_{-\pi/2}^{\pi/2}\cos^{3}\theta\,d\theta=96\cdot\frac23=\boxed{64}$$
- **三种积分的判别口诀**（背下来）：

| 题干里出现 | 用什么 |
| --- | --- |
| "薄片 / 壳体 / 曲面…割下的部分"、"（给定面密度的）质量" | **第一类曲面积分** $\iint_S\mu\,dS$ |
| "通量 / 穿过某曲面" | **第二类曲面积分**（多用高斯公式） |
| "围成的立体"、"（给定体密度的）质量" | **三重积分** $\iiint_\Omega\mu\,dV$ |

- **下次遇到同类题，第一步做什么**：
  **先在草稿角上写三个字——面 / 体 / 通量——圈定一个再动手。** 圈错了整题 0 分；圈对了，剩下都是套流程。

## 错题 05 · 第 23(2)(3) 题

#数学/模块/概率 #数学/考点/参数估计 #数学/失分/K

- **考点**：矩估计、最大似然估计
- **失分类型**：**K 知识性**（整块遗忘）
- **当时怎么想的**：
  > 「23 题后两问**忘了怎么写了**。」
- **做到哪一步了**：
  第 (1) 问你把 $Z_i$ 的密度写对了：$f_Z(z)=\dfrac{2}{\sqrt{2\pi}\sigma}e^{-\frac{z^{2}}{2\sigma^{2}}}\ (z\ge0)$ —— **这是本题的建模核心，你已经拿下**。第 (2)(3) 问空着。
- **关键决策点（两问都是纯套路）**：
  1. **矩估计（用一阶矩）**：先算 $E(Z_1)$，再令它等于样本均值 $\bar Z$，反解 $\sigma$。

     $$E(Z_1)=\int_{0}^{+\infty}z\cdot\frac{2}{\sqrt{2\pi}\sigma}e^{-\frac{z^{2}}{2\sigma^{2}}}dz=\frac{2\sigma}{\sqrt{2\pi}}=\sqrt{\frac2\pi}\,\sigma$$

     令 $E(Z_1)=\bar Z=\dfrac1n\sum\limits_{i=1}^{n}|X_i-\mu|$，得

     $$\hat\sigma=\sqrt{\frac\pi2}\cdot\frac1n\sum_{i=1}^{n}|X_i-\mu|$$

  2. **最大似然**：写似然函数 → 取对数 → 求导令零 → 解出。

     $$L(\sigma)=\prod_{i=1}^{n}\frac{2}{\sqrt{2\pi}\sigma}e^{-\frac{z_i^{2}}{2\sigma^{2}}}=\left(\frac{2}{\sqrt{2\pi}\sigma}\right)^{n}e^{-\frac{\sum z_i^{2}}{2\sigma^{2}}}\quad(z_i>0)$$

     $$\frac{d\ln L}{d\sigma}=-\frac n\sigma+\frac{1}{\sigma^{3}}\sum_{i=1}^{n}z_i^{2}=0\ \Longrightarrow\ \hat\sigma=\sqrt{\frac1n\sum_{i=1}^{n}Z_i^{2}}=\sqrt{\frac1n\sum_{i=1}^{n}(X_i-\mu)^{2}}$$
- **两类估计的固定套路**（背下来）：

| 题型 | 动作 |
| --- | --- |
| **矩估计** | 数未知参数个数 → 算对应的（一阶 / 二阶）总体矩 → 令"总体矩 = 样本矩" → 解方程 |
| **最大似然** | 写 $L(\theta)=\prod f(x_i;\theta)$ → 取 $\ln L$ → 对 $\theta$ 求导令零 → 解出 $\hat\theta$（先写清 $\theta$ 的取值范围） |
- **下次遇到同类题，第一步做什么**：
  **先看问的是"矩估计"还是"最大似然"，直接套上表里对应的一列流程**，不要现场推导。这两类题在真题里几乎是默写题。
- **重做状态**：☐ 未重做　☐ 已重做做对　☐ 仍错（升级为顽固错题）
