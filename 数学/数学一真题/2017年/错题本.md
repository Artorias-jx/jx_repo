## 错题 01 · 第 3 题

#数学/模块/高数 #数学/考点/方向导数 #数学/失分/K

**题**　求 $f=x^{2}y+z^{2}$ 在点 $P(1,2,0)$ 沿方向 $\boldsymbol n=(1,2,2)$ 的方向导数。
**答案**　$2$（选 D）　｜　**得分**　**0 / 4**　｜　**失分类型**　**K 知识性**

### ① 知识点是什么

- **方向导数**：$\left.\dfrac{\partial f}{\partial\boldsymbol n}\right|_{P}=\nabla f(P)\cdot\boldsymbol n^{0}$，其中 $\boldsymbol n^{0}=\dfrac{\boldsymbol n}{|\boldsymbol n|}$
- **梯度**：$\nabla f=(f_x,\ f_y,\ f_z)$
- ⚠️ **易混点**：**方向导数是数（标量）**，梯度是向量；$\boldsymbol n$ 只负责指明"沿哪个方向测"
- **方向向量必须先单位化**，否则算出来的是"每 $|\boldsymbol n|$ 长度"的变化率，比真值**大 $|\boldsymbol n|$ 倍**
- 最大方向导数 $=|\nabla f|$（$\boldsymbol n^0$ 与 $\nabla f$ 同向）；反向取最小 $=-|\nabla f|$

### ② 为什么错

- **你的原话**：
  > 「**忘记了方向导数的求法。**」
- **你的做法**：**整题没动笔** —— $\nabla f$ 与方向向量的单位化都没写。
- **正确做法**（固定三步）：
  1. $\nabla f=(2xy,\ x^{2},\ 2z)\big|_{(1,2,0)}=(4,1,0)$
  2. $|\boldsymbol n|=3$ ⇒ $\boldsymbol n^{0}=\dfrac13(1,2,2)$
  3. 点乘：$\dfrac{\partial f}{\partial\boldsymbol n}=\dfrac{4+2+0}{3}=2$
- **差在哪**：**公式遗忘**（K）—— 位置靠前的选择题，本来是送分题。

### ③ 出题人为什么这么出

- 把一个**纯公式题**放在选择题第 3 题 ⇒ 考"**基本公式有没有背下来**"。
- $\boldsymbol n=(1,2,2)$ **故意不是单位向量**（$|\boldsymbol n|=3$ 好算）⇒ 专门测你会不会**忘了单位化**。
- 三个分量都非零 ⇒ 逼你老老实实算点乘，不能靠"某项为 0"蒙。
- 正确答案是 $2$，若忘了单位化会得 $6$ —— **专门设的陷阱值**。

### ④ 操作手法 · 条件反射

| 见到 | 立刻做 |
| --- | --- |
| 「沿某个方向 $\boldsymbol n$ 的**方向导数**」 | 固定三步：$\nabla f(P)$ → **单位化** $\boldsymbol n^{0}$ → 点乘 |
| 给的方向向量**不是单位向量** | **先除以模长**，否则结果偏大 $|\boldsymbol n|$ 倍 |
| 「**最大**方向导数」 | $=|\nabla f|$；反向 ⇒ $-|\nabla f|$ |
| 要从"方向余弦公式"起步 | **停** —— 那只是三步的展开式，最容易记错 |

- **重做状态**：☐ 未重做　☐ 已重做做对　☐ 仍错（升级为顽固错题）

## 错题 02 · 第 18(1) 题

#数学/模块/高数 #数学/考点/极限保号性 #数学/失分/M

**题**　由 $\lim\limits_{x\to0^{+}}\dfrac{f(x)}{x}<0$ 证明 $f(x)$ 在某个区间内有零点。
**答案**　见下　｜　**得分**　**2 / 4**　｜　**失分类型**　**M 方法性**

### ① 知识点是什么

- **极限的局部保号性** —— 注意"**局部**"两个字：只保证在 $(x_0-\delta,\ x_0+\delta)$ 内
- **零点存在定理**
- 反例的作用：$f(x)=-x$ 就满足 $\dfrac{f(x)}{x}=-1<0$，但 $\lim\limits_{x\to0^{+}}f(x)=0$ —— 说明 $\dfrac{f(x)}{x}<0$ 只给出"**$f$ 与 $x$ 异号**"，**推不出** $f$ 的极限是负数

### ② 为什么错

- **你的原话**：
  > 「**我知道保号性是局部，但是我想着，$x$ 趋于 $0^{+}$ 了应该也没差多远，就没写。**」
- **你的做法**：写了「由 $\lim\limits_{x\to0^{+}}\dfrac{f(x)}{x}<0$ **得** $\lim\limits_{x\to0^{+}}f(x)<0$」—— **这一步不成立**。
- **正确做法**：
  1. **用局部保号性取一个具体的点 $c$**：$\exists\delta>0$，$x\in(0,\delta)$ 时 $\dfrac{f(x)}{x}<0$，故 $\exists c\in(0,\delta)$ 使 $f(c)<0$
  2. 在 $[c,1]$ 上用**零点定理**（$f(c)<0<f(1)$）⇒ $\exists\xi\in(c,1)$，$f(\xi)=0$
- **差在哪**：**推理跳步** —— 知道性质是"局部"，但**没把它落地成一个具体的点**。证明题里没有"差不多"，只有"能不能由已知推出来"。

### ③ 出题人为什么这么出

- 题干给的是**极限的符号**，要证的是**零点的存在** ⇒ 命题人就是要在两者之间架桥，而**这座桥必须由局部保号性搭**。
- 用 $\dfrac{f(x)}{x}$（而不是直接用 $f$）⇒ **故意做一层"异号"伪装**，专门抓"从极限符号直接跳到函数值符号"的人。
- **"取点 $c$"这一步本身就是评分点**，跳了直接丢分（你正是丢在这里）。

### ④ 操作手法 · 条件反射

| 见到 | 立刻做 |
| --- | --- |
| 「由 $\lim$ 的**符号** ⇒ 某点函数值的符号」 | **必须落地成一个具体的点 $c$** 写在卷面上 |
| 想用保号性 | 先念一遍"**局部**" —— 它不保证极限值，只保证邻域内 |
| 要证零点存在 | 用零点定理，**先凑出两个异号的函数值** |
| 想出"差不多/没差多远" | **打住** —— 证明题只认推理链 |

- **重做状态**：☐ 未重做　☐ 已重做做对　☐ 仍错（升级为顽固错题）

## 错题 03 · 第 18(2) 题

#数学/模块/高数 #数学/考点/中值定理 #数学/失分/K

**题**　证明 $ff''+(f')^{2}=0$ 在 $(0,1)$ 内有两个不同实根。
**答案**　（用两次罗尔）　｜　**得分**　**2 / 6**　｜　**失分类型**　**K 知识性**

### ① 知识点是什么

- **罗尔定理**（可反复使用）
- **「根的个数」型证明的通用套路**：

> 要证"某方程有 $k$ 个根" ⇒ 找一个**辅助函数 $F$**，凑出 $F$ 的 **$k+1$ 个零点** ⇒ 用 **$k$ 次罗尔定理**。
> $k=1$ 一般用零点定理；$k\ge2$ 基本都要"**先造零点、再罗尔**"。

- **辅助函数构造**：本题 $g(x)=f(x)f'(x)$，则 $g'=[f'(x)]^{2}+f(x)f''(x)$
- 由「$\lim\dfrac{f(x)}{x}$ 存在且有限」⇒ $f(0)=0$（**靠极限存在，不是靠保号性**）

### ② 为什么错

- **你的原话**：
  > 「**我没复习，已经忘了那些中值定理，还有什么证明题的定理。**」
- **你的做法**：**辅助函数 $g=ff'$ 和求导 $g'=[f']^{2}+ff''$ 都写对了**（这是本题**最难想到的一步**！），但中值定理忘了 ⇒ (2)(3) 空着。
- **正确做法**（三步）：
  1. **补出 $f(0)=0$**：因 $\dfrac{f(x)}{x}$ 极限存在且有限，$f(x)=x\cdot\dfrac{f(x)}{x}\to0$，$f$ 连续 ⇒ $f(0)=0$
  2. **造第三个零点**：在 $[0,\xi]$ 上对 $f$ 用**罗尔** ⇒ $\exists\eta\in(0,\xi)$，$f'(\eta)=0$ ⇒ $g(\eta)=0$。现在 $g$ 有三个零点 $0,\ \eta,\ \xi$
  3. **两段罗尔**：在 $(0,\eta)$、$(\eta,\xi)$ 上分别用罗尔 ⇒ $\exists\eta_1\ne\eta_2$ 使 $g'=0$
- **差在哪**：**构造辅助函数的直觉还在**，缺的是**定理本身** —— 这是**回补问题，不是能力问题**。

### ③ 出题人为什么这么出

- 题干给 $\dfrac{f(x)}{x}$ ⇒ **逼你先补 $f(0)=0$**（这一步用"极限存在且有限"，专门与上一问的保号性区分开）。
- 结论要证"**两个不同实根**" ⇒ 两根 ⇒ **需要两次罗尔** ⇒ **必须先造出三个零点** —— 层层递进，一步不省。
- 第 (I) 问已经给了零点 $\xi$ ⇒ **前后呼应**：(I) 就是为 (II) 铺路的。

### ④ 操作手法 · 条件反射

| 见到 | 立刻做 |
| --- | --- |
| 「证明某方程有 **$k$ 个**根」 | 找辅助函数 $F$，**凑 $F$ 的 $k+1$ 个零点，用 $k$ 次罗尔** |
| 「**两个不同**实根」 | 需要**两次罗尔** ⇒ 先造**三个零点** |
| 题干含 $\dfrac{f(x)}{x}$ 且极限存在 | 先补 $f(0)=0$（用"极限存在且有限"） |
| 中值定理整块记不清 | 默写全家桶：**罗尔 / 拉格朗日 / 柯西 / 泰勒 ＋ 零点定理** |

- **重做状态**：☐ 未重做　☐ 已重做做对　☐ 仍错（升级为顽固错题）

## 错题 04 · 第 19(2) 题

#数学/模块/高数 #数学/考点/曲面积分 #数学/失分/M

**题**　圆锥面 $z=\sqrt{x^{2}+y^{2}}$ 被柱面 $z^{2}=2x$ 割下的薄片 $S$，密度 $\mu=9\sqrt{x^{2}+y^{2}+z^{2}}$，求质量 $M$。
**答案**　$64$　｜　**得分**　**0 / 8**　｜　**失分类型**　**M 方法性**

### ① 知识点是什么

- **第一类曲面积分** $M=\displaystyle\iint_{S}\mu\,dS$（面密度 × 面积元素）
- $dS=\sqrt{1+z_x^{2}+z_y^{2}}\,dxdy$
- **投影区域**的确定 ＋ **极坐标**
- ⚠️ **三种积分怎么选**：

| 题干里出现 | 用什么 |
| --- | --- |
| 「**薄片 / 壳体 / 曲面…割下的部分**」、「（给定面密度的）质量」 | **第一类曲面积分** $\iint_S\mu\,dS$ |
| 「**通量 / 穿过某曲面**」 | **第二类曲面积分**（多用高斯公式） |
| 「**围成的立体**」、「（给定体密度的）质量」 | **三重积分** $\iiint_\Omega\mu\,dV$ |

### ② 为什么错

- **你的原话**：
  > 「**M，我发现我不会算第一类曲面积分。**」
- **你的做法**：写成 $M=\iiint_{\Omega}\mu\,dV$（$\Omega$ 取"二者的交集"），还把 $z$ 的上下限写成 $\sqrt{x^{2}+y^{2}}$ 到 $\sqrt{2x}$ —— **把"面"当成了"体"**。
- **正确做法**（三步）：
  1. **代曲面方程化简被积函数**：$z=\sqrt{x^{2}+y^{2}}$ ⇒ $\mu=9\sqrt2\sqrt{x^{2}+y^{2}}$
  2. **面积元素**：$dS=\sqrt{1+z_x^{2}+z_y^{2}}\,dxdy=\sqrt2\,dxdy$
  3. **投影定区域**：$D:\ x^{2}+y^{2}\le2x$ ⇒ 极坐标 ⇒ $M=64$
- **差在哪**：**型别判错**（面 vs 体）—— 判错则全题归零。

### ③ 出题人为什么这么出

- 题干用的是"**薄片**"、给的是"**密度**" ⇒ 明确指向**面**，考的就是"**一眼分出面 / 体 / 通量**"。
- 密度设计成 $\sqrt{x^{2}+y^{2}+z^{2}}$：代入曲面方程后恰好化成 $\sqrt2\sqrt{x^{2}+y^{2}}$，与 $dS$ 里的 $\sqrt2$ 相乘**凑成整数 18** ⇒ 命题人要求你**先把曲面方程代进被积函数，再算**。
- 与第 (I) 问的**投影曲线**联动 ⇒ 考"**把前一问的结论当已知条件用**"。

### ④ 操作手法 · 条件反射

| 见到 | 立刻做 |
| --- | --- |
| 「**薄片 / 壳体 / 曲面被…割下的部分**」＋「密度」 | **第一类曲面积分** $\iint_S\mu\,dS$（**不是三重积分**） |
| 「**通量 / 穿过**」 | 第二类曲面积分（多用高斯） |
| 「**围成的立体**」＋「体密度」 | 三重积分 |
| 拿到第一类曲面积分 | 三步：**代曲面方程化简 → $dS=\sqrt{1+z_x^{2}+z_y^{2}}dxdy$ → 投影定区域** |
| 草稿纸 | 先写三个字 **「面 / 体 / 通量」**，圈定一个再动手 |

- **同类题索引**：[[线面积分专项错题精析|📐 线面积分专项]] · 题 ①
- **重做状态**：☐ 未重做　☐ 已重做做对　☐ 仍错（升级为顽固错题）

## 错题 05 · 第 23(2)(3) 题

#数学/模块/概率 #数学/考点/参数估计 #数学/失分/K

**题**　(II) 求 $\sigma$ 的矩估计量；(III) 求 $\sigma$ 的最大似然估计量。
**答案**　$\hat\sigma=\sqrt{\dfrac\pi2}\cdot\dfrac1n\sum\limits_{i=1}^{n}\lvert X_i-\mu\rvert$；$\hat\sigma=\sqrt{\dfrac1n\sum\limits_{i=1}^{n}(X_i-\mu)^{2}}$　｜　**得分**　**0 / 7**　｜　**失分类型**　**K 知识性**

### ① 知识点是什么

- **矩估计**：先算总体矩，再令"**总体矩 = 样本矩**"，反解参数
- **最大似然**：$L(\theta)=\prod f(x_i;\theta)$ → 取 $\ln L$ → 对 $\theta$ 求导令零 → 解出
- 半正态的期望：$E(Z_1)=\sqrt{\dfrac2\pi}\,\sigma$

### ② 为什么错

- **你的原话**：
  > 「**23 题后两问忘了怎么写了。**」
- **你的做法**：第 (1) 问你把 $Z$ 的密度写对了（$f_Z(z)=\dfrac{2}{\sqrt{2\pi}\sigma}e^{-\frac{z^{2}}{2\sigma^{2}}}\ (z\ge0)$ —— **本题的建模核心，你已经拿下**）；(2)(3) 两问**空着**。
- **正确做法**（两问都是纯套路）：
  1. **矩估计**：$E(Z_1)=\dfrac{2\sigma}{\sqrt{2\pi}}=\sqrt{\dfrac2\pi}\sigma$ ⇒ 令 $E(Z_1)=\bar Z$ ⇒ $\hat\sigma=\sqrt{\dfrac\pi2}\cdot\dfrac1n\sum\lvert X_i-\mu\rvert$
  2. **最大似然**：$L(\sigma)=\left(\dfrac{2}{\sqrt{2\pi}\sigma}\right)^{n}e^{-\frac{\sum z_i^{2}}{2\sigma^{2}}}$ ⇒ $\dfrac{d\ln L}{d\sigma}=-\dfrac n\sigma+\dfrac{1}{\sigma^{3}}\sum z_i^{2}=0$ ⇒ $\hat\sigma=\sqrt{\dfrac1n\sum(X_i-\mu)^{2}}$
- **差在哪**：**整块遗忘** —— 建模会了，但**套路没背下来**。

### ③ 出题人为什么这么出

- 第 (1) 问先让你**把 $Z$ 的密度写出来** —— 铺好路之后，(2)(3) 变成"**默写题**"，不会就 0 分。
- $\mu$ **已知** ⇒ 参数只剩 $\sigma$ 一个 ⇒ 逼你**只用一阶矩**（不涉及二阶矩，难度降低）。
- 题干特意说明"$Z$ 与 $X$ 相互独立" ⇒ 保证 $\sum Z_i^{2}$ 的结构简单，**把计算量压到最低** —— 命题人明摆着只想考"你会不会套路"。

### ④ 操作手法 · 条件反射

| 见到 | 立刻做 |
| --- | --- |
| 「**矩估计**」 | 数未知参数个数 → 算对应的（一阶 / 二阶）总体矩 → **令"总体矩 = 样本矩"** → 解方程 |
| 「**最大似然估计**」 | $L(\theta)=\prod f$ → 取 $\ln L$ → 对 $\theta$ 求导令零 → 解出（**先写清 $\theta$ 的取值范围**） |
| 参数估计整题 | 这两类在真题里**几乎是默写题** ⇒ **直接套流程，别现场推导** |

- **重做状态**：☐ 未重做　☐ 已重做做对　☐ 仍错（升级为顽固错题）

## 本卷条件反射总表（考前扫一遍）

> **只收「不容易自己发现」的** —— 反直觉的判据 / 题干的伪装 / 会导致全题归零的第一步判断 / 自己踩过的动作习惯。
> **不收**：教科书标准流程；**以及"见弧长⇒弧长公式"这种字面自指的废话**。

| 见到 | 立刻做 | 出处 |
| --- | --- | --- |
| 「由 $\lim$ 的**符号** ⇒ 某点函数值符号」 | **必须落地成一个具体的点 $c$** —— 这一步本身就是评分点 | 第 18(1) 题 |
| 「证明某方程有 **$k$ 个根**」 | 找辅助函数 $F$，**凑 $F$ 的 $k+1$ 个零点，用 $k$ 次罗尔** | 第 18(2) 题 |
| 题干含 $\dfrac{f(x)}{x}$ 且极限存在 | 先补 $f(0)=0$（靠"极限存在且有限"，**不是**保号性） | 第 18(2) 题 |
| 「**薄片 / 壳体 / 曲面被…割下的部分**」＋密度 | 是**面** ⇒ **第一类曲面积分**（不是三重积分） | 第 19(2) 题 |
| **$\iint_S f\,dS$** | **这是第一类曲面积分，不是二重积分** —— 先乘 $dS=\sqrt{1+z_x^{2}+z_y^{2}}\,dxdy$ 再算 | 第 19(2) 题 |
