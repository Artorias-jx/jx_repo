# 多元函数微分学：利用柯西不等式求条件极值

在多元函数微分学中，若求**条件极值**时目标函数与约束条件呈现“线性组合”**与**“平方和”**的形式，利用**柯西不等式（Cauchy-Schwarz Inequality）求解通常比拉格朗日乘数法更为简便。

## 一、 核心公式与取等条件

### 1. 二维形式
$$(ax + by)^2 \le (a^2 + b^2)(x^2 + y^2)$$

- **取等号条件**：当且仅当 $\frac{x}{a} = \frac{y}{b}$ 时成立。

### 2. 三维形式
$$(ax + by + cz)^2 \le (a^2 + b^2 + c^2)(x^2 + y^2 + z^2)$$

- **取等号条件**：当且仅当 $\frac{x}{a} = \frac{y}{b} = \frac{z}{c}$ 时成立。

## 二、 典型例题解析

**【2018年数一二三】** 已知约束条件为：
$$2\pi x + 4y + 3z = 2$$

求目标函数 $f(x,y,z) = \pi x^2 + y^2 + \frac{\sqrt{3}}{4} z^2$ 的最小值。

### 1. 构造柯西不等式

为了匹配目标函数的平方项，将目标函数改写为标准平方和形式：

$$f(x,y,z) = (\sqrt{\pi}x)^2 + y^2 + \left(\frac{3^{\frac{1}{4}}}{2} z\right)^2$$

设定柯西不等式右侧的项为：

$$b_1 = \sqrt{\pi}x, \quad b_2 = y, \quad b_3 = \frac{3^{\frac{1}{4}}}{2} z$$

根据已知条件 $2\pi x + 4y + 3z = 2$，通过待定系数法确定 $a_1, a_2, a_3$：

$$\begin{aligned} a_1 &= \frac{2\pi x}{\sqrt{\pi}x} = 2\sqrt{\pi} \\ a_2 &= \frac{4y}{y} = 4 \\ a_3 &= \frac{3z}{\frac{3^{\frac{1}{4}}}{2} z} = 2 \cdot 3^{1 - \frac{1}{4}} = 2 \cdot 3^{\frac{3}{4}} \end{aligned}$$

### 2. 代入不等式求解

将系数代入三维柯西不等式 $(a_1b_1 + a_2b_2 + a_3b_3)^2 \le (a_1^2 + a_2^2 + a_3^2)(b_1^2 + b_2^2 + b_3^2)$：

$$(2\pi x + 4y + 3z)^2 \le \left[ (2\sqrt{\pi})^2 + 4^2 + (2 \cdot 3^{\frac{3}{4}})^2 \right] \cdot \left[ (\sqrt{\pi}x)^2 + y^2 + \left(\frac{3^{\frac{1}{4}}}{2} z\right)^2 \right]$$

代入已知数据化简：

$$2^2 \le (4\pi + 16 + 4 \cdot 3^{\frac{3}{2}}) \cdot f(x,y,z)$$

$$4 \le (4\pi + 16 + 12\sqrt{3}) \cdot f(x,y,z)$$

两边同除以 4，得：

$$f(x,y,z) \ge \frac{1}{\pi + 4 + 3\sqrt{3}}$$

因此，目标函数的最小值为：

$$f(x,y,z)_{\min} = \frac{1}{\pi + 4 + 3\sqrt{3}}$$

### 3. 求取等号时的自变量值

等号成立的条件为 $\frac{b_1}{a_1} = \frac{b_2}{a_2} = \frac{b_3}{a_3}$，即：

$$\frac{\sqrt{\pi}x}{2\sqrt{\pi}} = \frac{y}{4} = \frac{\frac{3^{\frac{1}{4}}}{2} z}{2 \cdot 3^{\frac{3}{4}}}$$

化简比例关系：

$$\frac{x}{2} = \frac{y}{4} = \frac{z}{4\sqrt{3}}$$

结合约束条件 $2\pi x + 4y + 3z = 2$，解得此时的精确坐标为：

$$x = \frac{1}{\pi + 4 + 3\sqrt{3}}, \quad y = \frac{2}{\pi + 4 + 3\sqrt{3}}, \quad z = \frac{2\sqrt{3}}{\pi + 4 + 3\sqrt{3}}$$

此时目标函数 $f(x,y,z) = \pi x^2 + y^2 + \frac{\sqrt{3}}{4} z^2$ 取得最小值。

**该最小值为：**

$$f_{\min} = \frac{1}{\pi + 4 + 3\sqrt{3}}$$
### 4. 代入验算（严谨性闭环）

为了确保柯西不等式推导出的极值准确无误，我们可以将解出的 $x, y, z$ 的值直接代入原目标函数进行验证。

令分母部分 $S = \pi + 4 + 3\sqrt{3}$，则：

$$x = \frac{1}{S}, \quad y = \frac{2}{S}, \quad z = \frac{2\sqrt{3}}{S}$$

将它们代入目标函数 $\pi x^2 + y^2 + \frac{\sqrt{3}}{4} z^2$：

$$\begin{aligned} f(x,y,z) &= = \frac{\pi + 4 + 3\sqrt{3}}{S^2} \end{aligned}$$

因为分子刚好等于 $S$，所以：

$$f(x,y,z) = \frac{S}{S^2} = \frac{1}{S} = \frac{1}{\pi + 4 + 3\sqrt{3}}$$

验算结果与柯西不等式直接得出的 $f \ge \frac{1}{\pi + 4 + 3\sqrt{3}}$ 完全一致。
