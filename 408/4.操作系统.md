# 操作系统笔记：进程与页表全景

## 1. 为什么每进程分配独立页表？

- **内存隔离与保护**：虚拟地址物理隔离，防止进程越界访问或恶意篡改。
- **统一地址空间**：编译/链接无需考虑物理装载位置，统一从基地址展开虚拟视图。
- **支持虚拟存储**：按需调页与超额分配（Overcommit），结合缺页置换突破物理内存容量限制。
- **细粒度权限控制**：页表项自带标志位管理读写权限（`R/W`）、防执行注入（`NX/XD`）与特权级（`U/S`）。
    
      
    
- **共享与写时复制（COW）**：多进程映射同一份动态库物理页；`fork()` 时父子共享页表并置只读，写时触发物理页复制。
    
      
    

## 2. 物理存储方式：单级 vs 多级页表

|**维度**|**单级页表**|**多级页表（现代主流）**|
|---|---|---|
|**物理存放**|**必须严格物理连续**（单一大数组，易产生外部碎片）|**整体离散，页内连续**（切分为 4KB 页框分散存放）|
|**寻址机制**|$\text{物理地址} = \text{PTBR} + (\text{页号} \times \text{项大小})$|顶级页表（页目录）索引下级页表的物理页框号|
|**内存占用**|必须一次性全部常驻内存（32 位需 4MB 连续空间）|**按需动态分配**，未使用的虚拟地址空间无需分配下级页表|

## 3. 页表基址寄存器（PTBR / CR3）

- **存储物理地址**：MMU 硬件寻址的绝对起点。若存虚拟地址，会导致“查页表需先翻译，翻译又需查页表”的硬件死循环。
    
      
    
- **地址属性辨析**：PC、SP 存放**虚拟地址**（需经 MMU 翻译）；PTBR / CR3 存放**物理地址**（直接供 MMU 硬件使用）。
    
      
    

## 4. 进程调度与页表去向

- **常规进程切换（低级调度）**：换下进程的页表**完好保留在物理内存中**；内核从新进程 PCB 读取其页表物理基址写入 CR3，并**刷新 TLB**。
    
      
    
- **中级调度（挂起换出）**：不活跃的数据页与部分下级页表换出至磁盘对换区（Swap），顶级页表与 PCB 仍常驻内核内存。
    
      
    

## 5. 多进程页表空间分布

- **物理分布**：各进程页表离散存放于物理内存的不同页框中，互不干扰。
    
      
    
- **用户空间（低地址）**：映射完全独立，不同进程相同虚拟地址指向不同物理页。
    
      
    
- **内核空间（高地址）**：所有进程映射完全相同，统一指向物理内存中唯一的内核代码与数据。
    
      
    

## 6. 408 核心考点速记

- 单级页表物理必须连续；多级页表物理离散、按需分配。
    
      
    
- PTBR / CR3 存放的是**物理地址**，不是虚拟地址。
    
      
    
- 进程下 CPU 时页表仍在物理内存中，切换时仅改变 CR3 寄存器指向并刷新 TLB。
    
      
    
- 多进程在用户态物理隔离，在内核态共享同一份物理映射。
