# 2. 进程与线程
## 2.1 PV专题
### P、V 大题注意事项

1. 尽量只用**记录型信号量**，若想用 `int` 型变量，需要**互斥**。
2. 注意不同进程间的**互斥**和**共享**（如：读者写者问题）。
3. 注意生产者生产的**不同类资源**是否应该区分？
4. **理发师问题**：服务人员即资源，没有明确生产者。
5. **哲学家进餐问题**：只需不让所有人一块访问资源即可。即控制人数 $< n$。
6. 注意审题，看题目让写的是 `P`、`V` 还是 `wait`、`signal`。

### 生产者——消费者问题

1. **有几类进程 $\longrightarrow$ 每类进程对应一个函数**
2. **在每个函数内，用中文描述进程动作 $\longrightarrow$**
    - **只做一次**
    - **不断重复**：加 `while(1)`
3. **每分析一个动作之前，是否需要 P 什么？**
    - 只要有 P，必有 V，先写 P 再写 V。
注意**隐含的互斥**："对缓冲区的访问"必须互斥。
4. **所有 PV 写完，再定义信号量**
    - 信号量定义完，再思考初始值。
5. **检查多个 P 操作连续出现的地方，是否有可能导致死锁？**
    -  解决方法：调整多个 P 的顺序。
6. **读题检查，是否满足题目，**

### 哲学家进餐问题
**特点**：进程要争多种资源才能运行。
> [!star] 核心思想
> 想办法只让 $n-1$ 个人同时取资源即可。

**信号量定义：**
```c
Semaphore chopstick[5] = {1, 1, 1, 1, 1}; // 5 根筷子，初值都为 1
Semaphore room = 4;                        // 最多允许 4 人同时进餐（n-1）
```
**代码模板：**
```c
Philosopher(int i) {  // 第 i 号哲学家
    while(1) {
        思考;
        
        P(room);           // 进入房间（限制人数）
        P(chopstick[i]);   // 拿左边筷子
        P(chopstick[(i+1)%5]); // 拿右边筷子
        
        进餐;
        
        V(chopstick[i]);   // 放下左边筷子
        V(chopstick[(i+1)%5]); // 放下右边筷子
        V(room);           // 离开房间
    }
}
```
