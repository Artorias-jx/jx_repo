# 一.绪论
## 1.数据结构与算法
逻辑结构与存储结构（物理结构）：
逻辑指的是数据的关系，包括集合（数据之间无相关）线性（一对一）图（多对多）树（一对一）
存储结构指的是存储方法，有顺序存（地址连着），链式（指针链接），哈希（通过关键字算出地址）索引（额外存储一个索引表）

## 2.算法时空复杂度
特性：确定性，有穷性，可行性，I，O。评估：正确性，健壮性等，不仅仅通过时间和空间复杂度
时间复杂度：一般指最坏。算法：单变量，直接算；多变量，列举i与j的变化，求和找出与n的关系
空间复杂度：额外开销，比如需要额外一个与输入规模n同阶的数组，空间复杂度就是O(n），如果额外开销与数据规模n无关则O(1)

# 二.线性表
## 1.顺序表
存储地址直接相连，如数组。静态分配方式和动态分配方式
支持随机存取，但是插入和删除比较麻烦：前者插入后需要后面的元素向后移动一位，后者则往前。时间复杂度为O（n）。
**重点是代码题**：如辅助数组的应用，双指针，快慢指针，三指针，数组逆置等。
	做法：认真读题，抓住题目重点，简化题目所求条件，根据题目限制找到常用暴力解法。
	快速想到时间复杂度尚且的暴力解，最优解一般不想。可适当列举几个情况进行模拟来判断代码的正确性。
## 2.链表
存储地址不直接相连，而是通过开辟一个空间存指针，指针指向下一个元素的地址。
不支持随机存取，但是插入和删除元素比较简单，但是仍要找到上一个节点以修改指针，时间花在查找上。
头结点：新增一个指向首元结点的节点，不存数据，为了操作的统一性，头指针head指向头结点。
**单链表**：最基础的链表，只有一个next指针，重点是操作：头插和尾插，头插法可以用于链表逆置
**双向链表**：新增一个prior指针指向前驱，如果已知当前结点，那么插入和删除时间复杂度为O（1）
**循环单链表**：新增一个尾指针指向头结点，判空：l->next == l，头结点的next指向自己。仅需一个尾指针即可完成在表头和表尾进行插入和删除。若只有头指针，则查找表尾需要复杂度O（n）
**循环双链表**：新增一个prior指针指向前驱，头节点的prior指向尾节点，查找节点方便，但操作复杂
**静态链表**：用数组cos链表，数据部分存储下一个结点的数组下标，尾结点为-1
## 3.顺序表和链表的比较
1. 存取方式:前者支持随机存取，后者只能顺序存取
2. 逻辑结构与物理结构：逻辑结构都是线性，物理结构前者是顺序存储，后者是链式存储
3. 查找，插入和删除： 若按值查找，无序则都为O(n)，若有序，顺序表可用折半查找，优化为O（logn）。按序号查找，前者O（1），后者O（n）。插入，删除：顺序表平均移动一半的元素，而链表只需要移动指针，但是查找操作需要O（n）
4. 空间分配：顺序表静态不方便，动态可能浪费，链表额外存储指针域，存储密度小于1
5. 频繁查找序号，则顺序表；频繁插入删除则链表
## 4.选择题重点：
对频繁的操作来选取合适的线性表的结构
对时间复杂度的要求来选取合适的结构
对常用操作所需指针的变化熟练掌握，判空判满。
删除结点时注意删除时结点的数量，特殊情况：只有一个首元节点。
熟练指针的变化来判断对应的操作，注意指针变化的先后顺序能不能颠倒。

## 3.数组和特殊矩阵
###  二维数组：m 行 n 列
- **按行优先**：设 $a_{ij} = S_{ij}$
则同列下一行的元素地址：$a_{(i+1)j} = S_{ij} + L \cdot n$ （$L$ 是每个单元大小）
- **核心技巧**：可用于快速求给定位置元素的地址。**算出对应行，再依次往后加即可**。
- **例题实操**：
    已知 $A[1][1] = 420$，$A[3][3] = 446$，$L = 1$，求 $A[5][5]$：
    - 先向下推导到第 3 行第 1 列：$A[3][1] = 420 + 2n$
    - 再向后推导到第 3 行第 3 列：$A[3][3] = 420 + 2n + 2 = 446$
        - 解得：$2n + 2 = 26 \implies n = 12$
    - 继续推导至第 5 行第 5 列：
        - $A[5][5] = A[3][3] + 2n + 2 = 446 + 2n + 2 = 446 + 26 = 472$

### 对称矩阵与三角矩阵
- **下三角矩阵**：第 $i$ 行有 $i$ 个元素。
- **上三角矩阵**：第 $i$ 行有 $n - i + 1$ 个元素（第 1 行有 $n$ 个，第 2 行有 $n-1$ 个...）。
- **核心策略**：无论是按行还是按列存储，不需要死记公式，**依次推即可**。

###  三对角矩阵
- **一般按行优先**：求第 $i$ 行，第 $j$ 列（**下标从 0 开头**）
    - **计算公式**：$3(i-1) - 1 + j - i + 1$
    - **公式拆解**：
        - $3(i-1) - 1$：代表**该行第一个地址**。
        - $j - i + 1$：代表在该行内的偏移量，取值范围为 `[0, 1, 2]`。
- **按列优先**：
    - **计算公式**：$3(j-1) - 1 + i - j + 1$
    - **核心策略**：将按行优先公式中的 $i$ 与 $j$ **互换即可**。

# 四.KMP
### 1. 时间复杂度对比
$O(m+n)$：KMP 算法。主串移动 $m$ 次，指针不会返回（回溯）。
$O(mn)$：暴力求法（BF 算法）。主串移动后指针会返回 $0$。

### 2. 求子串 $T$ 的 `next` 和 `nextval` 数组 与右滑距离
[KMP求next和nextval数组](琐碎知识点/KMP求next和nextval数组.md)
- 实际做题时，通常从 `next[3]` 和 `nextval[2]` 开始求解。（注：此规律基于**下标从 1 开始**的情况。若题目要求下标从 0 开始，则整体减 1）。

###  3.匹配失败时的指针跳转
- 对比时，若主串与模式串不匹配，即 $S[i] \neq T[j]$：
    - 则令 $j = \text{nextval}[j]$ 或 $j = \text{next}[j]$，将跳转后的新位置记为 $k$。
    - 接下来从 $S[i]$ 与 $T[k]$ 重新开始比较。

###  4.边界情况（指针为 0 时）的物理意义
**只要 $j$ 变到 0（无论是 `next` 还是 `nextval`），无脑执行 $i$ 与 $j$ 移动 1 位，即用主串的新字符补充模式串的首字符。 j=nextj 就是 j 要移动到的位置，若 nextj 为 0 或者 nextvalj 为 0 就表示不需要移动，直接让 i 加 1，j 为 1 （相当于 j 等于 0 加 1）即可**

# 五.树
## 1.树的结构与性质
树是一对多结构，可顺序存储，可链式存储。
树的结点每连一条边，度为1，称为结点的度。树的度为结点的度的最大值。
路径长度是根节点到叶结点的边的个数。
树中结点的个数＝总度数 + 1。(每个结点对应一个度连上父结点，根节点没有父结点，故再+1)
## 2.二叉树
1. 二叉树指度不大于2的树。
2. 二叉树的子树有明确的次序，固定，不能交换，属于有序树。
3. 满二叉树：结点满。
4. 完全二叉树：给结点编号，现有的结点编号与满二叉树中的对应的相同。完全二叉树中如果有度为1的结点，那么只会有一个，如果有第二个，那么编号会对不上。只有最后两层有叶结点。
5. 二叉排序树：左子树关键字＜根节点关键字＜右子树关键字，具有递归。
6. 平衡二叉树：任意一个结点左子树的度与右子树的度的差的绝对值≤1。
7. n0 ＝ n2 +1；n1消去了。完全二叉树可以用这个结论来算结点数。非空
8. 高度h＝log2（n+1）的上界，n是结点数。满二叉树的结点数=2的h次方-1
## 3.二叉树的遍历和线索二叉树
## 二叉树的遍历与线索二叉树（选择题快解技巧）

- **1. 中序遍历的边界结点**
    
    - **第一个结点：** 整棵树**最左下**的结点（一直向左走到底）。
        
    - **最后一个结点：** 整棵树**最右下**的结点（一直向右走到底）。
        
- **2. 序列推导：先/后序 + 中序 确定二叉树**
    
    - **定根：** 先序序列的**第一个**结点，或后序序列的**最后一个**（倒数第一个）结点，必然是当前树（或子树）的根结点。
        
    - **划界：** 找到根结点后，在**中序序列**中定位该结点，以此为界将中序序列分为两部分。然后再对左右两部分分别递归寻找左、右子树的根。
        
- **3. 序列推导：仅给先序和后序（确定中序可能性/结点度数）**
    
    - **结构对位法：**
        
        - 先序形态：`[根] [左子树的根, ...] [右子树的根, ...]`
            
        - 后序形态：`[..., 左子树的根] [..., 右子树的根] [根]`
            
    - **核心判定（对比“第二”与“倒二”）：**
        
        - 提取先序序列的**第 2 个**结点（即左子树的根），和后序序列的**倒数第 2 个**结点（即右子树的根）。
            
        - **若两者相等：** 说明该根结点**只有一个孩子**（无法确定是左还是右，因此对应的中序序列不唯一）。
            
        - **若两者不等：** 说明该根结点**有两个孩子**（左右孩子齐全）。
            
- **4. 找反例的常用模型**
    
    - 遇到判定树的形态或序列特性的命题，常构造退化树（单链表结构）来证伪：
        
        - **左斜树：** 根 A $\rightarrow$ 左孩子 B。
            
        - **右斜树：** 根 A $\rightarrow$ 右孩子 B。
            
- **5. 线索二叉树的查找局限性（“健康”与“残疾”）**
    
    - **中序线索二叉树（健康）：** 能够完美找到任意结点的直接前驱和直接后继。
        
    - **先序线索二叉树（残疾 - 找前驱困难）：** 若某结点有左孩子（`lchild` 指针被占用，无法存线索），由于先序遍历的特性，它的直接前驱大概率是其**父结点**。而在常规二叉链表中没有双亲指针，因此无法直接逆向找到前驱。
        
    - **后序线索二叉树（残疾 - 找后继困难）：** 若某结点有右孩子（`rchild` 指针被占用，无法存线索），由于后序遍历的特性，它的直接后继大概率是其**父结点**。同理，无双亲指针导致无法直接查找到后继。

# 六.图
## 1.图的概念
1. 主要区分有向图里面的路径和弧。
	路径是u到v，涉及的点。
	弧是u直接连到v。
   所以强连通图指每两个结点之间有路径，而不是有弧。
2. **极大连通子图是连通分量。极小连通子图是生成树。**
	极大连通子图不包含所有点，但要包含点涉及的所有边
	极小连通子图包含所有点，并且包含最少需要的边
3. 另外就是连通图的结点数|V|与|E|的关系。
	无向图。v-1个节点两两相连，此时完全图。再加一个点即不相连
	同时，最少v-1条边即可连通，若点数＞边数+1，则不连通
4. 图的度
	有向图：每个结点与其余n-1个结点有两条边，此时为有向完全图。每个结点最大的度为2n-2，n为节点数。总最大度数＝n * (2n - 2)
	无向图：每两个结点都连一条，总边数：n（n-1）\2,度为2倍的边数。
## 2.图的存储
- **邻接矩阵 (数组)**
    **特性：** 无向图的矩阵**必然对称**；有向图**不一定对称**。
    **复杂度：** 空间复杂度恒为 $O(|V|^2)$。
    **考点：** 无向图常利用对称性进行压缩存储，数组大小为 $n(n+1)/2$。
- **邻接表 (数组+链表)**
    **特性：** 同一个图的邻接表表示**不唯一**（取决于边插入链表的顺序）。
    **结点数：** 含有 $E$ 条边的无向图，边表结点数必为偶数（$2E$）；有向图边表结点数等于 $E$（不一定为奇偶）。
    **复杂度：** 空间复杂度无向图 $O(|V|+2|E|)$，有向图 $O(|V|+|E|)$。
- **高级链表 (解决特定痛点)**
    - **十字链表 (仅有向图)：** 解决邻接表“求入度极其困难”的问题（融合了邻接表和逆邻接表）。弧尾是同行，弧头指向其他行。
    - **邻接多重表 (仅无向图)：** 解决邻接表“同一条边存两份，删除/修改边困难”的问题（每条边只存一个结点）。结构：头，下一个头相同，尾，下一个尾相同。
## 3.图的遍历
- **核心逻辑**
    - **广度优先遍历 (BFS)：** 类似树的层次遍历。借助**队列**实现。
    - **深度优先遍历 (DFS)：** 类似树的先序遍历。借助**递归栈**实现。
- **时空复杂度**
    - **空间复杂度：** 无论是 BFS 还是 DFS，最坏情况下的辅助队列/栈深度均为 $O(|V|)$；同时都需 $O(|V|)$ 的 `visited` 数组。故空间复杂度均为 $O(|V|)$。
    - **时间复杂度 (仅取决于存储结构)：**
        - **邻接表：** $O(|V|+|E|)$
        - **邻接矩阵：** $O(|V|^2)$
- **遍历与连通性的判定**
    - **无向图：** 调用遍历算法（BFS/DFS）的次数 == 图的连通分量数。若一次调用就能访问所有结点，则图是连通图。
    - **有向图：** 极易踩坑！有向图能否一次遍历完，高度依赖起始点。即使图不是强连通图（例如 $A \rightarrow B \rightarrow C$），只要从正确的起点（如 $A$）出发，也可能一次遍历完毕。
