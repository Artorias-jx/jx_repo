# 3. 栈与队列
## 栈
按入栈次序写，分析选项的出栈顺序，对应一个删去一个即可
**栈的合法出栈序列数**$$C_n = \frac{1}{n+1} C_{2n}^{n} = \frac{(2n)!}{(n+1)!n!}$$这个数叫拉特兰数，求n个相同结点构成的二叉树的种类也是卡特兰数
## 循环队列
**队首**：删除元素的地方。**队尾**：加元素的地方。
**核心策略**：默认牺牲一个空位来避免判空和判满使用同一语句。

### ① front 指向队首，rear 指向队尾的下一个
![319](assets/1.%20数据结构知识/循环队列图1.png)
- **初始状态**：
指针位置：`f` 和 `r` 同时指向队首第一个位置。
**判空条件**：$front == rear$
- **队满状态**：
指针位置：`f` 指向队首，`r` 指向队尾后面的一个空位。
 **判满条件**：$front == (rear + 1) \% \text{maxsize}$
`注：此时 `rear` 所指的空间即为牺牲的空位。`

### ② front 指向队首前一个，rear 指向队尾
![363](assets/1.%20数据结构知识/循环队列图2.png)
- **初始状态**：
指针位置：`f` 和 `r` 同时指向同一个初始位置（图示为数组末尾）。
**判空条件**：$front == rear$        
- **队满状态**：
指针位置：`f` 指向队首的前一个位置，`r` 指向队尾。
**判满条件**：$front == (rear + 1) \% \text{maxsize}$
`注：此时 `front` 所指的空间即为牺牲的空位。`

## 求next数组
**咸鱼版求next数组：**

- `next[1] = 0`  `next[2] = 1` _(以上两项固定)_

**其他next：** 不匹配前划线，模式串后退，直到线前对上，或模式串完全跨过，此时j为值。
示例 T = "ababaa"
![652](assets/1.%20数据结构知识/求next数组.png)
## 求nextval数组
示例图
![625](assets/1.%20数据结构知识/求nextval数组.png)
先求 $next$ 数组，之后求 $nextval$  $nextval[1]=0$ 固定
若 $j$ 所指字符与 $next[j]$ 所指字符不相等
如 $j=2$，$T[2]=b$，$T[next[2]]=a$，$nextval[j]=next[j]$
若相等，则 $nextval[j]=nextval[next[j]]$
如 $j=3$，$a$ 与 $a$ 等，则 $nextval[3]=nextval[1]=0$
$j=5$，$T[next[5]]=a=T[5]$，$nextval[5]=nextval[next[5]]$
## 右滑距离
![394](assets/1.%20数据结构知识/求右滑距离.png)
**右滑距离：** $j - nextval[j]$
为当前失配回到何处距离，
向右滑，即指针不动，滑 $S$，
如 $j=6$，要移动到 $j=2$，
右滑 $1$，$j=5$，右滑$2$，$j=4$右滑$3$，$j=3$右滑$4$，$j=2$，ok。
