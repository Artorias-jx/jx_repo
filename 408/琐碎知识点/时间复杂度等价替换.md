## 遇到多变量时间复杂度分析时的处理技巧

**原则**：在多变量的时间复杂度分析中，如果没有找到 O(m + n)，一定要能立刻反应过来它可以直接等价替换为 O(max(m, n))。

**理由**：
- 当 m 和 n 都趋向于无穷大时，O(m + n) 和 O(max(m, n)) 是同一个数量级
- 因为 max(m, n) ≤ m + n ≤ 2·max(m, n)
- 上下界都是 max(m, n)，所以渐进意义下等价

**例子**：
- O(m + n) ≈ O(max(m, n))
- O(m + n + k) ≈ O(max(m, n, k))

**考试应用**：
如果选项中没有 O(m + n)，但有 O(max(m, n))，可以直接选择后者。
