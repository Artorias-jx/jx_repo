# 运算部件结构与工作流程

## 1. 加减运算部件（ALU）
![加减运算部件](assets/运算部件和工作流程/file-20260728215215405.png)

| 阶段 | 内容 |
|------|------|
| **开始状态** | X、Y 已在输入端，Sub 信号已给出 |
| **结束状态** | F = 结果（n 位），ZF/SF/CF/OF 已置位 |

**流程**：
1. Sub=0 → MUX 直通 Y，Cin=0 → F = X + Y
2. Sub=1 → MUX 输出 ~Y，Cin=1 → F = X + ~Y + 1 = X - Y
3. 标志位同步生成：ZF = (F == 0)，SF = F[n-1]，CF = Cout⊕Sub，OF = C_n⊕C_{n-1}

**核心**：加减共用一个加法器，减法是"加补码"。

## 2. 无符号乘法器（右移型）
![](assets/运算部件和工作流程/file-20260728215238321.png)

| 阶段 | 内容 |
|------|------|
| **开始状态** | P = 0（n 位），Y = 乘数（n 位），X = 被乘数（n 位） |
| **结束状态** | P\|Y 拼接 = 2n 位乘积 |

**流程**（n 次循环）：
1. 若 Y[0]=1 → P = P + X；若 Y[0]=0 → P 不变
2. P\|Y 整体**逻辑右移** 1 位（P 高位补 0，P[0] 移入 Y 最高位）

**移位方向**：右移。每次移出 Y 的最低位（已用过），下一轮的新 Y[0] 就是乘数的下一位。

**异常**：若只保留 n 位结果则 P ≠ 0 时溢出；保留完整 2n 位则无溢出。

## 3. 有符号乘法器（Booth 一位乘法）
![](assets/运算部件和工作流程/file-20260728215243121.png)

| 阶段 | 内容 |
|------|------|
| **开始状态** | P = 0（n 位），Y = 乘数（n 位），X = 被乘数（n 位），Y₋₁ = 0 |
| **结束状态** | P\|Y 拼接 = 2n 位补码乘积 |

**流程**（n 次循环）：
1. 根据 (Y[0], Y₋₁) 决定操作：

| Y[0] | Y₋₁ | 操作 | 含义 |
|:----:|:---:|------|------|
| 0 | 1 | P = P + X | 1 串开始 |
| 1 | 0 | P = P - X | 1 串结束 |
| 0 | 0 | 无操作 | 0 串中间 |
| 1 | 1 | 无操作 | 1 串中间 |

2. P\|Y 整体**算术右移** 1 位（P 高位补符号位，保持正负）

**与无符号乘法的关键区别**：

| 对比 | 无符号 | 有符号（Booth） |
|------|--------|----------------|
| P 初始化 | 0 | 0 |
| 移位方式 | **逻辑右移**（补 0） | **算术右移**（补符号位） |
| 操作类型 | 只加 | 加或减 |
| 判断依据 | Y[0] | (Y[0], Y₋₁) 两位 |

**异常**：若只保留 n 位结果则 P 不全为符号位时溢出。

## 4. 除法器
![](assets/运算部件和工作流程/file-20260728215246834.png)

**无符号除法（不恢复余数法）**

| 阶段 | 内容 |
|------|------|
| **开始状态** | R = 0（n 位），Q = 被除数（n 位），Y = 除数（n 位） |
| **结束状态** | Q = 商（n 位），R = 余数（n 位） |

**流程**（n 位操作数）：
1. RQ 左移 1 位
2. R = R - Y
3. 重复 n-1 次：
   - Q[0] = R≥0 ? 1 : 0
   - RQ 左移 1 位
   - R = R≥0 ? R - Y : R + Y
4. Q[0] = R≥0 ? 1 : 0（末位商，不再移位）
5. 若 R < 0：R = R + Y（恢复余数）

**带符号除法（补码加减交替法）**

| 阶段 | 内容 |
|------|------|
| **开始状态** | R = Q 的符号位填充（n 位），Q = 被除数（n 位），Y = 除数（n 位） |
| **结束状态** | Q = 商（n 位补码），R = 余数（n 位补码） |

**流程**（n 位操作数）：
1. RQ 左移 1 位
2. R = (R 与 Y 同号) ? R - Y : R + Y
3. 重复 n-1 次：
   - Q[0] = (R 与 Y 同号) ? 1 : 0
   - RQ 左移 1 位
   - R = (R 与 Y 同号) ? R - Y : R + Y
4. Q[0] = 1（末位恒置 1），若 R 与 Y 异号则 R = R + Y 恢复

**无符号 vs 带符号除法对比**

| 对比 | 无符号 | 带符号 |
|------|--------|--------|
| R 初始化 | 0（补 0 扩展） | 被除数符号位填充 |
| 判定条件 | R ≥ 0 | R 与 Y 同号 |
| 末位商 | R≥0 ? 1 : 0 | 恒置 1 |
| 移位方向 | 左移 | 左移 |

**异常检测**

| 异常    | 无符号                                                                | 带符号                                   |
| ----- | ------------------------------------------------------------------ | ------------------------------------- |
| 除数为 0 | Y = 0 → 异常                                                         | Y = 0 → 异常                            |
| 溢出    | 无（n 位 ÷ n 位，R 初始为 0，商必在 n 位内。⚠️ 若被除数为 2n 位（高 n 位在 R，低 n 位在 Q），则 R ≥ Y 时溢出） | $-2^{n-1} \div -1$（商 $+2^{n-1}$ 不可表示） |

## 408考点总结

| 部件 | 方向 | 核心操作 |
|------|:--:|------|
| ALU | — | Sub 切换加减，共用加法器 |
| 乘法器 | **右移** | 无符号逻辑右移，Booth 算术右移 |
| 除法器 | **左移** | 试商（减/加交替），带符号需符号扩展 |
