# 磁盘与固态硬盘汇总
> 整合计组与OS中磁盘、固态硬盘的全部知识点，按逻辑顺序组织：结构 → 存取 → 调度 → 缓存 → SSD

==核心主线==：先看机械硬盘（HDD）的物理结构和工作方式（计组），再看OS如何管理它（初始化、调度算法、缓存），最后对比固态硬盘（SSD）的特性差异。

---

## 1. 机械硬盘结构（计组）
**机械硬盘（HDD）** 由盘片、磁头、盘面、磁道、扇区组成，读写需要机械运动。

**磁盘存储器的组成**：磁盘存储器由==磁盘驱动器、磁盘控制器和盘片==组成。
- **磁盘驱动器**：驱动磁盘旋转并通过磁头在盘面上执行读/写操作的机械装置
- **磁盘控制器**：磁盘驱动器与主机之间的接口，负责接收并解析来自CPU的命令，向磁盘驱动器发送控制信号，同时监控其运行状态
- **盘片**：记录数据的载体

### 1.1 物理组成
- **盘片**：涂有磁性材料的圆盘，多个盘片叠在一起
- **盘面**：每个盘片有上下两个盘面，各有一个磁头。==一个盘片 = 2 个盘面==
- **磁道**：盘面上的同心圆，==从外向内编号（0, 1, 2, ...），最外圈是0号磁道==
- **扇区**：磁道划分成若干扇区（sector），是==磁盘读写的最小单位==，传统扇区==512B==，较新磁盘为4KB
- **柱面**：所有盘面上==相同编号的磁道==构成一个柱面（cylinder）。==同一柱面的数据可以不移动磁头依次读取==（只需电子切换磁头），所以柱面是顺序读写的最优单位

### 1.2 读写过程与存取时间
==**总存取时间 = 寻道时间 + 旋转延迟 + 传输时间**==

1. **寻道**：磁头臂移动，使磁头定位到指定磁道 → 耗时==寻道时间==（几ms，题目通常给出平均值）
2. **旋转延迟**：盘片旋转，使目标扇区转到磁头下 → 耗时==旋转延迟==。==平均值 = 转半圈时间 = $\dfrac{60}{转速(rpm)} \times \dfrac{1}{2}$ 秒==
3. **数据传输**：磁头读写数据 → 耗时==传输时间 = $\dfrac{数据量(B)}{传输速率(B/s)}$==

> [!warning] 易错点
> - ==旋转延迟的平均值是半圈时间==，不是一圈（最坏一圈，最好0，平均1/2圈）
> - 转速单位rpm（转/分钟）需÷60转换为r/s，不能直接当Hz用
> - 传输时间虽然比前两项小得多，但题目要求精确计算时不能省略

**传输速率计算**：
$$
传输速率 = \frac{每磁道容量}{旋转一周时间} = \frac{每磁道扇区数 \times 扇区大小}{\dfrac{60}{转速(rpm)}}
$$

**例**：转速7200rpm，每磁道200个扇区，每扇区512B
- 每磁道容量 = 200 × 512B = 100KB
- 旋转一圈时间 = 60 ÷ 7200 = 8.33ms
- 传输速率 = 100KB ÷ 8.33ms = 12MB/s

### 1.3 磁盘地址
**物理地址三元组**：`(柱面号, 盘面号, 扇区号)` 或 `(磁道号, 盘面号, 扇区号)`

**逻辑块地址（LBA）**：OS把磁盘抽象成==线性的逻辑块序列==，从0开始编号。磁盘控制器负责把LBA转换成物理地址。

转换公式（假设每磁道S个扇区，共H个盘面）：
$$
\text{LBA} = (\text{柱面号} \times H + \text{盘面号}) \times S + \text{扇区号}
$$

### 1.4 磁盘容量
$$
\text{总容量} = \text{盘面数} \times \text{每面磁道数} \times \text{每道扇区数} \times \text{每扇区字节数}
$$

> [!warning] 易错点
> - ==盘片数 ≠ 盘面数==（一个盘片 = 2个盘面）
> - 计算时容易忘记乘盘面数

**例**：3个盘片，每面1000磁道，每道200扇区，每扇区512B
$$
容量 = (3 \times 2) \times 1000 \times 200 \times 512B = 6 \times 1000 \times 200 \times 512B = 600MB
$$

## 2. 磁盘初始化（OS）
磁盘使用前需要三步：==低级格式化（出厂完成）→ 分区 → 高级格式化==

**低级格式化（物理格式化）**：出厂时完成，在盘面上==划分磁道和扇区==，写入扇区标识、校验码、间隙等控制信息。用户一般不做。

**分区**：把磁盘划分成一个或多个==逻辑卷（分区）==，每个分区可以安装不同的文件系统或OS。分区信息记录在==MBR的分区表==中。

**高级格式化（逻辑格式化）**：在分区上建立文件系统，写入==超级块、空闲块管理结构（位示图/空闲链表）、根目录==等元数据。`mkfs`、`format`命令做的就是这个。

## 3. 磁盘调度算法（OS）
目标：==减少寻道时间==（旋转延迟无法通过调度改变）。磁盘请求队列中每个请求指定要访问的柱面号，调度算法决定响应顺序。

假设磁道编号0~199，当前磁头在100号磁道，请求队列为：`55, 58, 39, 18, 90, 160, 150, 38, 184`

### 3.1 FCFS（先来先服务）
按请求到达顺序响应。
- 移动序列：`100 → 55 → 58 → 39 → 18 → 90 → 160 → 150 → 38 → 184`
- 总移动磁道数：45+3+19+21+72+70+10+112+146 = 498
- 优点：公平
- 缺点：==平均寻道时间长==，磁头大幅度来回移动
         
### 3.2 SSTF（最短寻道时间优先）
每次选择==距当前磁头位置最近==的请求（贪心）。
- 移动序列：`100 → 90 → 58 → 55 → 39 → 38 → 18 → 150 → 160 → 184`
- 总移动磁道数：10+32+3+16+1+20+132+10+24 = 248
- 优点：平均寻道时间短
- 缺点：==可能饥饿==，远离磁头的请求可能长期得不到服务

### 3.3 SCAN（扫描算法/电梯算法）
磁头沿==一个方向==移动，处理路径上的所有请求，到达边界后==反向扫描==。

假设初始向磁道号增大方向移动：
- 移动序列：`100 → 150 → 160 → 184 → 199（边界）→ 90 → 58 → 55 → 39 → 38 → 18`
- 总移动磁道数：(199-100) + (199-18) = 99 + 181 = 280
- 优点：==不会饥饿==，响应时间方差小
- 缺点：刚扫描过的区域如果立即又有请求，需等磁头反向回来

> [!tip] 核心思想
> 类似电梯：到顶再下，到底再上，沿途响应。

### 3.4 C-SCAN（循环扫描）
磁头单向移动（如始终向磁道号增大方向），到达边界后==直接返回起点==，不沿途响应，然后继续单向扫描。

- 移动序列：`100 → 150 → 160 → 184 → 199 → 0（直接返回）→ 18 → 38 → 39 → 55 → 58 → 90`
- 总移动磁道数：(199-100) + 199 + (90-0) = 99 + 199 + 90 = 388
- 优点：==响应时间更均匀==，两端磁道的请求不会等很久
- 缺点：返回时不响应请求，总移动距离可能更长

### 3.5 LOOK / C-LOOK
SCAN和C-SCAN的改进：磁头==不必到达边界==，只需到达==当前方向上的最后一个请求==即可反向或返回。

**LOOK**（基于SCAN）：
- 移动序列：`100 → 150 → 160 → 184 → 90 → 58 → 55 → 39 → 38 → 18`
- 总移动磁道数：(184-100) + (184-18) = 84 + 166 = 250

**C-LOOK**（基于C-SCAN）：
- 移动序列：`100 → 150 → 160 → 184 → 18（直接跳到最小请求）→ 38 → 39 → 55 → 58 → 90`
- 总移动磁道数：(184-100) + (184-18) + (90-18) = 84 + 166 + 72 = 322

> [!tip] 对比
> | 算法 | 平均寻道时间 | 公平性 | 特点 |
> |---|---|---|---|
> | FCFS | 长 | 最公平 | 可能大幅摆动 |
> | SSTF | 短 | ==可能饥饿== | 贪心，优先近的 |
> | SCAN | 中等 | 较公平 | ==电梯算法==，不会饥饿 |
> | C-SCAN | 中等 | ==最均匀== | 单向+返回，两端响应时间均匀 |
> | LOOK | 短 | 较公平 | SCAN改进，不到边界 |
> | C-LOOK | 中等 | 均匀 | C-SCAN改进，不到边界 |

> [!warning] 易错点
> - SSTF ==不是最优算法==，它是贪心策略，全局移动距离可能不是最小
> - SCAN到达边界是指==磁盘的物理边界（如0或199号磁道）==，LOOK是到==当前方向最后一个请求==
> - C-SCAN返回时==不响应请求==，直接跳到起点；C-LOOK直接跳到==最小请求位置==
> - ==磁盘调度只优化寻道时间，旋转延迟无法通过调度算法改变==

## 4. 磁盘高速缓存（OS）
**磁盘高速缓存（Disk Cache）**：在==内存==中划出一块区域，用于==缓存磁盘中的数据块==。读盘时先查缓存，命中则不访问磁盘；写盘时先写缓存，再按策略同步到磁盘。目标是==减少磁盘访问次数==。

**与缓冲区的区别**：
- **缓冲区（Buffer）**：设备独立性软件管理，用于==弥补CPU与设备的速度差==，数据从设备到缓冲区，进程取走后缓冲区就空了。==缓冲区是数据的中转站==，一次性使用
- **磁盘高速缓存（Cache）**：文件系统管理，用于==减少磁盘访问次数==，缓存的是==磁盘块的副本==，可能被多个进程共享读取。==高速缓存是数据的备份==，可重复命中
- **控制器数据寄存器**：硬件，容量极小（几字节），设备与CPU的接口

> [!warning] 易错点
> ==磁盘高速缓存、缓冲区、控制器数据寄存器==三者都在数据通路上，但层次和用途不同：
> - **控制器数据寄存器**：容量几字节，硬件缓冲
> - **缓冲区**：容量几KB到几MB，速度匹配，中转
> - **磁盘高速缓存**：容量几百MB到GB，减少IO，备份

**写策略**：
- **写回（Write Back）**：数据写入缓存即返回，==缓存与磁盘不一致==，定期或缓存块被替换时才写回磁盘。快，但==断电可能丢数据==
- **写穿（Write Through）**：数据同时写入缓存和磁盘，==缓存与磁盘始终一致==。慢，但安全

## 5. 固态硬盘（SSD）（OS + 计组）
**固态硬盘（SSD）**：由==闪存（Flash Memory）芯片==组成，==无机械部件==，常用==NAND闪存==。

### 5.1 存储层次
- **页（Page）**：==读写的基本单位==，通常==4KB或8KB==
- **块（Block）**：==擦除的基本单位==，通常==128~256页==（512KB~2MB）
- **平面/芯片**：多个块组成

> [!warning] 易错点
> ==SSD的"块"不是文件系统的"块"==，这里的块是闪存芯片的擦除单位，远大于文件系统块（4KB）。

### 5.2 读写特性
**读**：可以按页随机读，速度快，延迟低（微秒级）

**写**：==必须先擦除整个块，再按页写入==
- 擦除慢（毫秒级）
- ==擦除次数有限==（几千到几万次）
- 写操作采用==异地更新==：修改数据时不在原地覆盖，而是写到新位置，旧数据标记为无效，需要==垃圾回收==整理无效数据

**写放大（Write Amplification）**：
修改4KB数据可能需要读出整个块（512KB）、擦除、写回，==实际写入量远大于逻辑写入量==。垃圾回收也会加剧写放大。

### 5.3 磨损均衡（Wear Leveling）
闪存块擦除次数有限，频繁写入同一块会使其提前失效。SSD控制器通过==磨损均衡算法==把写操作均匀分散到所有块，延长寿命。

**动态磨损均衡**：对==被动态使用的块==（即正在被频繁写入的块）进行均衡，把新数据优先写到擦除次数少的块。

**静态磨损均衡**：包含==静态数据块==（长期不被修改的数据，如操作系统文件）的均衡。SSD会定期把静态数据搬移到擦除次数多的块，把擦除次数少的块腾出来给动态数据用，确保==所有块的擦除次数趋于一致==。

> 静态磨损均衡比动态磨损均衡更彻底，但会增加额外的数据搬移开销。

### 5.4 HDD vs SSD对比
| 特性 | HDD（机械硬盘） | SSD（固态硬盘） |
|---|---|---|
| 结构 | 盘片+磁头，机械运动 | 闪存芯片，==无机械部件== |
| 随机读写 | 慢（需寻道+旋转，ms级） | ==快（无机械延迟，μs级）== |
| 顺序读写 | 较快 | 更快 |
| 读写对称性 | 读写速度接近 | ==写比读慢==（需先擦除） |
| 寿命限制 | 机械磨损 | ==擦除次数限制== |
| 功耗/噪音 | 高/有 | 低/无 |
| 抗震 | 差 | 强 |
| 价格 | 低 | 高 |
| 调度算法 | 需要（优化寻道时间） | ==不需要==（无寻道概念） |

> [!tip] 核心区别
> HDD的瓶颈是==寻道时间==，调度算法优化磁头移动；SSD无寻道，但有==擦除限制和写放大==，需要磨损均衡和垃圾回收。

## 6. 考点总结
**计组侧重**：磁盘结构、地址转换、==存取时间计算==（寻道+旋转+传输）、容量计算

**OS侧重**：==磁盘调度算法==（必考，计算移动磁道数）、磁盘初始化流程、磁盘高速缓存与缓冲区区别、SSD特性与磨损均衡

**常见题型**：
1. 给定请求序列，计算各调度算法的磁道移动数（FCFS/SSTF/SCAN/C-SCAN/LOOK）
2. 判断"磁盘高速缓存在哪一层"、"缓冲区的作用"、"三者的区别"
3. SSD与HDD的性能对比、SSD为什么需要磨损均衡、为什么写比读慢
4. 计算平均存取时间：寻道 + 旋转延迟（半圈） + 传输时间
5. DMA传输时的请求次数：总数据量 ÷ 总线宽度
