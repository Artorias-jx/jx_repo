## 2.2数制和编码

1. 二进制B，十进制D，十六机制H、0x
   二进制，八进制，十六进制互转的规则，3位或4位 
2. 十进制数转换为任意进制数：整数部分---除基取余法，小数部分---乘基取整法
   十进制到二进制凑值法，记住常用的二的幂次方数：2^16=65536
3. 不是每个十进制小数都可以准确的用二进制表示，反之可以，整数也可以
4. 真值 vs 机器数（0正1负）
5. 定点数（小数点位置固定，常规计数） vs 浮点数（科学计数法）
6. **定点数分类**
   **无符号数**：无符号位，全是数值位。n位无符号数表示范围：0 ~ 2n-1。 无符号数只有整数没有小数，unsigned int/long（float ×）
   **有符号数**：符号位+尾数。整数、小数部分分别保存，小数点分别在最后和符号位

7. **有符号数的编码方式**
   1. **原码**
      ![](assets/2.计算机组成原理笔记1/file-20260514175921696.png)
   2. **补码**
      ![](assets/2.计算机组成原理笔记1/file-20260514180114456.png)
      - 补码的特点：同为正数或负数的情况下：仅看数值位，数值位的值越大，真值越大
      - 理解：补码里，把符号位也当成数值位的一部分，整个数就是一个"二进制里程表"。
      - 里程表从000...0(0）一直往上滚，滚过最大值011...1（最大正数），再滚一步变成100...0（最小负数），继续滚到111...1(-1)，再一步回到000...0。
      - 所以补码编码是完全单调的——二进制编码越大，真值越大，和正数负数没关系。
   3. **反码**
      ![](assets/2.计算机组成原理笔记1/file-20260514180310291.png)
   4. **移码**
      ![](assets/2.计算机组成原理笔记1/file-20260514214420333.png)
      移码的偏置位的理解: n+1字长的补码，只能用n位，表示范围 $-2^n \sim 2^n-1$，偏置值其实就是把符号位当做数值位为 $2^n$，移码值就是真值加上偏置值
      对于移码和真值大小的理解：真值从最小值-128 （移码0000 0000）到 0 （移码1000 0000）到最大真值 127（移码 1111 1111）。真值和移码是**单调递增**的一一对应关系——移码的二进制编码越大，对应的真值就越大
      移码和补码的关系：移码 = 补码的符号位取反。例如 8 位中，$+1$ 的补码 0000 0001 → 移码 1000 0001；$-1$ 的补码 1111 1111 → 移码 0111 1111，移码里面0开头是负数，补码里面0开头是正数。

对阶特殊情况：大数吃小数。float/double：大-小>24/53，则小阶数右移后有效位全部丢失，则出现结果为大阶数的情况
舍入：考试默认为就近舍入。IEEE754规定尾数“对阶”时，至少额外保留3bit冗余位。
	冗余位第一位为0，则舍去；第一位为1，后面至少有一个不为0，则进1，若为100，则看尾数最后一位为1还是0，为0则截断反之+1。
溢出：浮点数溢出实际上只有阶码溢出，尾数溢出可通过右规处理。
	上溢：尾数相加结果大于2，或者尾数舍入+1时。阶码左移时可出现
	下溢：左规时尾数左移，阶码-1。若阶码表示超过最小规格化阶码数（-126/-1022），则发生下溢

## 2.7 不同类型数据转化
1. int -> float：float含隐藏位仅24位有效位，而int有32位，int的二进制有效位大于24时，转float会发生精度缺失。
2. int/float -> double：后者有效位更多，一般都可精准表示
3. double -> float：一方面float表示范围小，另一方面float尾数有效位少，所以会溢出或者舍入导致精度缺失
4. float/double -> int：一方面小数部分会截断，另一方面数值大于int的话会整数溢出
# 6. 总线系统
## 6.1 总线概述
总线的特性：分时共享。总线分为主设备和分设备。
总线的分类：
1. 片内总线：连接芯片内部的总线。系统总线： 数据总线，双向，传输操作数，状态字，中断类型号等；地址总线，单向，cpu向主存或IO端口发出的地址；控制总线，单/双，电信号之类的控制信号。IO总线，通信总线。
2. 串行总线（长距离）和并行总线（段距离）
3. 同步总线和异步总线
IO总线的三种：
数据线：数据缓冲寄存器和命令/状态寄存器的内容（**命令字**，数据，状态信息），中断类型号
地址线：IO接口的内部寄存器（IO端口）的地址
控制线：控制信号，对IO端口进行读写控制
