# 11.9

## 数据结构

- **强连通分量**：每对顶点都能互相到达；一般加边越多，强连通分量越少，加点越多则越多。

## 计算机组成原理

- **芯片扩展地址计算**：地址分成「芯片号 | 块内地址」两段；容量按各段位数反推。
- **多重中断**：高优先级中断的处理过程中，中断屏蔽字会屏蔽优先级 ≤ 自己的中断。

## 操作系统

- **进程创建**：用户登录、作业调度、提供服务、应用请求；==创建原语执行中是创建态，执行完是就绪态==。
- **父子进程**：父进程可以终止子进程。
- **PV 操作**：能解决一切互斥，但==不能解决死锁==；注意是否是对称结构。
- **程序执行**：异步执行有不可再现性，同步没有。
- **共享段表**：==整个操作系统只有一个共享段表==。
- **页表访存**：每多一级页表就多一次访存；==二级页表共 3 次==（查两级页表 + 取数据）。
- **设备驱动程序**：运行在内核态，==不允许系统调用==。
- **磁盘读取**：先读一个记录，读取时间 = 旋转总时间 ÷ 每磁道记录数；再处理，==处理时磁盘仍在旋转==。

## 计算机网络

- **802.11**：通过 SIFS 机制保证 ACK 这类高优先级帧更早响应。
- **排序与重组**：排序由传输层完成，重组由网络层的目的主机完成。
- **SR 协议（选择重传）**：滑动窗口移动时，要看最左边（窗口首部）是否已经确认。
- **TCP 快速重传**：TCP 有重复 ACK，收到三次冗余 ACK 后会触发快速重传。
- **HTTP**：响应报文的实体主体部分可以为空。

**TCP 的四种计时器**：

| 计时器 | 作用 |
|---|---|
| 超时（重传） | 超时未确认就重传 |
| 持续（坚持） | 防止零窗口死锁 |
| 时间等待 | 保证释放连接可靠 |
| 保活 | 检测长期空闲的 TCP 连接是否有效 |

# 11.14

## 数据结构

- **二叉树遍历**：讨论遍历情况时把所有情况列清楚——在左子树还是右子树、左右有无孩子等。
- **分块查找求 ASL**：索引表和各块都用顺序查找、且块大小不均时，先算每块查找成功所需比较次数，再除以块数。例：第 1 块在索引表比 1 次，块内从 2 开始累加；第 2 块索引表比 2 次，块内从 3 开始累加……
- **单链表**：需要暂存前驱的思想；连续递增段直接按序遍历即可判断。

## 计算机组成原理

- **地址引脚与块内地址**：要看按什么编址、存储字长多少。按字节编址、存储字长 8 位时，块内地址不额外占地址位；存储字长 16 位时需多 1 位。
- **进制转换**：算的时候注意十进制与十六进制互转。
- **突发传输**：先判断一次突发能否传完，再决定要不要多次传输。
- **控制冒险**：J 型指令和 BEQ 指令都在 MEM 段更新 PC，所以一次控制冒险损失 3 个时钟周期（袁书）。

## 操作系统

- **是否需要内核服务**：一看边界，二查阶段，三看特权。
- **被屏蔽的信号**：也要被记录（置为未决）。
- **死锁检测**：系统资源分配图画出来后，有环就是有环，不用消除。
- **VFS**：通过 V 结点（vnode）对象中保存的操作函数指针来区分不同文件系统。
- **内核服务程序被中断**：执行内核服务程序时被中断，返回后仍回到内核服务程序。

## 计算机网络

- **已发出但未到达的数据量**：可用时间轴法，先算传输时延再分块；也可由时延带宽积判断——传输时延大于传播时延时，发完时时延带宽积是满的。
- **分层**：第 n+1 层使用第 n 层的服务，不需要知道第 n 层的具体细节。
- **IPv6 简写**：每组的前导 0 可省略；若有全 0 组，每组至少保留一个 0；用两个冒号省略中间的 0 只能省一次。
- **快恢复**：快重传（收到 3 个冗余 ACK，见 11.9）之后，把拥塞窗口和门限都缩小为原来的一半，再进入拥塞避免。
- **TCP ACK 的含义**：返回 ACK 只说明 ACK 之前的段已被存入缓存，不代表应用进程已经读取。
