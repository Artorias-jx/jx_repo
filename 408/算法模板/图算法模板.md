# 图算法模板

## 数据结构定义

### 邻接矩阵

```c
#define MaxVertexNum 100

typedef struct{
    int Vex[MaxVertexNum];              // 顶点表
    int Edge[MaxVertexNum][MaxVertexNum]; // 邻接矩阵
    int vexnum, arcnum;                  // 顶点数和边数
} MGraph;
```

### 邻接表

```c
typedef struct ArcNode{
    int adjvex;              // 边指向的顶点位置
    struct ArcNode *next;    // 下一条边
    int weight;              // 边的权重（可选）
} ArcNode;

typedef struct VNode{
    int data;                // 顶点信息
    ArcNode *first;          // 第一条边
} VNode, AdjList[MaxVertexNum];

typedef struct{
    AdjList vertices;        // 邻接表
    int vexnum, arcnum;      // 顶点数和边数
} ALGraph;
```

## 基础题

### 1. 实现连通图 G（以邻接表存储）的广度优先遍历（BFS）

**时间复杂度**：$O(n+e)$，空间复杂度：$O(n)$

```c
void BFS_ALGraph(ALGraph G, int v){
    bool visited[MaxVertexNum] = {false};
    int queue[MaxVertexNum];
    int front = 0, rear = 0;
    
    printf("BFS遍历（邻接表）：");
    visited[v] = true;
    printf("%d ", v);
    queue[rear++] = v;
    
    while (front < rear){
        int u = queue[front++];
        ArcNode *p = G.vertices[u].first;
        
        while (p != NULL){
            int w = p->adjvex;
            if (!visited[w]){
                visited[w] = true;
                printf("%d ", w);
                queue[rear++] = w;
            }
            p = p->next;
        }
    }
    printf("\n");
}
```

**要点**：
- 使用队列实现
- 从起点v开始，逐层访问邻接顶点
- visited数组防止重复访问

**时间复杂度**：$O(n^2)$，空间复杂度：$O(n)$

```c
void BFS_MGraph(MGraph G, int v){

    printf("BFS遍历（邻接矩阵）：");

    while (front < rear){
        int u = queue[front++];

                visited[w] = true;
                printf("%d ", w);
                queue[rear++] = w;
            }
        }
    }
    printf("\n");
}
```

**要点**：
- 邻接矩阵：需要遍历整行查找邻接顶点
- 时间复杂度较高：$O(n^2)$

### 3. 实现连通图 G（以邻接表存储）的深度优先遍历（DFS）

**时间复杂度**：$O(n+e)$，空间复杂度：$O(n)$

```c
void DFS_ALGraph(ALGraph G, int v, bool visited[]){
    visited[v] = true;
    printf("%d ", v);
    
    ArcNode *p = G.vertices[v].first;
    while (p != NULL){
        if (!visited[p->adjvex])
            DFS_ALGraph(G, p->adjvex, visited);
        p = p->next;
    }
}

void DFS_traverse_AL(ALGraph G){
    bool visited[MaxVertexNum] = {false};
    printf("DFS遍历（邻接表）：");
    
    for (int i = 0; i < G.vexnum; i++){
        if (!visited[i])
            DFS_ALGraph(G, i, visited);
    }
    printf("\n");
}
```

**要点**：
- 递归实现
- 访问当前顶点后，递归访问未访问的邻接顶点

### 5. 设计算法，求无向连通图距顶点 v 最远的一个结点（即路径长度最大）

**方法：BFS求最短路径，找距离最大的顶点**

**时间复杂度**：$O(n+e)$，空间复杂度：$O(n)$

```c
int find_farthest(ALGraph G, int v){
    int dist[MaxVertexNum];
    bool visited[MaxVertexNum] = {false};
    int queue[MaxVertexNum];
    int front = 0, rear = 0;
    
    // 初始化距离
    for (int i = 0; i < G.vexnum; i++)
        dist[i] = -1;
    
    dist[v] = 0;
    visited[v] = true;
    queue[rear++] = v;
    
    while (front < rear){
        int u = queue[front++];
        ArcNode *p = G.vertices[u].first;
        
        while (p != NULL){
            int w = p->adjvex;
            if (!visited[w]){
                visited[w] = true;
                dist[w] = dist[u] + 1;
                queue[rear++] = w;
            }
            p = p->next;
        }
    }
    
    // 找距离最大的顶点
    int maxDist = 0, farthest = v;
    for (int i = 0; i < G.vexnum; i++){
        if (dist[i] > maxDist){
            maxDist = dist[i];
            farthest = i;
        }
    }
    
    return farthest;
}
```

**要点**：
- BFS求出v到所有顶点的最短路径
- 找距离最大的顶点

### 7. 有向图采用邻接表存储，判断顶点 Vi 和顶点 Vj 之间是否存在路径

**时间复杂度**：$O(n+e)$，空间复杂度：$O(n)$

```c
bool has_path_DFS(ALGraph G, int i, int j, bool visited[]){
    if (i == j) return true;
    
    visited[i] = true;
    ArcNode *p = G.vertices[i].first;
    
    while (p != NULL){
        int w = p->adjvex;
        if (!visited[w]){
            if (has_path_DFS(G, w, j, visited))
                return true;
        }
        p = p->next;
    }
    
    return false;
}

bool has_path(ALGraph G, int i, int j){
    bool visited[MaxVertexNum] = {false};
    return has_path_DFS(G, i, j, visited);
}
```

**要点**：
- DFS从i开始搜索
- 如果能到达j，返回true

### 8. 在有向图中，如果顶点 r 到图中所有顶点都存在路径，则称 r 为图的根结点。编写代码输出有向图中所有根结点

**时间复杂度**：$O(n(n+e))$，空间复杂度：$O(n)$

```c
bool can_reach_all(ALGraph G, int v){
    bool visited[MaxVertexNum] = {false};
    DFS_component(G, v, visited);
    
    // 检查是否所有顶点都被访问
    for (int i = 0; i < G.vexnum; i++){
        if (!visited[i])
            return false;
    }
    
    return true;
}

void find_all_roots(ALGraph G){
    printf("图的根结点：");
    bool hasRoot = false;
    
    for (int i = 0; i < G.vexnum; i++){
        if (can_reach_all(G, i)){
            printf("%d ", i);
            hasRoot = true;
        }
    }
    
    if (!hasRoot)
        printf("无根结点");
    printf("\n");
}
```

**要点**：
- 对每个顶点进行DFS
- 如果能到达所有顶点，则是根结点

### 9. 有向图采用邻接表存储，计算每个顶点的入度和出度

**时间复杂度**：$O(n+e)$，空间复杂度：$O(n)$

```c
void calculate_degree(ALGraph G){
    int indegree[MaxVertexNum] = {0};
    int outdegree[MaxVertexNum] = {0};
    
    for (int i = 0; i < G.vexnum; i++){
        ArcNode *p = G.vertices[i].first;
        
        while (p != NULL){
            outdegree[i]++;
            indegree[p->adjvex]++;
            p = p->next;
        }
    }
    
    printf("顶点\t入度\t出度\n");
    for (int i = 0; i < G.vexnum; i++){
        printf("%d\t%d\t%d\n", i, indegree[i], outdegree[i]);
    }
}
```

**要点**：
- 出度：该顶点邻接表的边数
- 入度：其他顶点指向该顶点的边数

### 12. 输出有向图 Vi 顶点到 Vj 顶点所有简单路径

**时间复杂度**：$O(n!)$，空间复杂度：$O(n)$

```c
void find_all_paths(ALGraph G, int start, int end, bool visited[], int path[], int pathLen){
    visited[start] = true;
    path[pathLen++] = start;
    
    if (start == end){
        for (int i = 0; i < pathLen; i++)
            printf("%d ", path[i]);
        printf("\n");
    } else {
        ArcNode *p = G.vertices[start].first;
        while (p != NULL){
            if (!visited[p->adjvex])
                find_all_paths(G, p->adjvex, end, visited, path, pathLen);
            p = p->next;
        }
    }
    
    visited[start] = false;
    pathLen--;
}

void print_all_paths(ALGraph G, int start, int end){
    bool visited[MaxVertexNum] = {false};
    int path[MaxVertexNum];
    find_all_paths(G, start, end, visited, path, 0);
}
```

**要点**：
- DFS + 回溯
- 到达目标顶点时输出路径

### 13. 求不带权的无/有向图中 v 顶点到其他顶点的最短路径长度

**BFS求无权图的最短路径**

**时间复杂度**：$O(n+e)$，空间复杂度：$O(n)$

```c
void bfs_shortest_path(ALGraph G, int v){
    int dist[MaxVertexNum];
    bool visited[MaxVertexNum] = {false};
    int queue[MaxVertexNum];
    int front = 0, rear = 0;
    
    for (int i = 0; i < G.vexnum; i++)
        dist[i] = -1;
    
    dist[v] = 0;
    visited[v] = true;
    queue[rear++] = v;
    
    while (front < rear){
        int u = queue[front++];
        ArcNode *p = G.vertices[u].first;
        
        while (p != NULL){
            int w = p->adjvex;
            if (!visited[w]){
                visited[w] = true;
                dist[w] = dist[u] + 1;
                queue[rear++] = w;
            }
            p = p->next;
        }
    }
    
    printf("从顶点 %d 到各顶点的最短路径长度：\n", v);
    for (int i = 0; i < G.vexnum; i++){
        printf("到顶点 %d：%d\n", i, dist[i]);
    }
}
```

**要点**：
- BFS保证先访问到的路径是最短的

### 14. Floyd 求有/无向图的最短路径长度

**时间复杂度**：$O(n^3)$，空间复杂度：$O(n^2)$

```c
void floyd(MGraph G){
    int dist[MaxVertexNum][MaxVertexNum];
    
    for (int i = 0; i < G.vexnum; i++){
        for (int j = 0; j < G.vexnum; j++){
            if (i == j)
                dist[i][j] = 0;
            else if (G.Edge[i][j] != 0)
                dist[i][j] = G.Edge[i][j];
            else
                dist[i][j] = 99999;
        }
    }
    
    for (int k = 0; k < G.vexnum; k++){
        for (int i = 0; i < G.vexnum; i++){
            for (int j = 0; j < G.vexnum; j++){
                if (dist[i][k] + dist[k][j] < dist[i][j]){
                    dist[i][j] = dist[i][k] + dist[k][j];
                }
            }
        }
    }
    
    printf("最短路径矩阵：\n");
    for (int i = 0; i < G.vexnum; i++){
        for (int j = 0; j < G.vexnum; j++){
            printf("%d\t", dist[i][j]);
        }
        printf("\n");
    }
}
```

**要点**：
- 动态规划思想
- 枚举中间顶点k

### 15. 判断有向图是否有环（邻接表/邻接矩阵）

**方法：拓扑排序**

**时间复杂度**：$O(n+e)$，空间复杂度：$O(n)$

```c
bool has_cycle(ALGraph G){
    int indegree[MaxVertexNum] = {0};
    int queue[MaxVertexNum];
    int front = 0, rear = 0;
    int count = 0;
    
    for (int i = 0; i < G.vexnum; i++){
        ArcNode *p = G.vertices[i].first;
        while (p != NULL){
            indegree[p->adjvex]++;
            p = p->next;
        }
    }
    
    for (int i = 0; i < G.vexnum; i++){
        if (indegree[i] == 0)
            queue[rear++] = i;
    }
    
    while (front < rear){
        int v = queue[front++];
        count++;
        
        ArcNode *p = G.vertices[v].first;
        while (p != NULL){
            indegree[p->adjvex]--;
            if (indegree[p->adjvex] == 0)
                queue[rear++] = p->adjvex;
            p = p->next;
        }
    }
    
    return count < G.vexnum;
}
```

**要点**：
- 如果能完成拓扑排序，则无环

### 16. 给定一个有向图 G (顶点编号 0...n)，边 (u→v) 表示任务 u 必须在任务 v 之前完成。请输出一组字典序最小的一种可执行顺序

**拓扑排序 + 最小堆**

**时间复杂度**：$O((n+e) \log n)$，空间复杂度：$O(n)$

```c
void topological_sort_lexical(ALGraph G){
    int indegree[MaxVertexNum] = {0};
    
    for (int i = 0; i < G.vexnum; i++){
        ArcNode *p = G.vertices[i].first;
        while (p != NULL){
            indegree[p->adjvex]++;
            p = p->next;
        }
    }
    
    // 使用优先队列（最小堆）
    int heap[MaxVertexNum];
    int heapSize = 0;
    
    for (int i = 0; i < G.vexnum; i++){
        if (indegree[i] == 0)
            insert_heap(heap, &heapSize, i);
    }
    
    printf("拓扑序列：");
    while (heapSize > 0){
        int v = delete_min(heap, &heapSize);
        printf("%d ", v);
        
        ArcNode *p = G.vertices[v].first;
        while (p != NULL){
            indegree[p->adjvex]--;
            if (indegree[p->adjvex] == 0)
                insert_heap(heap, &heapSize, p->adjvex);
            p = p->next;
        }
    }
    printf("\n");
}
```

**要点**：
- 用最小堆代替队列
- 保证字典序最小

### 17. 判断无向图是否有环

**方法：DFS判断回边**

**时间复杂度**：$O(n+e)$，空间复杂度：$O(n)$

```c
bool dfs_cycle(ALGraph G, int v, int parent, bool visited[]){
    visited[v] = true;
    ArcNode *p = G.vertices[v].first;
    
    while (p != NULL){
        int w = p->adjvex;
        
        if (!visited[w]){
            if (dfs_cycle(G, w, v, visited))
                return true;
        } else if (w != parent){
            return true;
        }
        
        p = p->next;
    }
    
    return false;
}

bool has_cycle_undirected(ALGraph G){
    bool visited[MaxVertexNum] = {false};
    
    for (int i = 0; i < G.vexnum; i++){
        if (!visited[i]){
            if (dfs_cycle(G, i, -1, visited))
                return true;
        }
    }
    
    return false;
}
```

**要点**：
- DFS遍历，记录父结点
- 如果访问到已访问的顶点且不是父结点，则有环

## 总结

### 图的遍历

| 方法 | 数据结构 | 应用 |
|------|----------|------|
| BFS | 队列 | 最短路径（无权图）、层次遍历 |
| DFS | 栈/递归 | 连通性、路径、环检测 |

### 最短路径算法

| 算法 | 适用 | 时间复杂度 |
|------|------|------------|
| BFS | 无权图 | $O(n+e)$ |
| Dijkstra | 非负权图，单源 | $O(n^2)$ 或 $O((n+e)\log n)$ |
| Floyd | 所有顶点对 | $O(n^3)$ |

### 拓扑排序

- **应用**：任务调度、依赖关系
- **判环**：拓扑排序失败 ↔ 有环
- **字典序最小**：用最小堆代替队列
