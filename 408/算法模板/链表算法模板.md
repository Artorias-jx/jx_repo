# 链表算法模板

## 数据结构定义

```c
typedef struct LNode{
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

---

## 基础题

### 1. 对带头结点的单链表 L 头插/尾插一个值为 x 的节点

**头插法**

**时间复杂度**：$O(1)$，空间复杂度：$O(1)$

```c
void headInsert(LinkList L, int x){
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->data = x;
    s->next = L->next;
    L->next = s;
}
```

**尾插法**

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
void tailInsert(LinkList L, int x){
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->data = x;
    s->next = NULL;
    
    LNode *p = L;
    for (p = L; p->next; p = p->next);  // 找到尾结点
    p->next = s;
}
```

**要点**：
- 头插法：新结点插入到头结点之后，时间 $O(1)$
- 尾插法：需要遍历到尾部，时间 $O(n)$
- 优化：可以维护一个尾指针，使尾插法也达到 $O(1)$

### 2. 查找单链表中第一个值为 x 的结点

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
LNode* search(LinkList L, int x){
    for (LNode *p = L->next; p != NULL; p = p->next)
        if (p->data == x)
            return p;
    return NULL;
}
```

**要点**：
- 从第一个数据结点开始查找
- 找到返回指针，未找到返回 NULL

---

### 3. 试编写算法将带头结点的单链表就地逆置

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
void Reverse(LinkList L){
    LNode *p = L->next;
    L->next = NULL;
    
    while (p != NULL){
        LNode *r = p->next;
        p->next = L->next;
        L->next = p;
        p = r;
    }
}
```

**要点**：
- 使用头插法实现逆置
- 遍历原链表，每个结点依次头插到头结点后
- 需要保存下一个结点的指针

### 4. 删除单链表中第一个值为 x 的结点

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
bool del(LinkList L, int x){
    for (LNode *r = L; r->next; r = r->next)
        if (r->next->data == x){
            LNode *p = r->next;
            r->next = p->next;
            free(p);
            return true;
        }
    return false;
}
```

**要点**：
- 遍历时保存前驱结点
- 找到目标结点后，修改前驱的 next
- 释放被删除结点的内存

### 5. 对递增单链表 L，插入一个值为 x 的结点后，使其保持非递减有序

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
void InsertNode(LinkList L, int x) {
    LNode *p = (LNode*)malloc(sizeof(LNode));
    p->data = x;
    p->next = NULL;
    
    LNode *r;
    for (r = L; r->next && r->next->data < x; r = r->next);
    
    p->next = r->next;
    r->next = p;
}
```

**要点**：
- 找到第一个值 ≥ x 的结点位置
- 将新结点插入到该位置之前

### 6. 删除单链表 L 中最小值结点（多个选择第一个/默认认一）

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
void delete_min(LinkList L){
    LNode *pos = L;  // 最小值结点的前驱
    
    for (LNode *p = L; p->next; p = p->next)
        if (p->next->data < pos->next->data)
            pos = p;
    
    LNode *u = pos->next;
    pos->next = u->next;
    free(u);
}
```

**要点**：
- 遍历找到最小值结点的前驱
- 删除最小值结点

**拓展：将最小值结点与后继结点交换位置呢？（假设存在后继结点）**

```c
LNode *u = pos->next;
LNode *r = u->next;
u->next = r->next;
r->next = pos->next;
pos->next = r;
```

### 7. 删除循环单链表 L 中最小值结点（多个选择第一个/默认认一）

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
void delete_min_circular(LinkList L){
    LNode *pos = L;
    LNode *p = L;
    
    do {
        if (p->next->data < pos->next->data)
            pos = p;
        p = p->next;
    } while (p != L);
    
    LNode *u = pos->next;
    pos->next = u->next;
    free(u);
}
```

**要点**：
- 循环链表使用 `do...while (p != L)` 遍历
- 其余逻辑与单链表相同

### 8. 按递增有序输出单链表中各结点的数值，并释放结点所占空间

**时间复杂度**：$O(n^2)$，空间复杂度：$O(1)$

```c
void print_and_free(LinkList L){
    while (L->next != NULL){
        LNode *pos = L;
        
        for (LNode *p = L; p->next; p = p->next)
            if (p->next->data < pos->next->data)
                pos = p;
        
        printf("%d ", pos->next->data);
        
        LNode *u = pos->next;
        pos->next = u->next;
        free(u);
    }
    printf("\n");
    free(L);
}
```

**要点**：
- 每次找最小值，输出并删除
- 重复 n 次直到链表为空
- 时间复杂度 $O(n^2)$

### 9. 将一个带头结点双向链表中值最小的结点插入到整个链表的最前面

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
typedef struct DNode{
    int data;
    struct DNode *prior, *next;
} DNode, *DLinkList;

void move_min_to_front(DLinkList L){
    if (L->next == NULL) return;
    
    DNode *minNode = L->next;
    DNode *p = L->next->next;
    
    // 找到最小值结点
    while (p != NULL){
        if (p->data < minNode->data)
            minNode = p;
        p = p->next;
    }
    
    // 如果最小值结点已经在最前面，无需移动
    if (minNode == L->next) return;
    
    // 从原位置删除
    minNode->prior->next = minNode->next;
    if (minNode->next != NULL)
        minNode->next->prior = minNode->prior;
    
    // 插入到最前面
    minNode->next = L->next;
    minNode->prior = L;
    L->next->prior = minNode;
    L->next = minNode;
}
```

**要点**：
- 遍历找到最小值结点
- 从原位置删除（修改前驱和后继的指针）
- 插入到头结点之后
- 双向链表需要维护prior和next两个指针

## 强化题

### 10. 删除单链表中所有值为 x 的结点

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
void delete_all_x(LinkList L, int x){
    LNode *p = L->next;
    LNode *pre = L;
    
    while (p != NULL){
        if (p->data == x){
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            pre = p;
            p = p->next;
        }
    }
}
```

**要点**：
- 需要前驱指针 pre
- 删除后 p 移到下一个结点，pre 不动
- 不删除时 pre 和 p 都后移

### 11. 尽可能高效地删除单链表中重复的结点，仅保留第一个

**时间复杂度**：$O(n^2)$，空间复杂度：$O(1)$

```c
void delete_duplicate(LinkList L){
    LNode *p = L->next;
    
    while (p != NULL){
        LNode *q = p->next;
        LNode *pre = p;
        
        while (q != NULL){
            if (q->data == p->data){
                pre->next = q->next;
                free(q);
                q = pre->next;
            } else {
                pre = q;
                q = q->next;
            }
        }
        p = p->next;
    }
}
```

### 12. 尽可能高效地删除递增链表中重复的结点，仅保留第一个

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
void delete_duplicate_sorted(LinkList L) {
    LNode *p = L->next;
    if (p == NULL) return; // 空表保护

    while (p->next != NULL) {
        // 如果当前结点与后继结点值相同，直接删除后继结点
        if (p->data == p->next->data) {
            LNode *q = p->next;
            p->next = q->next; // 跨过重复结点
            free(q);           // 释放内存
            // 注意：此时 p 不后移，下一轮继续拿 p 和新的 p->next 比较（处理连续多个相同值）
        } else {
            p = p->next;       // 不相同时，p 才往后移
        }
    }
}

```

**要点**：
- 有序链表中，重复元素相邻
- 只需比较相邻结点即可

### 13. 将一个带头结点的单链表 A 分解成两个带头结点的单链表 A 和 B，使 A 中保留值大于等于 0 的结点，B 中为小于 0 的结点

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
LinkList split_positive_negative(LinkList A){
    LinkList B = (LinkList)malloc(sizeof(LNode));
    B->next = NULL;
    
    LNode *tailB = B;
    LNode *p = A->next;
    LNode *pre = A;
    
    while (p != NULL){
        if (p->data < 0){
            pre->next = p->next;
            tailB->next = p;
            tailB = p;
            p = pre->next;
            tailB->next = NULL;
        } else {
            pre = p;
            p = p->next;
        }
    }
    
    return B;
}
```

**要点**：
- 使用尾插法创建链表B
- 维护B的尾指针
- 从A中删除的结点直接插入B

### 14. 将单链表{a1,b1,a2,b2,...,an,bn}拆成{a1,a2,...,an}和{b1,b2,...,bn}

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
LinkList split_alternate(LinkList A){
    LinkList B = (LinkList)malloc(sizeof(LNode));
    B->next = NULL;
    
    LNode *tailA = A;
    LNode *tailB = B;
    LNode *p = A->next;
    int count = 1;
    
    while (p != NULL){
        if (count % 2 == 1){  // 奇数位置，留在A
            tailA->next = p;
            tailA = p;
        } else {              // 偶数位置，放到B
            tailB->next = p;
            tailB = p;
        }
        p = p->next;
        count++;
    }
    
    tailA->next = NULL;
    tailB->next = NULL;
    
    return B;
}
```

**要点**：
- 用计数器判断奇偶位置
- 分别维护A和B的尾指针

### 15. 将单链表{a1,b1,a2,b2,...,an,bn}拆成{a1,a2,...,an}和{bn,bn-1,...,b1}

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
LinkList split_alternate_reverse(LinkList A){
    LinkList B = (LinkList)malloc(sizeof(LNode));
    B->next = NULL;
    
    LNode *tailA = A;
    LNode *p = A->next;
    int count = 1;
    
    while (p != NULL){
        LNode *next = p->next;
        if (count % 2 == 1){  // 奇数位置，尾插到A
            tailA->next = p;
            tailA = p;
        } else {              // 偶数位置，头插到B
            p->next = B->next;
            B->next = p;
        }
        p = next;
        count++;
    }
    
    tailA->next = NULL;
    
    return B;
}
```

**要点**：
- A链表用尾插法保持原顺序
- B链表用头插法实现逆序

### 16. 两个递增有序的单链表，将 B 合并到 A 中，仍保证非递减有序

**时间复杂度**：$O(n+m)$，空间复杂度：$O(1)$

```c
void merge_sorted(LinkList A, LinkList B){
    LNode *pa = A->next;
    LNode *pb = B->next;
    LNode *tail = A;
    
    while (pa != NULL && pb != NULL){
        if (pa->data <= pb->data){
            tail->next = pa;
            tail = pa;
            pa = pa->next;
        } else {
            tail->next = pb;
            tail = pb;
            pb = pb->next;
        }
    }
    
    if (pa != NULL)
        tail->next = pa;
    else
        tail->next = pb;
    
    free(B);
}
```

**要点**：
- 双指针分别遍历A和B
- 比较当前结点，小的接到结果链表
- 某个链表遍历完后，直接连接另一个链表的剩余部分

### 17. 两个递增有序的单链表，将 B 合并到 A 中，保证非递增有序

**时间复杂度**：$O(n+m)$，空间复杂度：$O(1)$

```c
void merge_sorted_desc(LinkList A, LinkList B){
    LNode *pa = A->next;
    LNode *pb = B->next;
    A->next = NULL;
    
    while (pa != NULL && pb != NULL){
        if (pa->data <= pb->data){
            LNode *temp = pa->next;
            pa->next = A->next;
            A->next = pa;
            pa = temp;
        } else {
            LNode *temp = pb->next;
            pb->next = A->next;
            A->next = pb;
            pb = temp;
        }
    }
    
    while (pa != NULL){
        LNode *temp = pa->next;
        pa->next = A->next;
        A->next = pa;
        pa = temp;
    }
    
    while (pb != NULL){
        LNode *temp = pb->next;
        pb->next = A->next;
        A->next = pb;
        pb = temp;
    }
    
    free(B);
}
```

**要点**：
- 使用头插法实现逆序
- 每次选择较小的元素头插到A

### 18. A、B 两个单链表递增有序，从 A、B 中找出公共元素产生单链表 C

**时间复杂度**：$O(n+m)$，空间复杂度：$O(k)$

```c
LinkList find_common(LinkList A, LinkList B){
    LinkList C = (LinkList)malloc(sizeof(LNode));
    C->next = NULL;
    
    LNode *pa = A->next;
    LNode *pb = B->next;
    LNode *tail = C;
    
    while (pa != NULL && pb != NULL){
        if (pa->data < pb->data){
            pa = pa->next;
        } else if (pa->data > pb->data){
            pb = pb->next;
        } else {
            LNode *s = (LNode*)malloc(sizeof(LNode));
            s->data = pa->data;
            tail->next = s;
            tail = s;
            pa = pa->next;
            pb = pb->next;
        }
    }
    
    tail->next = NULL;
    return C;
}
```

**要点**：
- 双指针同时遍历A和B
- 较小的指针后移
- 相等时创建新结点加入C

### 19. 只进行一次遍历，打印链表最中间结点的值（链表结点个数为奇数）

**快慢指针**

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
void print_middle(LinkList L){
    if (L->next == NULL) return;
    
    LNode *slow = L->next;
    LNode *fast = L->next;
    
    while (fast != NULL && fast->next != NULL){
        slow = slow->next;
        fast = fast->next->next;
    }
    
    printf("中间结点的值：%d\n", slow->data);
}
```

**要点**：
- slow每次走1步，fast每次走2步
- fast到达末尾时，slow正好在中间

### 20. 单链表有环，是指单链表的最后一个结点的指针指向了链表中的某个结点。编写算法判断单链表是否有环

**Floyd判圈算法（快慢指针）**

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
bool has_cycle(LinkList L){
    if (L->next == NULL) return false;
    
    LNode *slow = L->next;
    LNode *fast = L->next;
    
    while (fast != NULL && fast->next != NULL){
        slow = slow->next;
        fast = fast->next->next;
        
        if (slow == fast)
            return true;
    }
    
    return false;
}
```

**要点**：
- slow每次走1步，fast每次走2步
- 如果有环，fast最终会追上slow
- 如果无环，fast会先到达NULL

**拓展：找到环的入口点**

```c
LNode* find_cycle_entry(LinkList L){
    if (L->next == NULL) return NULL;
    
    LNode *slow = L->next;
    LNode *fast = L->next;
    
    while (fast != NULL && fast->next != NULL){
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) break;
    }
    
    if (fast == NULL || fast->next == NULL)
        return NULL;
    
    slow = L->next;
    while (slow != fast){
        slow = slow->next;
        fast = fast->next;
    }
    
    return slow;
}
```

### 21. 设计算法将链表 L 循环左移 k 个结点

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
void rotate_left(LinkList L, int k){
    if (L->next == NULL || k <= 0) return;
    
    LNode *tail = L->next;
    int len = 1;
    while (tail->next != NULL){
        tail = tail->next;
        len++;
    }
    
    k = k % len;
    if (k == 0) return;
    
    LNode *p = L->next;
    for (int i = 1; i < k; i++)
        p = p->next;
    
    tail->next = L->next;
    L->next = p->next;
    p->next = NULL;
}
```

**要点**：
- 找到链表尾结点和计算长度
- 找到第k个结点
- 调整指针完成循环左移

### 22. 多项式以单链表按指数升序存储（不含零系数项），现给定两个带头结点的单链表 A 与 B，请将 B 就地并入 A 得到和多项式 A+B

**多项式结点结构**：

```c
typedef struct PolyNode{
    double coef;  // 系数
    int exp;      // 指数
    struct PolyNode *next;
} PolyNode, *Polynomial;
```

**时间复杂度**：$O(n+m)$，空间复杂度：$O(1)$

```c
void add_polynomial(Polynomial A, Polynomial B){
    PolyNode *pa = A->next;
    PolyNode *pb = B->next;
    PolyNode *pre = A;
    
    while (pa != NULL && pb != NULL){
        if (pa->exp < pb->exp){
            pre = pa;
            pa = pa->next;
        } else if (pa->exp > pb->exp){
            pre->next = pb;
            pb = pb->next;
            pre->next->next = pa;
            pre = pre->next;
        } else {
            pa->coef += pb->coef;
            if (pa->coef == 0){
                pre->next = pa->next;
                free(pa);
                pa = pre->next;
            } else {
                pre = pa;
                pa = pa->next;
            }
            PolyNode *temp = pb;
            pb = pb->next;
            free(temp);
        }
    }
    
    if (pb != NULL)
        pre->next = pb;
    
    free(B);
}
```

**要点**：
- 比较指数大小，决定操作
- 指数相等时，系数相加
- 系数为0的项要删除
- 就地合并，不申请新空间

## 总结

### 常用技巧

1. **双指针法**：用于删除、合并等问题
2. **快慢指针**：找中间结点、判断环
3. **头插法与尾插法**：控制插入顺序
4. **前驱指针**：删除结点必备

### 链表 vs 顺序表

| 操作 | 顺序表 | 链表 |
|------|--------|------|
| 按位查找 | $O(1)$ | $O(n)$ |
| 按值查找 | $O(n)$ | $O(n)$ |
| 插入（已知位置） | $O(n)$ | $O(1)$ |
| 删除（已知位置） | $O(n)$ | $O(1)$ |

### 常见错误

1. 忘记释放内存
2. 空指针检查
3. 尾结点next未置NULL
4. 前驱指针未更新
5. 循环条件错误
