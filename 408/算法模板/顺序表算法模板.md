# 顺序表算法模板
## 数据结构定义

```c
#define maxsize 50
typedef struct{
    int data[maxsize];
    int length;
} Sqlist;
```

## 基础题
## 1. 在顺序表 L 的第 k 个位置插入元素 x

**时间复杂度**：$O(n)$ 和 $O(1)$（如果是数组呢？）

```c
bool insert_x(Sqlist *L, int k, int x){
    if (k < 1 || k > L->length+1 || L->length >= maxsize)  // k 的合法区间是 [1, length+1]；表满也不能插入
        return false;
    
    for (int i = L->length-1; i >= k-1; i--)  // 从最后一个元素起逐个后移一位，必须倒着来（从后往前）否则会被覆盖
        L->data[i+1] = L->data[i];
    
    L->data[k-1] = x;   // “第 k 个位置”对应下标 k-1
    L->length++;
    return true;
}
```

**要点**：
- 判断插入位置是否合法：`k < 1 || k > L->length+1`
- 判断顺序表是否已满：`L->length >= maxsize`
- 从后往前移动元素，避免覆盖
- 数组下标从 0 开始，第 k 个位置对应下标 `k-1`

## 2. 将顺序表中的元素逆置

**时间复杂度**：$O(n)$ 和 $O(1)$

```c
void Reverse(Sqlist *L){
    for (int i = 0, j = L->length -1; i < j; i++, j--){  // 头尾双指针相向走，i==j（奇数个）或 i>j（偶数个）时停止
        int temp = L->data[i];      // 交换一对对称位置的元素
        L->data[i] = L->data[j];
        L->data[j] = temp;
    }
}
```

**要点**：
- 双指针从两端向中间移动
- 交换元素使用临时变量
- 循环条件：`i < j`

## 3. 查找顺序表中第一个值为 x 的元素的位置（和索引有区别）

**时间复杂度**：$O(n)$ 和 $O(1)$

```c
int find_x(Sqlist L, int x){
    for (int i = 0; i < L.length; i++)   // 从下标 0 开始顺序查找
        if (L.data[i] == x) 
            return i + 1;  // 返回“位置”（从 1 开始），不是“下标”
    return -1;  // 未找到
}
```

**要点**：
- 返回**位置**（从 1 开始），不是**下标**（从 0 开始）
- 未找到返回 -1
- 如果要返回下标，改为 `return i`

## 4. 删除顺序表中值为 x 的元素（仅有一个 x）

**时间复杂度**：$O(n)$ 和 $O(1)$（如果有多个 x 呢？强化会讲）

```c
bool del_x(Sqlist *L, int x){
    for (int i = 0; i < L->length; i++)
        if (L->data[i] == x){
            for (int j = i + 1; j < L->length; j++)   // 找到后，其后的元素整体前移一位
                L->data[j - 1] = L->data[j];
            L->length--;      // 长度减一
            return true;      // 只删第一个匹配的，立即返回
        }
    return false;
}
```

**要点**：
- 先查找元素位置
- 从删除位置开始，后续元素依次前移
- 长度减 1
- 未找到返回 false

## 5. 顺序表递增有序，插入元素 x，仍递增有序（非递减）

**时间复杂度**：$O(n)$ 和 $O(1)$（学完二分，还可以优化）

```c
void insert_L(Sqlist *L, int x) {
    int pos;
    for (pos = 0; pos < L->length && L->data[pos] < x; pos++);  // 空循环：定位第一个 ≥ x 的位置 pos
    
    for (int i = L->length - 1; i >= pos; i--)   // 从后往前把 [pos, length-1] 整体后移一位
        L->data[i + 1] = L->data[i];
    
    L->data[pos] = x;
    L->length++;
}
```

**要点**：
- 先找到插入位置 pos（第一个 ≥ x 的位置）
- 从后往前移动元素，为新元素腾出空间
- 插入元素并更新长度
- 优化：可以用二分查找定位插入位置

## 6. 删除整个顺序表中最小的元素（若存在多个相同的最小元素，默认选择第一个）

**时间复杂度**：$O(n)$ 和 $O(1)$

```c
void delete_min(Sqlist *L){
    int min = 0;   // min 存的是“最小元素的下标”，不是最小值本身
    for (int i = 1; i < L->length; i++)
        if (L->data[i] < L->data[min])
            min = i;
    
    for (int i = min + 1; i < L->length; i++)   // 从最小值位置起，后续元素整体前移
        L->data[i - 1] = L->data[i];
    
    L->length--;
}
```

**要点**：
- 第一步：遍历找到最小元素的下标
- 第二步：从最小元素位置开始，后续元素前移
- 长度减 1

**拓展**：将最小元素和第一个元素进行交换呢？

```c
void delete_min(Sqlist *L){
    int min = 0;
    for (int i = 1; i < L->length; i++)
        if (L->data[i] < L->data[min])
            min = i;
    
    int temp = L->data[0];      // 直接交换最小值与第一个元素（min==0 时也成立）
    L->data[0] = L->data[min];
    L->data[min] = temp;
}
```

### 7. 删除所有值为 x 的元素

**方法1：逐个删除（效率低，不推荐）**
- 每找到一个 x 就执行一次删除操作
- 时间复杂度：$O(n^2)$

**方法2：双指针法（推荐）**

```c
void delete_all_x(Sqlist *L, int x){
    int k = 0;  // k = 已保留的非 x 元素个数，同时是下一个该写入的下标
    for (int i = 0; i < L->length; i++)
        if (L->data[i] != x)
            L->data[k++] = L->data[i];   // 非 x 就地前移；k 追上 i 时相当于原地不动
    L->length = k;   // 新长度 = 保留下的元素个数
}
```

**时间复杂度**：$O(n)$ 和 $O(1)$

**要点**：
- k 指针指向下一个非 x 元素应该存放的位置
- 遍历数组，遇到非 x 元素就放到 k 位置
- 最后更新长度为 k

### 8. 尽可能高效地从顺序表中删除所有值重复的元素，仅保留第一个

**前提**：顺序表**无序**

```c
void delete_duplicate(Sqlist *L){
    int k = 1;  // 前 k 个元素是“已去重”的结果区（首个元素天然保留）
    for (int i = 1; i < L->length; i++){
        bool isDuplicate = false;
        // 在已保留的 [0, k-1] 里查 data[i] 是否出现过
        for (int j = 0; j < k; j++){
            if (L->data[i] == L->data[j]){
                isDuplicate = true;
                break;   // 出现过 → 丢弃 data[i]
            }
        }
        if (!isDuplicate)
            L->data[k++] = L->data[i];   // 没出现过 → 追加进结果区
    }
    L->length = k;
}
```

**时间复杂度**：$O(n^2)$ 和 $O(1)$

### 9. 尽可能高效地从有序表中删除所有值重复的元素，仅保留第一个

**前提**：顺序表**有序**

```c
void delete_duplicate_sorted(Sqlist *L){
    int k = 1;  // 保留第一个元素；k-1 是“已保留的最后一个元素”的下标
    for (int i = 1; i < L->length; i++)
        if (L->data[i] != L->data[k-1])   // 有序表里重复元素相邻，只需和上一个保留的比
            L->data[k++] = L->data[i];
    L->length = k;
}
```

**时间复杂度**：$O(n)$ 和 $O(1)$

**要点**：
- 有序表中相同元素相邻
- 只需比较当前元素和前一个保留的元素
- k-1 指向最后一个保留的元素

### 10. 两个递增有序表合并成一个递增有序表

```c
bool merge_sorted(Sqlist LA, Sqlist LB, Sqlist *LC){
    if (LA.length + LB.length > maxsize)   // 结果放不下 → 失败
        return false;
    
    int i = 0, j = 0, k = 0;   // i→LA, j→LB, k→LC
    
    while (i < LA.length && j < LB.length){
        if (LA.data[i] <= LB.data[j])   // 取较小者；用 <= 保证稳定性
            LC->data[k++] = LA.data[i++];
        else
            LC->data[k++] = LB.data[j++];
    }
    
    while (i < LA.length)   // 谁没走完，把剩余整段搬过去
        LC->data[k++] = LA.data[i++];
    
    while (j < LB.length)
        LC->data[k++] = LB.data[j++];
    
    LC->length = k;
    return true;
}
```

**时间复杂度**：$O(n+m)$，空间复杂度：$O(1)$（不考虑结果数组）

**要点**：
- 三指针：i 指向 LA，j 指向 LB，k 指向 LC
- 比较两个指针所指元素，小的放入 LC
- 某一个数组遍历完后，将另一个数组剩余元素直接复制

### 11. 两个递增有序表合并成一个非递增有序表

```c
bool merge_sorted_desc(Sqlist LA, Sqlist LB, Sqlist *LC){
    if (LA.length + LB.length > maxsize)
        return false;
    
    int i = LA.length - 1, j = LB.length - 1, k = 0;   // 从两表“尾部”开始比
    
    while (i >= 0 && j >= 0){
        if (LA.data[i] >= LB.data[j])   // 每次挑较大的放到结果前端
            LC->data[k++] = LA.data[i--];
        else
            LC->data[k++] = LB.data[j--];
    }
    
    while (i >= 0)
        LC->data[k++] = LA.data[i--];
    
    while (j >= 0)
        LC->data[k++] = LB.data[j--];
    
    LC->length = k;
    return true;
}
```

**时间复杂度**：$O(n+m)$，空间复杂度：$O(1)$

**要点**：
- 从两个递增序列的**尾部**开始比较
- 每次选择较大的元素放入结果数组
- 得到的是非递增（递减）序列

### 12. 三个序列 A、B、C 长度均为 n，且均为无重复元素的递增序列，输出三个序列中共同存在的所有元素（三指针）

```c
void find_common(Sqlist A, Sqlist B, Sqlist C){
    int i = 0, j = 0, k = 0;   // 三指针分别指向 A、B、C
    
    while (i < A.length && j < B.length && k < C.length){
        if (A.data[i] == B.data[j] && B.data[j] == C.data[k]){
            printf("%d ", A.data[i]);   // 三者相等 → 是公共元素，一起后移
            i++; j++; k++;
        }
        else{
            int minVal = A.data[i];     // 取三者最小值
            if (B.data[j] < minVal) minVal = B.data[j];
            if (C.data[k] < minVal) minVal = C.data[k];
            
            if (A.data[i] == minVal) i++;   // 最小值所在的序列往前走（它不可能再成为公共元素）
            if (B.data[j] == minVal) j++;
            if (C.data[k] == minVal) k++;
        }
    }
}
```

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

**要点**：
- 三个指针分别指向三个序列
- 如果三个元素相等，输出并三个指针都后移
- 否则，找到最小的元素，将对应指针后移
- 利用有序性，最小元素不可能是共同元素

### 13. 将数组中所有负数移动到数组最前端，所有非负数移动到最后端

**快速排序的 partition 思想**

```c
void move_negative(Sqlist *L){
    int i = 0, j = L->length - 1;
    
    while (i < j){
        while (i < j && L->data[i] < 0) i++;  // i 停在第一个“非负数”上
        while (i < j && L->data[j] >= 0) j--; // j 停在最后一个“负数”上
        
        if (i < j){          // 左边非负、右边负 → 交换，让负数整体靠前
            int temp = L->data[i];
            L->data[i] = L->data[j];
            L->data[j] = temp;
        }
    }
}
```

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

**要点**：
- 双指针从两端向中间移动
- i 找非负数，j 找负数，找到后交换
- 类似快速排序的 partition 过程

### 14. 重排数组，奇数位置放奇数，偶数位置放偶数

```c
void rearrange_odd_even(Sqlist *L){
    int i = 0, j = L->length - 1;
    
    while (i < j){
        while (i < j && L->data[i] % 2 != 0) i++;  // i 停在第一个“偶数”上
        while (i < j && L->data[j] % 2 == 0) j--;  // j 停在最后一个“奇数”上
        
        if (i < j){          // 左偶右奇 → 交换，使奇数整体在前、偶数在后
            int temp = L->data[i];
            L->data[i] = L->data[j];
            L->data[j] = temp;
        }
    }
}
```

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

### 15. 将序列 (a1,a2,...,am,b1,b2,...,bn) 转换成 (b1,b2,...,bn,a1,a2,...,am)

**方法：三次逆置**

```c
void reverse_range(Sqlist *L, int left, int right){
    while (left < right){
        int temp = L->data[left];
        L->data[left] = L->data[right];
        L->data[right] = temp;
        left++;
        right--;
    }
}

void exchange(Sqlist *L, int m, int n){
    reverse_range(L, 0, m-1);        // 逆置前 m 个 → A⁻¹ B
    reverse_range(L, m, m+n-1);      // 逆置后 n 个 → A⁻¹ B⁻¹
    reverse_range(L, 0, m+n-1);      // 整体再逆置 → (A⁻¹B⁻¹)⁻¹ = BA
}
```

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

**原理**：
- $(a_1, a_2, ..., a_m, b_1, b_2, ..., b_n)$
- 逆置前m个：$(a_m, ..., a_2, a_1, b_1, b_2, ..., b_n)$
- 逆置后n个：$(a_m, ..., a_2, a_1, b_n, ..., b_2, b_1)$
- 整体逆置：$(b_1, b_2, ..., b_n, a_1, a_2, ..., a_m)$

### 16. 已知整数序列 A={a0,a1,...,an-1}，其中 0 ≤ ai < n (0 ≤ i < n)，设计时间上尽可能高效的算法，找出数组中存在重复的所有元素（一定存在）

**方法：利用下标映射**

```c
void find_duplicate(Sqlist L){
    int count[maxsize] = {0};  // count[v] = 值 v 出现的次数（利用 0 ≤ ai < n）
    
    for (int i = 0; i < L.length; i++)
        count[L.data[i]]++;      // 直接把元素值当计数下标（空间换时间）
    
    for (int i = 0; i < maxsize; i++)
        if (count[i] > 1)
            printf("%d ", i);    // 次数 > 1 即重复元素
}
```

**时间复杂度**：$O(n)$，空间复杂度：$O(n)$

**要点**：
- 利用元素值在 0~n-1 范围内的特点
- 用计数数组统计每个元素出现次数
- 出现次数 > 1 的就是重复元素

### 17. 给定一个 n (n > 2) 个元素的整数数组，打印相加和最小的两个数

```c
void find_min_sum_two(Sqlist L){
    int min1, min2;
    
    if (L.data[0] < L.data[1]){   // 先让 min1=最小、min2=次小
        min1 = L.data[0];
        min2 = L.data[1];
    } else {
        min1 = L.data[1];
        min2 = L.data[0];
    }
    
    for (int i = 2; i < L.length; i++){   // 一次遍历同时维护最小与次小
        if (L.data[i] < min1){            // 比最小还小 → 原最小降级为次小
            min2 = min1;
            min1 = L.data[i];
        } else if (L.data[i] < min2){     // 介于两者之间 → 只更新次小
            min2 = L.data[i];
        }
    }
    
    printf("最小的两个数：%d 和 %d，和为：%d\n", min1, min2, min1 + min2);
}
```

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

**要点**：
- 维护两个变量：min1（最小）、min2（次小）
- 遍历数组，更新最小和次小值
- 只需一次遍历

## 总结

### 常用技巧

1. **双指针法**：用于逆置、删除、分组等问题
2. **快慢指针**：用于删除重复元素
3. **三指针法**：用于合并、求交集等问题
4. **计数数组**：利用元素范围小的特点
5. **三次逆置**：用于数组循环移位

### 时间复杂度分析

- **单层循环**：$O(n)$
- **嵌套循环**：$O(n^2)$（可能需要优化）
- **二分查找**：$O(\log n)$
- **合并操作**：$O(n+m)$

### 空间复杂度优化

- 尽量**原地操作**，避免使用额外数组
- 使用**双指针**代替辅助空间
- 利用**元素范围**特点，使用计数数组（空间换时间）
