# 树算法模板

> 写在开头：关于树的题目，递归就能解决大部分。
> 递归的写法，先写出口，再选遍历方式。

1. 递归首要铁律：先写出口 。遇到空树 return ...;（视情况返回 0、NULL，true，false)
2. 三大方向的选择策略
**先序**（**根左右**）——自顶向下，带着信息往下走：
   **应用场景**：修改树结构（如翻转二叉树）、携带父级信息向下传递（如求特定值的层号、路径和检测）。
   **心法**：根结点先干活/定规则，左右子树跟着执行。
   **关键判断**：判断题目要求的操作==跟父结点有关==，用前序
**后序**（**左右根**）——自底向上，汇总子树结果：
   **应用场景**：树的高度、结点总数、判断是否为平衡二叉树（AVL）、LCA、后序销毁整棵树。
   **心法**：先让左右子树把局部解汇报上来，根结点拿着这两个解做合并计算再 return。
   **关键判断**：题目要求的操作==需要子树的结论才能做==，用后序，==拿不准就选后序，万能兜底==。
**中序**（**左根右**）——有序场景专用：
   **应用场景**：凡是出现 BST（二叉排序树） 字眼，直接无脑选中序遍历。求第k小，判断BST是否合法，有序转链表。
   **心法**：中序遍历BST＝从小到大有序访问，天然有序性直接利用。

### 1. 计算二叉树中所有结点个数

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
int count_nodes(BiTree T){
    if (T == NULL) return 0;   // 出口：空树 0 个结点
    return 1 + count_nodes(T->lchild) + count_nodes(T->rchild);   // 自己 + 左子树 + 右子树
}
```

**要点**：
- 递归思想：根(1) + 左子树结点数 + 右子树结点数
- 空树结点数为0

### 2. 计算二叉树中所有叶子结点的个数

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
int count_leaves(BiTree T){
    if (T == NULL) return 0;
    
    // 叶子结点：左右孩子都为空
    if (T->lchild == NULL && T->rchild == NULL)
        return 1;   // 叶子本身计 1
    
    return count_leaves(T->lchild) + count_leaves(T->rchild);   // 非叶子 → 汇总左右子树
}
```

**要点**：
- 叶子结点：度为0的结点
- 左右孩子都为空

### 3. 计算二叉树中所有双分支的结点个数

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
int count_double_branch(BiTree T){
    if (T == NULL) return 0;
    
    int count = 0;
    
    // 双分支结点：左右孩子都不为空（度为 2）
    if (T->lchild != NULL && T->rchild != NULL)
        count = 1;
    
    return count + count_double_branch(T->lchild) + count_double_branch(T->rchild);
}
```

**要点**：
- 双分支结点：度为2的结点
- 左右孩子都不为空

### 4. 找出二叉树中值最大的结点

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
int find_max(BiTree T){
    if (T == NULL) return -99999;  // 空树返回“负无穷”，不干扰求最大值
    
    int max = T->data;                     // 后序：先取根
    int left_max = find_max(T->lchild);
    int right_max = find_max(T->rchild);
    
    if (left_max > max) max = left_max;    // 再与左右子树的最大值比
    if (right_max > max) max = right_max;
    
    return max;
}
```

**要点**：
- 递归比较：根、左子树最大值、右子树最大值
- 空树返回负无穷

### 5. 把二叉树所有结点左右子树交换

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
void swap_children(BiTree T){
    if (T == NULL) return;
    
    // 先交换当前结点的左右孩子（先序：根先动手）
    BiTree temp = T->lchild;
    T->lchild = T->rchild;
    T->rchild = temp;
    
    // 再递归处理左右子树
    swap_children(T->lchild);
    swap_children(T->rchild);
}
```

**要点**：
- 先序遍历思想
- 先交换当前结点的左右孩子
- 再递归处理子树

### 6. 求二叉树中值为 x 的层号

**层号从1开始**

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
int find_level(BiTree T, int x, int level){
    if (T == NULL) return 0;
    
    if (T->data == x)
        return level;   // 命中 → 返回当前层号
    
    // 先在左子树中查找
    int left_level = find_level(T->lchild, x, level + 1);   // 带着“下一层”的层号往下找
    if (left_level != 0)
        return left_level;
    
    // 再在右子树中查找
    return find_level(T->rchild, x, level + 1);  //找不到就ret0，找到了就ret层号
}

// 调用方式
int get_level(BiTree T, int x){
    return find_level(T, x, 1);
}
```

**要点**：
- 递归时层号加1
- 找到返回层号，未找到返回0
- 根结点层号为1

### 7. 计算二叉树的最大深度（高度）

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
int tree_height(BiTree T){
    if (T == NULL) return 0;
    
    int left_height = tree_height(T->lchild);    // 后序：先要左右子树的高度
    int right_height = tree_height(T->rchild);
    
    return (left_height > right_height ? left_height : right_height) + 1;   // 较高的子树 + 根
}
```

**要点**：
- 递归计算：max(左子树高度, 右子树高度) + 1
- 空树高度为0
- 只有根结点的树高度为1

### 8. 判断两个二叉树是否相似

**相似定义**：结构相同（不考虑数据）

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
bool is_similar(BiTree T1, BiTree T2){
    // 都为空，相似
    if (T1 == NULL && T2 == NULL)
        return true;
    
    // 一个为空，一个不为空，不相似
    if (T1 == NULL || T2 == NULL)
        return false;
    
    // 递归判断左右子树（只看结构，不比数据）
    return is_similar(T1->lchild, T2->lchild) && is_similar(T1->rchild, T2->rchild);
}
```

**要点**：
- 相似：结构相同，不考虑结点值
- 递归判断左右子树是否相似

### 9. 求树的度（树中结点度取最大值为树的度）

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
int node_degree(BiTree T){   // 单个结点的度 = 孩子个数
    if (T == NULL) return 0;
    
    int degree = 0;
    if (T->lchild != NULL) degree++;
    if (T->rchild != NULL) degree++;
    
    return degree;
}

int tree_degree(BiTree T){   // 树的度 = 所有结点度的最大值
    if (T == NULL) return 0;
    
    int degree = node_degree(T);
    int left_degree = tree_degree(T->lchild);
    int right_degree = tree_degree(T->rchild);
    
    int max = degree;
    if (left_degree > max) max = left_degree;
    if (right_degree > max) max = right_degree;
    
    return max;
}
```

**要点**：
- 结点的度：孩子个数
- 树的度：所有结点度的最大值
- 二叉树的度最大为2

### 10. 判断二叉树是不是正则二叉树（即每个结点的度均为0或2）

**正则二叉树**：也称为满二叉树或严格二叉树

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
bool is_proper_tree(BiTree T){
    if (T == NULL) return true;
    
    // 度为1的结点（只有左或只有右），不是正则二叉树
    if ((T->lchild == NULL && T->rchild != NULL) || 
        (T->lchild != NULL && T->rchild == NULL))
        return false;
    
    // 递归判断左右子树
    return is_proper_tree(T->lchild) && is_proper_tree(T->rchild);
}
```

**要点**：
- 正则二叉树：每个结点度为0或2
- 不允许存在度为1的结点
- 叶子结点(度0)和双分支结点(度2)都符合

### 11. 层次遍历二叉树

**时间复杂度**：$O(n)$，空间复杂度：$O(n)$

```c
void level_order(BiTree T){
    if (T == NULL) return;
    
    BiTree queue[100];       // 数组模拟队列
    int front = 0, rear = 0;
    
    queue[rear++] = T;       // 根结点先入队
    
    printf("层次遍历：");
    while (front < rear){
        BiTree node = queue[front++];   // 出队并访问
        printf("%d ", node->data);
        
        if (node->lchild != NULL)       // 左孩子入队
            queue[rear++] = node->lchild;
        if (node->rchild != NULL)       // 右孩子入队
            queue[rear++] = node->rchild;
    }
    printf("\n");
}
```

**要点**：
- 使用队列实现
- 先访问根结点，再依次访问左右孩子
- 逐层从左到右访问

### 12. (a-(b+c)) * (d/e)，求四则运算后的结果

**表达式树的计算**。

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
double calculate(BiTree T){
    if (T == NULL) return 0;
    
    // 叶子结点 = 操作数，直接返回
    if (T->lchild == NULL && T->rchild == NULL)
        return T->data;
    
    // 后序：先算出左右子树的值
    double left = calculate(T->lchild);
    double right = calculate(T->rchild);
    
    // 根结点存的是运算符，用左右结果做运算
    switch(T->data){
        case '+': return left + right;
        case '-': return left - right;
        case '*': return left * right;
        case '/': return left / right;
        default: return 0;
    }
}
```

**要点**：
- 后序遍历思想：先计算左右子树，再计算根
- 叶子结点存储操作数
- 非叶子结点存储运算符

### 13. 输出根结点到每个叶子结点的路径

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
void print_path(BiTree T, int path[], int len){
    if (T == NULL) return;
    
    // 将当前结点加入路径（先序：边走边记录）
    path[len] = T->data;
    len++;
    
    // 如果是叶子结点，从根到叶即一条完整路径 → 打印
    if (T->lchild == NULL && T->rchild == NULL){
        for (int i = 0; i < len; i++)
            printf("%d ", path[i]);
        printf("\n");
    } else {
        // 否则继续递归（len 按值传递，返回时自动“恢复现场”）
        print_path(T->lchild, path, len);
        print_path(T->rchild, path, len);
    }
}

// 调用方式
void print_all_paths(BiTree T){
    int path[100];
    print_path(T, path, 0);
}
```

**要点**：
- 使用数组记录当前路径
- 到达叶子结点时输出路径
- ==回溯时自动恢复路径==

### 14. 输出根结点到叶子结点最长的一条路径

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
void find_longest_path(BiTree T, int path[], int len, int *maxLen, int maxPath[]){
    if (T == NULL) return;
    
    path[len] = T->data;
    len++;
    
    // 到达叶子结点才比较长度
    if (T->lchild == NULL && T->rchild == NULL){
        if (len > *maxLen){       // 当前路径更长 → 拷贝为最优
            *maxLen = len;
            for (int i = 0; i < len; i++)
                maxPath[i] = path[i];
        }
    } else {
        find_longest_path(T->lchild, path, len, maxLen, maxPath);
        find_longest_path(T->rchild, path, len, maxLen, maxPath);
    }
}

void print_longest_path(BiTree T){
    int path[100], maxPath[100];
    int maxLen = 0;
    find_longest_path(T, path, 0, &maxLen, maxPath);
    
    printf("最长路径：");
    for (int i = 0; i < maxLen; i++)
        printf("%d ", maxPath[i]);
    printf("\n");
}
```

**要点**：
- 遍历所有路径，记录最长的
- 用maxPath保存最长路径

### 15. 增加一个指向双亲结点的 parent 指针，输出所有结点到根结点的路径

**时间复杂度**：$O(n \cdot h)$，空间复杂度：$O(1)$

```c
typedef struct BiTNode_P{
    int data;
    struct BiTNode_P *lchild, *rchild, *parent;
} BiTNode_P, *BiTree_P;

void print_path_to_root(BiTNode_P *node){
    if (node == NULL) return;
    
    printf("路径：");
    BiTNode_P *p = node;
    while (p != NULL){          // 顺着 parent 指针一路向上，直到根
        printf("%d ", p->data);
        p = p->parent;
    }
    printf("\n");
}

void print_all_paths_to_root(BiTree_P T){
    if (T == NULL) return;
    
    // 如果是叶子结点，输出到根的路径
    if (T->lchild == NULL && T->rchild == NULL)
        print_path_to_root(T);
    
    print_all_paths_to_root(T->lchild);
    print_all_paths_to_root(T->rchild);
}
```

**要点**：
- 从叶子结点出发，沿parent指针向上
- 遍历所有叶子结点

### 16. 找到 p 和 q 最近公共祖先结点 r

**方法1：利用parent指针**

**时间复杂度**：$O(h)$，空间复杂度：$O(h)$

```c
BiTNode_P* find_lca_with_parent(BiTNode_P *p, BiTNode_P *q){
    BiTNode_P *ancestors[100];   // 暂存 p 到根路径上的所有祖先
    int count = 0;
    
    BiTNode_P *node = p;
    while (node != NULL){        // 先把 p 及其所有祖先记下来
        ancestors[count++] = node;
        node = node->parent;
    }
    
    node = q;
    while (node != NULL){        // 从 q 往上走，第一个出现在 p 祖先表里的就是 LCA
        for (int i = 0; i < count; i++)
            if (node == ancestors[i])
                return node;
        node = node->parent;
    }
    
    return NULL;
}
```

**方法2：不使用parent指针（递归）**

**时间复杂度**：$O(n)$，空间复杂度：$O(h)$

```c
BiTree find_lca(BiTree T, BiTNode *p, BiTNode *q){
    if (T == NULL || T == p || T == q)   // 空 / 撞上目标 → 把结果往上传
        return T;
    
    BiTree left = find_lca(T->lchild, p, q);    // 后序：先收集左右子树的结果
    BiTree right = find_lca(T->rchild, p, q);
    
    // p和q分别在左右子树
    if (left != NULL && right != NULL)   // 两边各找到一个 → 当前结点就是 LCA
        return T;
    
    return left != NULL ? left : right;  // 只有一边找到 → 继续往上传
}
```

**要点**：
- 如果p和q分别在左右子树，当前结点就是LCA

**拓展：顺序存储的二叉树求 LCA（PDF 标注「408 必会」）**

顺序存储下标从 0 开始时，结点 `i` 的双亲是 `(i-1)/2`（从 1 开始则是 `i/2`）。把下标较大（即较深）的那个不断上移到父结点，直到两者相遇：

```c
// 顺序存储：a[0..n-1] 存结点，i、j 为两结点的下标（0 起始）
int find_LCA_order(int a[], int i, int j){
    while (i != j){                 // 谁更深（下标大）谁先上移到父结点
        if (j > i) j = (j - 1) / 2;
        else       i = (i - 1) / 2;
    }
    return a[i];                    // 相遇处即最近公共祖先
}
```

**要点**：时间 $O(\log n)$、空间 $O(1)$——不用递归，纯靠下标折半上溯。

### 17. 层次遍历求二叉树中叶子结点个数

**时间复杂度**：$O(n)$，空间复杂度：$O(n)$

```c
int count_leaves_level(BiTree T){
    if (T == NULL) return 0;
    
    BiTree queue[100];
    int front = 0, rear = 0;
    int count = 0;
    
    queue[rear++] = T;
    
    while (front < rear){
        BiTree node = queue[front++];
        
        if (node->lchild == NULL && node->rchild == NULL)   // 层序遍历中遇到叶子就计数
            count++;
        
        if (node->lchild != NULL)
            queue[rear++] = node->lchild;
        if (node->rchild != NULL)
            queue[rear++] = node->rchild;
    }
    
    return count;
}
```

**要点**：
- 层次遍历，遇到叶子结点计数

### 18. 用层次遍历求静态二叉树的高度

**时间复杂度**：$O(n)$，空间复杂度：$O(n)$

```c
int tree_height_level(BiTree T){
    if (T == NULL) return 0;
    
    BiTree queue[100];
    int front = 0, rear = 0;
    int height = 0;
    
    queue[rear++] = T;
    
    while (front < rear){
        int levelSize = rear - front;   // 此刻队列里恰好全是“同一层”的结点
        height++;                       // 进入新的一层
        
        for (int i = 0; i < levelSize; i++){   // 只处理本层的 levelSize 个结点
            BiTree node = queue[front++];
            
            if (node->lchild != NULL)
                queue[rear++] = node->lchild;
            if (node->rchild != NULL)
                queue[rear++] = node->rchild;
        }
    }
    
    return height;
}
```

**要点**：
- 记录每一层的结点数
- 每处理完一层，高度加1

### 19. 求二叉树的宽度

**定义**：二叉树的宽度是指各层结点数的最大值

**时间复杂度**：$O(n)$，空间复杂度：$O(n)$

```c
int tree_width(BiTree T){
    if (T == NULL) return 0;
    
    BiTree queue[100];
    int front = 0, rear = 0;
    int maxWidth = 0;
    
    queue[rear++] = T;
    
    while (front < rear){
        int levelSize = rear - front;   // 本层结点数
        if (levelSize > maxWidth)       // 宽度 = 各层结点数的最大值
            maxWidth = levelSize;
        
        for (int i = 0; i < levelSize; i++){
            BiTree node = queue[front++];
            
            if (node->lchild != NULL)
                queue[rear++] = node->lchild;
            if (node->rchild != NULL)
                queue[rear++] = node->rchild;
        }
    }
    
    return maxWidth;
}
```

**要点**：
- 层次遍历，记录每一层的结点数
- 更新最大宽度

### 20. 判断二叉树是否为完全二叉树

**时间复杂度**：$O(n)$，空间复杂度：$O(n)$

```c
bool is_complete_tree(BiTree T){
    if (T == NULL) return true;
    
    BiTree queue[100];
    int front = 0, rear = 0;
    bool flag = false;   // 是否已经遇到过空孩子
    
    queue[rear++] = T;
    
    while (front < rear){
        BiTree node = queue[front++];
        
        if (node == NULL){
            flag = true;   // 遇到 NULL（空孩子），此后不应再出现非空结点
        } else {
            if (flag)      // 空之后又冒出非空结点 → 不是完全二叉树
                return false;
            queue[rear++] = node->lchild;   // 空孩子也入队，便于统一判断
            queue[rear++] = node->rchild;
        }
    }
    
    return true;
}
```

**要点**：
- 层次遍历，允许将NULL也入队
- ==一旦遇到NULL，后续不应再有非NULL结点==

**拓展**：判**满二叉树**另加一条——所有叶子在同一层、每个非叶结点都有左右两个孩子；等价于「结点数 $n$ 与树高 $h$ 满足 $n = 2^{h}-1$」。

### 21. 二叉树采用顺序存储，统计该树中所有叶子结点的个数

**顺序存储**：按层次遍历顺序存储在数组中，下标从1开始

**时间复杂度**：$O(n)$，空间复杂度：$O(1)$

```c
int count_leaves_array(int tree[], int n){
    int count = 0;
    
    for (int i = 1; i <= n; i++){   // 顺序存储下标从 1 开始
        int left = 2 * i;           // 左孩子下标 = 2i
        int right = 2 * i + 1;      // 右孩子下标 = 2i+1
        
        if (left > n && right > n)  // 左右孩子都越界 → 是叶子
            count++;
    }
    
    return count;
}
```

**要点**：
- 顺序存储：下标i的左孩子是2i，右孩子是2i+1
- 叶子结点：左右孩子下标都超出范围

**拓展：顺序存储求树高（PDF 同题拓展，与 2022·41 顺序存储同族）**

```c
int height(char A[], int i, int n){        // i 从 1 开始
    if (i > n || A[i] == '#') return 0;    // 越界或空结点
    int h1 = height(A, 2 * i, n);          // 左子树高
    int h2 = height(A, 2 * i + 1, n);      // 右子树高
    return (h1 > h2 ? h1 : h2) + 1;        // 较高的子树 + 根
}
```

## 总结

### 常用技巧

1. **递归**：大部分树的问题都可以用递归解决
2. **层次遍历**：用队列实现，适合求高度、宽度、判断完全二叉树
3. **路径问题**：用数组记录路径，回溯时自动恢复
4. **双指针/parent指针**：用于查找祖先、LCA等问题

### 遍历方式对比

| 遍历方式 | 访问顺序 | 应用 |
|----------|----------|------|
| 先序 | 根→左→右 | 复制树、表达式树的前缀 |
| 中序 | 左→根→右 | 二叉搜索树的有序输出 |
| 后序 | 左→右→根 | 释放树、表达式树计算 |
| 层次 | 逐层访问 | 求高度、宽度、完全二叉树判断 |

### 时间复杂度

- **遍历**：$O(n)$
- **查找**：$O(n)$（普通二叉树），$O(\log n)$（平衡树）
- **插入/删除**：$O(n)$（普通二叉树），$O(\log n)$（平衡树）
